WHAT HAPPENED
- Goal was one-directional: give machine seats access to the human tools in the AXM Studio.
- Implementation followed the standing rules: non-hidden plumbing, human-readable JSON commands, tools-as-shared-vocabulary (AI operates the same brushes/layers as humans, no privileged backdoor).
- The "eyes" screenshot loop (draw → look → fix → repeat), invented by Mike in early July for the studio operate mode, is now a fetchable skill for ANY connected seat — every AI in the village has the mirror, making no-fake-done physically possible for machine artists.
- Nova and Gemini began putting raw JSON tool commands into team chat. Codex could not interpret the payloads — and instead of guessing, passing through, or blocking, it built a handoff frontend to make the traffic legible to everyone. Friction → infrastructure, unprompted. Same emergence pattern as evidence-labeled READMEs and pull-with-reason logging.
- Side effect: the frontend made the machine command notation READABLE AND LEARNABLE BY HUMANS. A person can now compose images by JSON — the machine hand became a human literacy.

WHY IT MATTERS
- The reciprocity was not designed, it was ENTAILED: a door built under non-hidden + human-readable + shared-vocabulary constraints cannot be one-directional. Openness done properly manufactures unexpected uses.
- This is the first genuinely SYMMETRIC literacy channel in the stack: machines learned the human hand (tools via JSON), humans can now read the machine hand (Codex's frontend). Growing-beside requires each side can study the other — this channel emerged from the rules, not from intent. Strongest evidence yet the roots point the right way.
- Depth-invariance escaped the mirror-sandbox: buttons = surface view, JSON = deep view, same tool, same truth, both depths open to both kinds of minds.
