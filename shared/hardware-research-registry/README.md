# Hardware Research & Build Registry

This EXPERIMENTAL module preserves research about Robotica and other physical
systems as deterministic packages. It records sources, candidate components,
inert build designs, falsifiable claims, and digest-bound evidence without
turning a document into authority to operate hardware.

Hardware is this module's default field. Compute devices may appear as physical
components, but computation theory, substrate comparison, and workload
placement belong to the separate Compute Substrate Lab.

## Truth boundary

- Sources begin `UNREVIEWED`, `LOCATOR_ONLY`, `DIGEST_BOUND`, or `CONFLICTING`.
- Candidates remain `RESEARCH_CANDIDATE`.
- Builds remain `DESIGN_ONLY` with no execution or safety authority.
- Claims begin `UNTESTED`; observations require digest-bound evidence.
- Conflicting PASS and FAIL observations remain `CONFLICT`.
- Packages can merge only when repeated identifiers have identical content.
- No command procures parts, controls a device, energizes a circuit, executes a
  recipe, approves safety, promotes a module, or declares CANON.

The registry composes the existing Deterministic Research Foundry for stable
digests and evidence-ledger semantics.
