# Deterministic Research Foundry Roadmap

Status: `TEST` — implementation candidate, not canon.

## Implemented foundation

- R0: exact goal and Workshop Direction normalization.
- R1: current manifest, module-contract, lifecycle-seam, verify-report, need, and direction scanning.
- R2: exact capability comparison with typed HAND, SKILL, AUTHORITY, SUBSTRATE, EVIDENCE, CONTRACT, and UNKNOWN gaps.
- R3: deterministic question, hypothesis, native evidence route, and disconfirming experiment compilation.
- R4: transparent builder/steward ranking with no automatic assignment.
- R5: digest-bound evidence ledger that preserves contradictions.
- R6: machine-readable report, Markdown handoff, run receipt, and observe-only Workshop view.

## Honest next research seams

- Add opt-in source adapters for external literature, standards, and datasets; every fetched snapshot needs provenance and a content digest.
- Add domain-specific experiment executors only when their permissions, budgets, and failure recovery are independently declared.
- Connect reviewed research candidates to Discovery Engine sessions without treating model output as executed evidence.
- Add multi-builder claim leasing so two builders can investigate the same question without overwriting evidence.
- Add historical report comparison that distinguishes a closed gap, renamed capability, changed goal, and missing evidence source.
