# Exact-target checklist

Keep the module on **HOLD** until the real Windows/Codex host proves each item.

1. Run `VALIDATE_WINDOWS.bat` and `SELF_TEST_WINDOWS.bat`.
2. Run `INSTALL_WINDOWS.bat`; confirm staged validation completes before the old program is replaced.
3. Confirm all five skill folders are installed and each focused wrapper returns valid JSON from `status`.
4. Click **AXM - Show Codex** and choose one window through the browser picker.
5. Confirm local Codex uses `axm-visual-intake`, receives the exact absolute file path, and truly opens the image with a visual-capable host tool.
6. Have Codex use `axm-visual-publish` to publish an image; confirm it appears without reopening folders.
7. Have Codex use `axm-visual-snapshot` for a local preview and confirm static HTML scripts and remote resources do not run.
8. Use `axm-visual-runtime` to stop and restart the bridge; confirm no stale session is reused.
9. Upgrade once and run `RESTORE_PREVIOUS_WINDOWS.bat`; confirm the earlier program and skill suite return while exchange history remains.
10. Compare the button and CLI contracts against existing AXM modules; merge overlap instead of creating a second visual inbox.
11. Record Mike's decision. Promotion is never automatic.
