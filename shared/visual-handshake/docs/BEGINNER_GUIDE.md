# Beginner guide

## Install once

Double-click `INSTALL_WINDOWS.bat`. It creates two desktop buttons and places five small Codex skills in your personal `.agents/skills` folder. Codex chooses the intake, publish, snapshot, or runtime skill automatically; the original handshake skill remains as the router.

## Show Codex something

1. Click **AXM – Show Codex**.
2. Click **Choose screen / window**.
3. Pick the program or screen.
4. Draw on the screenshot when useful.
5. Add one sentence about what Codex should inspect.
6. Click **Send visual to Codex**.
7. Tell Codex: `Check the Visual Handshake.`

## Let Codex show you

Ask Codex: `Show me the current result through Visual Handshake.`

Codex publishes the image or preview. Click **AXM – Codex Show Me**. The window also refreshes automatically when already open.

## Private information

Before sharing a screen, close or hide passwords, access tokens, private keys, recovery codes, bank information, and private messages. The bridge is local-only, but Codex still receives the screenshot as task context.
