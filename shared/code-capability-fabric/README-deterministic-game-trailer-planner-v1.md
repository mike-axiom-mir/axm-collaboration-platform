# Deterministic Game Trailer Planner v1

Status: `TEST`

This provider-neutral planner turns the exact Four Roots Adventure content and
Game Hub manifest into one bounded, evidence-linked trailer plan. It teaches
the proven controls and may state only claims present in those exact source
bytes. Line endings are normalized to canonical UTF-8/LF before hashing, so a
Windows checkout does not forge lineage drift.

The plan fixes a 30-second, 640x360, silent and captioned profile with 48 unique
RGBA frames, 360 sample references, MP4 and WebM outputs, zero child processes,
zero network requests, and a 50 MiB encoded-output ceiling. Its schemas close
all nested emitted records.

The planner does not render, write, call a provider, execute the game, publish,
install, promote, change Foundation, or decide `CANON`. Rendering is a separate
trusted native adapter. Public distribution remains `HOLD` for Mike's later
decision.

Run:

```powershell
node shared/code-capability-fabric/selftest-deterministic-game-trailer-planner-v1.js
```
