# Code Specialization Router v1.5

Status: `TEST`

This provider-neutral, deterministic planning rung categorizes observed code
artifacts before any specialist knowledge is attached. It uses separate axes
for language/format, artifact family, responsibility, runtime, framework,
interfaces, authority, and evidence needs. A file extension supplies candidate
metadata only; it never proves language or semantics.

The initial catalog covers broad markup, style, browser, scripting, systems,
managed, query, configuration, build, shader, game-script, proof-language, and
hardware-description families. It deliberately does **not** claim to enumerate
every language. Unknown languages, runtimes, responsibilities, and frameworks
emit typed gaps. Ambiguous path kinds such as `.m` (MATLAB or Objective-C),
`.pl` (Perl or Prolog), and `.v` (Coq or Verilog) require an exact declaration
and remain holds when undeclared.

Four roots run before classification. A current, digest-bound artifact
observation is required, but its host declarations remain independently
untrusted. The router reads no artifact source and grants no files, process,
provider, network, or lifecycle authority.

Specialist organs are narrow technical routing profiles, not identities. They
reuse exact method-mask references from the existing Workshop Specialist
Library. Every matching organ receives its own proposal lane. Multiple lanes
remain separate and require coordination; they are never auto-merged.

Each organ declares a future knowledge lane for accepted recipes, tests,
countertests, and privacy-safe failure rules. In v1.5 every lane is
`REFERENCE_ONLY_EMPTY`: no knowledge is loaded, no lesson is generated, and no
persistent learning occurs. Tier-3 human decision plus held-out regression is
required before any future lesson admission.

The output is only an `axm.code-specialization-plan/v1`. Candidate generation,
sandbox execution, tests, installation, integration, publication, promotion,
physical actuation, and `CANON` remain outside this capability. A clean plan's
next gate is a new exact Tier-1 detached-candidate request.

Run:

```powershell
node shared/code-capability-fabric/selftest-code-specialization-router-v1.js
```
