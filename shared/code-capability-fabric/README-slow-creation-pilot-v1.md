# Code Capability Fabric slow-creation pilot v1

Status: `TEST`

This is the first deliberately small creation rung for the provider-neutral Code Capability Fabric. It turns one exact, grounded-consent-scoped intent into one fixed inert candidate module shell. The result is candidate **data** for review, not installed or runnable authority.

The pilot is Fabric-first only inside this explicit operation. It does not change the Workshop or Machine Host default.

## What it proves

- the intent, emitter profile, consent scope, exact pilot declaration, output bytes, Nursery inspection, and receipt are digest-bound;
- one attempt may create one new direct-child root under one existing host-selected parent;
- six deterministic candidate files are written exclusively, read back byte-for-byte, and structurally inspected by the Detached Candidate Nursery;
- a failed attempt cleans only the newly owned pilot root;
- the retained receipt separates emitted structure from runtime quality, authority, learning, installation, promotion, and CANON.

## What it does not prove

- cryptographic human identity, informed understanding, trusted time, live revocation, or declaration replay prevention;
- the content of referenced predecision evidence;
- semantic code generation or improvement;
- candidate execution, behavior, visual quality, or safety;
- duration or memory enforcement;
- machine-wide default activation;
- persistent learning, installation, registration, staging, promotion, or CANON.

The fixed template contains HTML text only and no script. The emitter does not read source artifacts, use the network, spawn a process, or execute the candidate. Its filesystem authority comes from the surrounding trusted host invocation and is reported honestly as external disposable write authority; the Fabric does not grant it.

## One-candidate CLI

The command requires an absolute canonical existing parent, a new name beginning with `axm-fabric-creation-pilot-`, and the exact acknowledgement `ONE INERT CANDIDATE ONLY`. That declaration is scoped to the invocation, but this v1 pilot has no durable replay ledger and does not treat the phrase as authenticated human consent.

```powershell
node shared/code-capability-fabric/slow-creation-pilot-cli.js `
  --allowed-parent $pilotParent `
  --root-name axm-fabric-creation-pilot-example `
  --acknowledge "ONE INERT CANDIDATE ONLY"
```

The CLI prints a path-free receipt. The selected output path is known to the caller from the two path arguments. Do not execute emitted candidate files; inspect them as data.

## Next typed gaps

The receipt preserves the next work rather than calling the experiment complete: authenticated human decisions, live revocation, trusted time, a fixed Machine Host action, semantic candidate generation, runtime-quality verification in an explicitly authorized disposable sandbox, and a separate learning-admission decision.
