# Grounded Growth human-route coverage

Status: `TEST`

This pure additive leaf verifies that every current Grounded Growth capability
chain has exactly one honest human-evidence disposition:

- a claim-native, named-local, voluntary route with a verified protocol,
  answer-free participant packet, exact current outcome/cycle binding, and v2
  intervention link; or
- a typed hold that names why the route must not be manufactured.

The module refuses stale outcome bindings, cross-capability protocols, answer
leakage, missing chains, duplicate coverage, invalid ancestry, and deferred
proposal activation. A complete coverage receipt can still contain holds. It
does not mean participation occurred or human benefit was established.

Native verification rebuilds from the portfolio and complete route sources.
Detached verification checks receipt integrity and authority boundaries but
holds source truth and currentness at `UNKNOWN`.

The module performs no I/O, network action, participation, installation,
permission grant, promotion, merge, `CANON` decision, Foundation mutation, or
model training.

Run:

```powershell
node shared/grounded-growth-human-route-coverage/selftest.js
```
