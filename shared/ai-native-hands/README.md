# AXM AI-Native Hands

This shared service gives AI-native skills executable, bounded mechanics without turning a skill into authority.

- Evidence Router maps an atomic claim to the proof surface capable of testing it.
- Capability Gap compares typed requirements with a declared inventory and emits missing contracts.
- Session Curator reuses the Evidence Retention spine and can delete only digest-matched Eye-owned temporary files.
- Ephemeral Vision keeps a bounded in-memory sequence, produces a time-ordered contact sheet and tiny digest receipt, then wipes the raw frame buffer.
- Computed Style reads bounded presentation measurements from one exact same-document DOM root for Eye 4. It never reads text content, stores pixels, mutates the page, or turns gradients and incomplete coverage into a pass.
- Eye uses the browser or explicitly shared visual surface first. Windows Native Eye is its backup for native apps, stalled browser capture, or a mismatch between browser and user-visible Windows pixels. It compiles its inspectable C# helper with the laptop's built-in Windows .NET compiler, then uses the native screen body under a named, timed, human-approved lease. Browser permission never transfers to the fallback. Each temporary JPEG is digested and deleted immediately after it enters the bounded memory loop. No antivirus exception or third-party capture package is required.

The hands do not decide taste, grant permissions, install dependencies, publish artifacts or promote evidence into canon.

Run `node shared/ai-native-hands/selftest.js` for focused verification.

An actual native capture is never part of the ordinary test suite. With explicit consent, run `node shared/ai-native-hands/native-capture-smoketest.js --live`; it captures one primary-screen frame, verifies it, and deletes the temporary JPEG.
