# Grounded Growth Challenger Lab

Status: `TEST`

Clone, canonical comparison, and digest preparation use the shared strict
`deterministic-json-core`. Existing JSON-safe plan, evaluation, and readiness
bytes remain unchanged; unsupported JSON state is refused before it can be
silently dropped.

This leaf composes existing AXM organs into a bounded improvement experiment:

```text
verified non-WAIT direction
  -> exact baseline + inert challenger
  -> declared design-visible / held-out case split
  -> Shadow Simulator receipt
  -> paired Diagnostic Experiment Runner receipts
  -> regression / no-gain / evidence-hold / review-candidate disposition
```

It does not execute those tools. It verifies their supplied receipts, derives
comparisons, and refuses a plan for `WAIT_FOR_EVIDENCE`. At least one held-out
AI-workflow case and one held-out regression case are required. A held-out win
can support only the bounded evaluation; it does not establish generalization,
model learning, human benefit, shared growth, adoption, or CANON.

The strongest output is `TECHNICAL_AI_REVIEW_CANDIDATE` with
`adoptionState: NOT_AUTHORIZED`. Separate steward review and a native Grounded
Growth outcome remain mandatory.

Version 0.2 also makes current lab readiness a native exact-rebuild contract.
It binds the verified direction handoff, its direction-readiness receipt, the
two bounded `EXPERIMENTAL` organ contracts, and the exact supplied plan and
evaluation arrays. An empty current array proves only that no plan or evaluation
was supplied to that receipt; it does not prove Workshop-wide absence.
