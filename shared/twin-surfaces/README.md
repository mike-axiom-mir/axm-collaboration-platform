# AXM LEGO City Human/Machine Twin Surfaces

Status: **EXPERIMENTAL**

The compiler creates machine capability packets, exact non-authorizing effect
request templates, and beginner human labels from one city graph. Human labels
must preserve every declared capability, effect, and risk classification and
must map every displayed effect to its exact machine packet.

“Low” is a relative declared-effect category, never a safety statement. Unknown
effect declarations become unknown risk. The generated view cannot install,
execute, authorize, promote, merge, or alter CANON.
