# AXM Aetherglass 7.1 — Visual Logic

## Core equation

**Void + orientation light + material depth + restrained spectrum + semantic motion = otherworldly professionalism.**

The engine is designed around controlled opposites:

- Darkness creates weight; light creates orientation.
- Glass keeps layers visibly related; shadow keeps them distinct.
- Neon communicates energy; quiet neutral typography prevents visual fatigue.
- Fantasy comes from atmosphere, impossible illumination, spectral material, and scale.
- Professionalism comes from hierarchy, spacing, restraint, consistency, accessibility, and predictable control.

The goal is not “everything glows.” The goal is a world where light means something.

## Three visual layers

### 1. World

The global world sits behind the platform:

- void base;
- nebula mass;
- aurora flow;
- caustic light;
- directional beams;
- horizon energy;
- mist;
- stars;
- perspective grid;
- contextual light stage;
- grain;
- vignette;
- optional Aetherfield canvas.

These layers create spatial continuity between separate platform components.

### 2. Material

Glass surfaces are information planes inside the world. Material presets change how they hold light:

- **Clear** — light and transparent; useful for sparse overlays.
- **Smoked** — quiet and readable; useful for operations and long sessions.
- **Crystal** — balanced refraction and depth; general Aetherglass identity.
- **Obsidian** — darker, heavier, high-luxury material.
- **Pearl** — soft, pale internal reflection for gallery and sanctuary states.
- **Holographic** — prismatic and magical; reserve for deliberate focal experiences.

Material is separate from color theme. A Royal theme can use Pearl glass, and an Aether theme can use Obsidian.

### 3. Meaning

Meaningful light and motion express platform state:

- current workspace;
- selected module;
- live AI seat;
- active media;
- focus mode;
- creation mode;
- review mode;
- success, warning, or error;
- completed verification;
- temporary reveal or celebration.

The semantic state bridge makes these relationships explicit. It does not infer hidden states.

## Independent visual axes

Aetherglass avoids one giant theme switch. The platform can tune separate axes:

| Axis | Question it answers |
|---|---|
| Theme | Which color world is active? |
| Atmosphere | What kind of space does the platform occupy? |
| Material | How do information surfaces hold light? |
| Depth | How dimensional should hierarchy feel? |
| Luminosity | How much light energy should the world carry? |
| Density | How open or compact should spacing be? |
| Shape | Should geometry feel soft, sculpted, or precise? |
| Transparency | How much real glass is appropriate for the device and user? |
| Contrast | How strongly should boundaries and text separate? |
| Quality | What visual cost is appropriate? |
| Motion | How much animation is permitted? |
| Intensity | What is the master energy level? |
| Atmosphere strength | How strongly should the world-space layers appear? |
| Glow strength | How much luminous spill should surfaces and accents carry? |

This separation lets the platform remain recognizably AXM while changing purpose.

## Light hierarchy

Use light in this order:

1. **Orientation light** — one primary source that shows where attention belongs.
2. **State light** — selected, live, verified, warning, or completed state.
3. **Material reflection** — glass edge and inner highlight.
4. **Atmospheric light** — broad world depth.
5. **Decorative light** — last and least important.

Decorative glow must never outvote state or content.

## Surface hierarchy

Recommended relative intensity:

1. Focal hero or current command surface: luminous or prismatic.
2. Main workspaces: standard glass.
3. Secondary context: quiet glass.
4. Dense tables and long reading: smoked or solid glass.
5. Background and inactive regions: mostly darkness.

Use no more than one strong luminous surface in a local visual region.

## Typography

- Keep body text neutral and high enough contrast.
- Use gradients only for major titles or rare identity marks.
- Keep labels small but not faint.
- Do not encode state only through color.
- Avoid blurred text, glowing paragraph copy, or low-opacity controls.
- Let spacing and hierarchy do more work than effects.

## Motion grammar

Motion should explain relationship, not demand attention.

- Atmosphere: slow, continuous, low amplitude.
- Hover and focus: short, restrained, reversible.
- Scene transitions: smooth cross-composition changes.
- Success: brief expansion and return.
- Warning/error: short pulse, no endless alarm animation.
- Reduced motion: remove spatial movement; retain clear state changes.
- Motion off: no required information may depend on animation.

## Restraint rules

- Preserve large dark areas.
- Bind only a small number of meaningful global lights.
- Gold is a luxury or completion signal, not a universal accent.
- Holographic material is a focal tool, not the default for every card.
- Particle fields should support atmosphere, not cover content.
- Dense operational screens should use Quiet, Eclipse, Smoked, or Opaque routes.
- Celebration should be temporary and return to the exact previous state.
- Never let visual state silently change permissions, logic, or workflow.

## Performance identity

Aetherglass is designed to degrade by cost while preserving identity:

- **High** — all atmospheric detail, fuller particles, blur, grain, and motion.
- **Balanced** — core world and material identity with reduced subtle cost.
- **Low** — simplified atmosphere, fewer particles, reduced blur and animation.
- **Opaque transparency** — removes backdrop dependence while retaining geometry, borders, and palette.
- **Motion off** — retains hierarchy without animation.

The Performance Governor reports local frame behavior. Recommendation mode is the default because visual adaptation should remain visible and reversible.

## Accessibility identity

Accessibility is not a separate aesthetic failure state. It is another valid Aetherglass composition:

- reduced and off motion preserve information;
- high contrast strengthens borders and readable separation;
- opaque surfaces retain palette and hierarchy;
- focus-visible treatment remains clear;
- fixed atmosphere layers never capture input;
- semantic states should also use text, icons, or structure;
- mobile layouts keep wide content inside local scroll containers.

## Professionalism test

Before approving a screen, ask:

- Can the user immediately see the current working region?
- Does every bright element have a reason?
- Are there enough dark areas for the light to matter?
- Is content clearer than decoration?
- Does the screen still work with motion and transparency disabled?
- Can the visual layer be removed without breaking platform logic?
- Does a temporary effect return to the exact prior composition?

A screen that passes those questions can feel fantastical without becoming chaotic.
