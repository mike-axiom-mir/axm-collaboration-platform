# Aetherglass runtime seam

This directory vendors the bounded runtime used by AXM's skin system.

- Source release: `AXM Aetherglass Visual Engine v7.1.0`
- Intake archive SHA-256: `F7EC6A7B8E2AAF4F82445C7D02E46E3555005502BEF185EFB2EEBA1EDE938DDE`
- Loaded organs: core atmosphere and Luminous Layer Forge
- Network access: none
- Persistence: owned by the AXM skin data contract, not by Aetherglass

The original release remains at the workshop root. These files are kept separate so the integration can be updated or rolled back without flattening them into Hub code.
