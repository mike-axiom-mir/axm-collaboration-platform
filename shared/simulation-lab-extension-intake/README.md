# Simulation Lab Extension Intake

Status: `TEST`

Representation boundary: v0.2 uses the shared strict deterministic JSON core.
Safe JSON keeps the existing canonical bytes; unsupported, cyclic, sparse, or
otherwise non-JSON state is refused instead of being dropped or rewritten.

This permissionless leaf prepares AXM to receive a simulation-lab capability
from a branch without creating another baseline root.

```text
explicit branch module folder
  -> existing Branch Module Return Gate
  -> inert package + exact return receipt
  -> extension declaration bound to the current host profile
  -> static identity, boundary and capability-mapping assessment
  -> NOT_RUN evaluation requirements
  -> explicit steward decision before any experiment
```

The protected host profile is built from three exact `TEST` contracts:

- Portable Baseline Capsule owns portable baseline identity;
- Baseline Simulation Lab owns invariant run truth rules;
- Grounded Growth Challenger Lab owns bounded challenger adjudication.

A returned candidate must use a distinct module ID and declare itself as an
`ADAPTER` or `SPECIALIST_EXTENSION`. It must remain `EXPERIMENTAL`, request no
permissions, preserve unsupported fields by digest-bound reference, and admit
that translation does not create native schema identity.

`READY_FOR_EXPERIMENTAL_EVALUATION_PLANNING` proves only that the inert package
and mappings are structurally ready to plan tests. Runtime behavior, held-out
improvement, human usefulness, grafting, installation, promotion, merge and
CANON all remain outside this leaf.

Run:

```powershell
node shared/simulation-lab-extension-intake/selftest.js
```
