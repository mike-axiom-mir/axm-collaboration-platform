# Compute Substrate Lab

This EXPERIMENTAL module studies how computation may be represented, moved,
combined, reclaimed, and physically implemented. It covers mechanical,
electromechanical, electronic, analog, optical, fluidic, biological, quantum,
and hybrid candidates; e-waste compute; and body/village/workshop/cloud
architectures.

Compute is this module's default field. Physical components may be referenced
through digest-bound Hardware Research Registry handoffs, but this module cannot
declare a robot build safe or operate hardware.

## Provisional known start

The current formal lineage starts at **1837**, the user-selected documented
Analytical Engine boundary. This is a provisional working root, not a claim that
no earlier computation or conception existed. A known 1834 conception boundary
is retained as a candidate rather than silently replacing the selected root.

Changing the working root requires:

1. an earlier milestone already present in the package;
2. two independent digest-bound evidence surfaces;
3. a proposal bound to the exact package and current root;
4. a named human decision with a PASS evidence verdict and independent review;
5. an append-only root-history event preserving the superseded root.

Even an accepted decision changes only the `WORKING_ROOT`; it cannot declare
CANON.

## Refused authority

Research packages and architectures are data. The lab does not run benchmarks,
energize devices, deploy workloads, manipulate live robots, certify resource or
electrical safety, purchase hardware, promote modules, or canonize history.
