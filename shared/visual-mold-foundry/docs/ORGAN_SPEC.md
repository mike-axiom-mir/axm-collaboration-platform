# AXM Visual Organ Specification 0.1

Every organ contract contains:

- stable `id` and `version`;
- `category` and description;
- typed conceptual `inputs` and `outputs`;
- organ `dependencies`;
- compatible runtimes;
- performance cost;
- a fallback when practical;
- validator list;
- evidence-based status.

A browser implementation can be BUILT while its Blender or Godot equivalent
remains LOCAL VALIDATION REQUIRED. Shared semantics do not imply pixel parity.
