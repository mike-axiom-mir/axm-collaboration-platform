CORE PURPOSE
============
AXM's code and collaboration systems are far ahead of its visual layer. This
package must create the missing visual capability layer between human/AI intent
and finished visual output.

The package must combine:
- visual tokens;
- reusable organs;
- controlled molds;
- variants;
- presets;
- lineage;
- rollback;
- proof generation;
- validation;
- export adapters;
- a governed Foundry for deriving more molds.

The aim is not a flat folder of thousands of templates. The aim is a local
visual factory with a useful starter library and a safe way to grow.

FOUNDRY INTAKE
==============
Implement a usable first Foundry workflow:

1. Create or import a visual description/mold manifest.
2. Mark protected, constrained, and free fields.
3. Identify repeated tokens.
4. Select existing organs.
5. Add or remove variant axes.
6. Generate candidate configurations.
7. Run validation.
8. Generate proof.
9. Save as candidate.
10. Derive from a parent.
11. Approve manually or keep experimental.
12. Preserve lineage and rollback.

A full AI decomposition system is not required for v0.1 unless it can be built
honestly and locally. A functional guided Foundry is better than a fake
"automatic intelligence" button.
