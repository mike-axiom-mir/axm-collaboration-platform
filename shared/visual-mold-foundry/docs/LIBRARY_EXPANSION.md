# PRACTICAL LIBRARY EXPANSION — v0.5

## Purpose

Earlier Foundry versions had strong governance but only a small reference library. v0.5 expands the protected package into practical families that can be used immediately and still remain traceable to three protected roots.

## Protected library

The package contains **32 protected molds**:

| Family | Count | Examples |
|---|---:|---|
| Marketing, explanation, and visual logs | 8 | product launch, service poster, case-study proof, event beacon, collaboration call |
| Software UI | 8 | dashboard, settings, onboarding, command palette, alert/recovery, metric, timeline, team panel |
| Game UI and marketing | 8 | launch card, mission briefing, character dossier, loot inspect, quest ledger, boss warning, world event, HUD |
| Living materials | 4 | living skin, frosted crystal, rooted machine, wet neon membrane |
| Atmospheric scenes | 4 | portal, neon street gate, rooted sanctuary, public-calm stage |

The source structure remains **3 roots + 29 sparse derived manifests**. A derived manifest stores only its identity, lineage, provenance, preview, and sparse overrides; the build tool resolves it into a complete runtime mold.

## Practical breadth without flattening

The expansion does not duplicate complete parent manifests. New molds reuse:

- semantic tokens;
- reusable organ contracts;
- governed theme contracts;
- typed controls;
- independent variant axes;
- shared proof and export machinery.

## Preset coverage

The starter garden contains **38 presets**. Every protected mold has at least one starter preset, so each mold can be opened with a useful example rather than an empty contract.

## Growth boundary

The 32 package molds remain protected source material. User-created growth belongs in the separate local candidate, theme, and extension registries. Nothing created locally silently rewrites the protected library.
