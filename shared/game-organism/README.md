# AXM Game Organism Experiment v0.1

This lane generalizes the useful anatomy discovered in Mirror and Foundation
Planet without pretending every organ is AI. Reasoning, physics, animation,
assets, evidence and repair remain different categories. They share only the
portable grammar needed to be composed safely: identity, typed ports,
capabilities, bounded resources, evidence requirements and explicit authority.

The compiler creates an **assembly plan and receipt**, not a game installation.
Every organ is candidate-only, offline and side-effect-free at this rung.
Missing exact versions, category conflicts, type mismatches, unbound inputs,
cycles and resource overruns produce `HELD`. No score can bypass those holds.

The Street Life Slice example follows:

`intent -> design -> rules -> physics -> animation/assets -> assembly -> playtest Eye -> evidence -> bounded repair proposal -> human release gate`

The repair organ is deliberately declared rather than falsely implemented. It
may later consume only proven Repair Buddy recipes. It cannot write new code or
rewrite a canonical game.

Run:

```powershell
node shared/game-organism/selftest.js
```
