# Model Shadow Challenger Gate

Status: `TEST`

This data-only bridge turns one narrow class of Model Shadow Continuity result
into an existing Grounded Growth Challenger Lab plan:

```text
valid ordinary structured drift
  + distinct digest-bound output artifacts
  + an existing verified non-WAIT Grounded Growth direction
  + design-visible and held-out cases
  -> exact challenger plan
  -> Review Inbox projection
  -> declared-human-review handoff with execution still unauthorized
```

It does not invent a Grounded Growth direction. Matching traces, invalid
comparisons, critical authority drift, and observations without distinct output
artifacts remain held and create no plan.

The gate verifies the model-shadow observation by exact rebuild and delegates
plan construction to the existing Challenger Lab. Its Review Inbox projection
binds the exact plan digest. A reviewed handoff requires the exact approved
digest, the required distinct approval count, and at least one seat declared as
human. Review Inbox does not authenticate actors, so the handoff explicitly
states that actual human participation is not proven.

Approval creates no execution or adoption authority. No raw model output,
private context, review discussion, or vote notes are retained. The leaf invokes
no model or provider, writes no state, executes no experiment, performs no
evaluation, and cannot install, train, promote, merge, or canonize anything.

Run:

```powershell
node shared/model-shadow-challenger-gate/selftest.js
```
