# Static Analysis Findings Normalizer

Detached AXM Verification & Proof organ for seed 038.

Normalizes diagnostics from multiple caller-supplied linters and analyzers, deduplicates equivalent findings while preserving contributing tools and suppressions, and evaluates only an explicit severity policy. Tool agreement and a policy PASS are not treated as proof of correctness.

Status: TEST-HOLD, detached, v0.1.0.
