# Runtime Sanitizer Adapter

Detached AXM Verification & Proof organ for seed 037.

Normalizes caller-supplied AddressSanitizer, UndefinedBehaviorSanitizer, ThreadSanitizer, LeakSanitizer, and generic runtime reports into typed findings with a raw-report digest. It distinguishes not enabled, incomplete, failed, and clean completed runs and never launches a sanitizer itself.

Status: TEST-HOLD, detached, v0.1.0.
