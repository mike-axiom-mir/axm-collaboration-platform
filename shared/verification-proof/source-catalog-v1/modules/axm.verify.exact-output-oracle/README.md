# Exact Expected-Output Oracle

Detached AXM Verification & Proof organ for seed 013.

It compares deterministic expected and observed outputs in explicit scalar, text, canonical JSON, base64-bytes, or state-transition modes. Mismatch receipts expose hashes, sizes, and first differing position where safe; they do not infer correctness beyond the declared exact oracle.
