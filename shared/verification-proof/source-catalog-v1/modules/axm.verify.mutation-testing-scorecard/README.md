# Mutation Testing Scorecard

Detached AXM Verification & Proof organ for seed 039.

Calculates a transparent mutation score from caller-supplied mutant outcomes while keeping survivors, timeouts, errors, not-run mutants, and equivalent-mutant candidates separate. It applies an explicit threshold only when the assessment has no unresolved or equivalent-candidate uncertainty.
