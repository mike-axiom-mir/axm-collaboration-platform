# Round-Trip and Inverse Oracle

Detached AXM Verification & Proof organ for seed 018.

It checks whether a forward operation followed by its inverse restores the declared equivalence of the original observation. Equivalence may be exact, canonical JSON, selected JSON Pointer paths, or numeric tolerance. It compares supplied observations and does not execute either operation.
