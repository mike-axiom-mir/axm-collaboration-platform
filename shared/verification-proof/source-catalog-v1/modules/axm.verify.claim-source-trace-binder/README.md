# Claim-to-Source Trace Binder

Detached AXM Verification & Proof organ for seed 008.

It binds a factual or research claim to an exact source identity, version, locator, location, excerpt, observation date, and local evidence-copy state. It does not judge whether the source supports the claim.

## Truth boundaries

- Source support remains `UNCHECKED`.
- Quote fidelity remains `NOT_RUN`.
- Missing local copies must be declared as `NOT_CAPTURED` with a reason.
- The module performs no network fetch and no citation correction.

Status: TEST-HOLD, detached, v0.1.0.
