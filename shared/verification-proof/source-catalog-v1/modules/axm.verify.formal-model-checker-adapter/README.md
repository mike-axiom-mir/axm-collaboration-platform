# Formal Model Checker Adapter

Detached AXM Verification & Proof organ for seed 034.

Creates sealed bounded model-check requests and normalizes caller-supplied tool results while preserving tool identity, assumptions, bounds, property identifiers, counterexamples, and unknown states. It does not run a checker and never expands bounded verification into universal correctness.

Status: TEST-HOLD, detached, v0.1.0.
