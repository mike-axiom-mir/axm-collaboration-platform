# Requirement Traceability Graph

Detached AXM Verification & Proof organ for seed 007.

It links goals and requirements to designs, changed paths, tests, evidence, failures, approvals, and release decisions through an append-only graph. Approval and release nodes are records only; they do not grant authority.

## Truth boundaries

- Nodes and edges are immutable once added.
- Edges require both endpoint nodes to exist.
- Relationship vocabulary is explicit.
- Unlinked requirements remain visible.
- Graph connectivity is navigation, not correctness.

Status: TEST-HOLD, detached, v0.1.0.
