# Evidence Sufficiency Policy Engine

Detached AXM Verification & Proof organ for seed 011.

It evaluates evidence against declared minimum count, required proof surfaces, freshness, relevance, native fit, verdict state, and explicit verifier independence. It reports `SUFFICIENT`, `INSUFFICIENT`, or `UNKNOWN`; it never converts sufficiency into claim approval.

## Truth boundaries

- Every evidence dimension remains visible.
- Duplicate receipt identities are refused.
- Unknown freshness, relevance, native fit, or independence stays unknown.
- Independent evidence must be explicitly declared; it is not inferred from names.
- Sufficiency is policy satisfaction, not truth or CANON authority.

Status: TEST-HOLD, detached, v0.1.0.
