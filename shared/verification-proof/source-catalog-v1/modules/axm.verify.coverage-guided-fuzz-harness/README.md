# Coverage-Guided Fuzz Harness

Detached AXM Verification & Proof organ for seed 036.

Runs a caller-supplied in-process byte target under deterministic case and input-size ceilings, retains inputs that expose new caller-declared coverage tokens, and records the first violation or exception with a bounded deletion-based reproducer. A clean run means only no failure was observed in that bounded campaign.

Status: TEST-HOLD, detached, v0.1.0.
