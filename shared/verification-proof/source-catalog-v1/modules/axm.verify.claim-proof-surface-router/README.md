# Claim-to-Proof Surface Router

Detached AXM Verification & Proof organ for seed 003.

It matches explicitly declared proof surfaces to explicitly registered specialist verifiers. It never executes a verifier and never treats a route as evidence.

## Truth boundaries

- Required proof surfaces come from the claim.
- Claim-type defaults remain suggestions unless the caller explicitly includes them.
- Unknown surfaces remain `UNROUTED`.
- Missing scope remains visible.
- Routing does not transfer authority from specialist verifiers to this module.

Status: TEST-HOLD, detached, v0.1.0.
