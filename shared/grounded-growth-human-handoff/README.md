# Grounded Growth human handoff

Status: `TEST`

Clone, canonical comparison, and digest preparation use the shared strict
`deterministic-json-core`. Existing JSON-safe handoff bytes remain unchanged;
unsupported JSON state is refused before source or package binding.

This additive leaf composes the existing voluntary Human Benefit Evidence and
Grounded Growth Human Bridge v2 contracts into a staged handoff. It closes the
technical space between a retained session receipt and a bridge-ready package
without starting participation, selecting a verdict, writing a file, or
claiming a person was authenticated.

The stages remain distinct:

1. exact session receipts produce a deterministic evaluation;
2. a separate explicit claim-scoped judgment remains required;
3. a native local-steward source declaration binds the protocol, sessions,
   evaluation, judgment, scope, and pseudonymous judge reference;
4. the exact candidate or `REUSE_EXISTING` ancestry, v2 intervention link,
   source declaration, and current closure compose a bridge package.

The local declaration is a declaration, not identity or presence
authentication. It cannot represent a cohort. Synthetic fixtures remain
`SYNTHETIC_HOLD` and map to `UNKNOWN`, even when their deterministic signal and
fixture judgment say `PASS`.

The module has no permissions and performs no I/O, network action, install,
promotion, merge, CANON decision, Foundation mutation, or model training.

Run focused checks with:

```powershell
node shared/grounded-growth-human-handoff/selftest.js
```
