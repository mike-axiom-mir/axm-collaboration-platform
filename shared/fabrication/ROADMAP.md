# Future Fabrication Lane

## Now — research and digital contracts

- Preserve full-colour 3D, UV surface, 3D/resin, laser, CNC and hybrid output as one vendor-neutral capability family.
- Reuse UCP lineage, existing 3MF creation, material/UV metadata, physical toolpath simulation, Asset Fabric incubation and Output Engine receipts.
- Treat all supplied product claims as `UNVERIFIED_ADVERTISING`.
- Build schemas, readiness gates and a digital-only bounded-test package.
- Do not purchase, connect or command hardware.

## Later — independent physical evidence

- Test through a makerspace, school, print service, partner or one manually operated device.
- Verify standard import/export, offline core operation, vendor-AI bypass, colour fidelity, feature size, transparency, strength, repeatability, maintenance, consumables, privacy and real cost.
- Start with calibration coupons and one small AXM token, not a batch.
- Record the exact source, adapter, machine profile, settings, material, measurements, failures and human judgment.

## Far later — governed hardware adapters

- Add one replaceable machine adapter only after its digital and safety contracts pass.
- Require Body Pulse/resource limits, current human operator authority, machine cross-check, emergency stop evidence, and an explicit bounded job lease.
- Keep device command generation and physical execution separate from design approval.
- A single successful print never authorizes unattended or repeated production.

## First useful AXM proofs

1. game-night token with colour/texture intent;
2. QR or table stand;
3. Tilburg building miniature;
4. controller dock or label plate;
5. one-source demonstration set: screen render, printable card, UV surface and 3D object.

## Purchase position

`NO BUY DECISION`. Prove the workflow through external access before hardware ownership. Hardware must remain replaceable without changing the AXM grammar.
