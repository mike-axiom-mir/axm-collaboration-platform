# AXM Orientation Core

This subsystem keeps a small, append-only description of where a person or AI is in a piece of work. It is a re-entry aid, not a second project database and not an autonomy engine.

An `axm.orientation-packet/v0.1` keeps observations separate from interpretations, names uncertainties and blind spots, classifies boundaries explicitly, and records the smallest next test. Its compact re-entry view copies no canonical project state and transfers no authority.

An `axm.representation-translation-receipt/v0.1` records what a format conversion preserved, lost, or compressed. A receipt never claims semantic equivalence or automatic acceptance.

Run `node shared/orientation/selftest.js` for the focused contract check.
