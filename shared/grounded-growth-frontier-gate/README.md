# Grounded Growth Frontier Gate

Status: `TEST`

All frontier clone, canonical comparison, and digest paths use the shared
strict `deterministic-json-core`. Existing JSON-safe frontier bytes remain
unchanged; unsupported JSON state is refused before lane composition.

This additive leaf answers one scoped question: given the exact current
Grounded Growth portfolio, direction handoff, voluntary human handoff
readiness, and simulation-extension intake readiness, what action is actually
authorized now?

It natively verifies the portfolio, direction handoff, and extension host
profile; verifies the self-digests of both readiness receipts; binds the exact
portfolio embedded in the direction handoff; and derives three separate lanes:

- current technical directions;
- voluntary human evidence;
- an externally supplied experimental extension.

The result never authorizes autonomous work. A ready human route is not consent,
an example extension declaration is not a candidate, and a workflow evaluation
is not model learning or human benefit. The receipt is scoped to its five exact
inputs and is not a claim that the entire Workshop has no useful work.

Version 0.1 accepts only the current zero-candidate extension readiness state.
A later candidate-aware version must receive and verify the exact candidate as
a new input; a self-digested readiness count is not evidence of candidate
presence.

The backward-compatible v0.2 module also emits an evidence-frontier receipt.
It exact-rebuild verifies the original frontier and one phone evidence gate,
then exposes the phone route as a fourth, supplemental lane. It does not change
the four-capability portfolio, and even complete phone device plus human keys do
not by themselves prove shared growth or model learning.

The backward-compatible v0.3 module adds a stewardship-frontier receipt. It
exact-rebuild verifies the evidence frontier and Challenger Lab readiness,
cross-binds both to the same direction handoff, and exposes the bounded AI
challenger as a fifth lane beside the human evidence routes. Lab readiness is
not learning, a challenger evaluation is not human benefit, and neither grants
adoption or lifecycle authority.

Run focused checks with:

```powershell
node shared/grounded-growth-frontier-gate/selftest.js
```
