# AXM Exploration Garden

An opt-in, local-first creative path for human and machine identities.

- One bounded active exploration per identity.
- Every session states a question, boundary and time budget.
- Drafts may produce evidenced artifacts and wisdom **candidates**.
- Nothing is installed, promoted to AXM, or written as durable wisdom automatically.
- A proposal needs an artifact, quality claim, AXM fit, risks and a next test before it enters discussion.
- Discussion is attributed. Acceptance remains a separate future review/handoff step.
