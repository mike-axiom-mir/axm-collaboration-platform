AXM CSS SKIN FABRIC v0.2.0 — START HERE

1. Launch the local visual workshop:
   Windows: double-click START_LOCAL_WINDOWS.bat
   Linux/macOS: run ./start_local.sh

2. Open the Theme Laboratory.
   Test accents, blur, glow, geometry and wide/panel/phone containers.
   Exported packets are TEST-HOLD-REVIEW and do not modify canonical CSS.

3. Test every theme, density, effects tier and motion mode.
   The diagnostics section checks target size, duplicate IDs, semantic contrast and browser feature fallbacks.

4. Validate this pack:
   python tools/validate_pack.py

5. Before touching the existing AXM platform, run:
   python tools/audit_css.py PATH_TO_AXM_PROJECT --out audit-output

6. Capture current screenshots and place existing styles in the legacy layer.

7. Extract values into tokens without changing appearance.

8. Migrate one component family and its full state matrix at a time.

9. Use tools/visual_change_packet.py for attributable token changes.

Root rule: generated output proposes; evidence tests; a human decides.
