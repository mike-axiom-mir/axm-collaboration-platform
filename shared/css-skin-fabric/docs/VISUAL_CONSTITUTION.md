# AXM Visual Constitution v0.2

Status: **WORKING**

## Root

A visual system is allowed to grow only when its growth remains explainable, reversible, accessible and attributable.

## Non-negotiable rules

1. Generated output begins as `TEST-HOLD-REVIEW`; it cannot approve or promote itself.
2. Canonical token, component, material and theme files are never overwritten silently.
3. Every promoted visual change carries a purpose, source, before/after evidence, QA result and rollback pointer.
4. A component requests semantic meaning; it does not invent private colors, depth values or motion curves.
5. Effects serve orientation, hierarchy, state, material or atmosphere. Decorative noise without a named purpose is rejected.
6. Reduced-motion, high-contrast, reduced-transparency and low-power behavior are first-class outputs.
7. Human review remains the final promotion gate.

## Promotion path

`TEST-HOLD-REVIEW → WORKING → CANON`

A candidate can move forward only after responsive, keyboard, contrast, overflow, motion, performance and visual-baseline checks. Rejection preserves its manifest and reason rather than erasing history.

## Drift repair

When visual drift appears, restore the latest verified baseline, compare token and recipe lineage, isolate the smallest responsible change, and repair forward without rewriting unrelated surfaces.
