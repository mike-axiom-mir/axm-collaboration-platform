# Recommended Organ Priority — v0.2

## Tier 1 — Preserve reality

### 1. Source Auditor
Maps styles, repeated values, inline rules, runtime injection and risk concentration without editing the project.

### 2. Cascade Governor
Owns deterministic layer order and protects existing CSS inside a documented legacy boundary.

### 3. Visual Constitution
Defines promotion, provenance, evidence and rollback rules before visual generation expands.

### 4. Token Foundry and Token Bridge
Turn repeated values into semantic visual meaning while keeping CSS and AXM's JSON-native collaboration flow connected.

### 5. Visual QA Mirror
Makes current states, computed contrast, target size, compatibility and responsive behavior visible.

## Tier 2 — Compound capability

### 6. Component Mold Registry
Sixteen reusable families cover common tool states instead of producing isolated showcase screens.

### 7. Material & Effect Lab
Eleven semantic recipes provide controlled depth, glass, structure, diagnostics, play and accessibility fallbacks.

### 8. Theme Composer and Theme Laboratory
Shared components can inhabit eight visual worlds. Laboratory output remains temporary until a change packet is reviewed.

### 9. Layout Forge
Fifteen composition primitives separate space from material identity and support container-driven reuse.

## Tier 3 — Govern human use

### 10. Accessibility and Contrast Governors
Protect keyboard focus, target size, forced colors, semantic contrast and readable accent foregrounds.

### 11. Compatibility and Performance Governors
Make advanced CSS an enhancement rather than a hidden hardware or browser requirement.

### 12. Motion Governor
Uses movement for response and orientation, with reduced-motion behavior built in.

## Tier 4 — Grow carefully

### 13. Mold Breeder
Produces specimens for every registered component but cannot write canon.

### 14. Change Packet Builder
Records attributable before/after token values, pending QA and rollback context.

Build the judging and rollback organs before increasing generation volume.
