# No-Loss Migration Protocol v0.2

1. Create a source checkpoint and exact rollback reference.
2. Run `tools/audit_css.py` against the current project.
3. Review repeated-value candidates by meaning; repetition alone does not create a token.
4. Capture route, component, interaction and narrow-container screenshots before edits.
5. Declare cascade layer order.
6. Put current styles into `legacy` without changing visual output.
7. Extract primitive and semantic values one category at a time.
8. Compare screenshots and browser diagnostics after every extraction.
9. Extract one component family and its complete state matrix.
10. Move effects into registered material recipes with low-power and compatibility fallbacks.
11. Record intentional token changes through a visual change packet.
12. Promote only after responsive, keyboard, contrast, motion, performance, visual-baseline and human review.

No automatic canon. No silent rewrite. No generator self-approval.
