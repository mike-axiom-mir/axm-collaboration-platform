# v0.2 Upgrade Notes

This pass preserves v0.1 and adds a visual workshop layer.

- Live bounded Theme Laboratory with local candidate export.
- Browser-computed contrast evidence across semantic token pairs.
- Component state matrix and six new practical molds.
- Three new governed materials: Aetherglass, Obsidian Ceramic and Signal Weave.
- Two new themes: Aetherglass and Calm Workshop.
- Compatibility fallbacks for color mixing, backdrop filters, transparency and data-saving preferences.
- Visual Constitution, governance registry and change-packet schema.
- Expanded Mold Breeder support for every registered component.
- Stronger CSS source audit with risk scoring and migration candidates.
- Optional Playwright visual smoke harness.

## Preserved

- Native CSS source of truth.
- No external runtime dependencies for the gallery.
- Candidate-only generation.
- No silent overwrite or automatic promotion.
