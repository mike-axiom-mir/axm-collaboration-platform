Integrate this pack into the existing AXM platform as a no-visible-change migration. Preserve active direction and current behavior. Do not rebuild the platform or replace existing styles wholesale.

Required order:

2. Run tools/audit_css.py against the platform and preserve all three reports.
3. Identify every stylesheet, inline style, runtime injection, shadow root and framework boundary.
4. Capture current screenshots for routes, states, supported devices and narrow containers.
5. Introduce the declared cascade order.
6. Place existing author CSS in the legacy layer or a documented adapter.
7. Extract repeated primitive and semantic values while preserving screenshots.
8. Migrate one core component family with every registered state.

10. Use the Theme Laboratory only for candidate exploration.
11. Build visual change packets for intentional token changes.
12. Keep all generated output in TEST-HOLD-REVIEW until human approval.

Hard boundaries:
- Native CSS remains the source of truth.
- No silent rewrite or destructive migration.
- No unexplained raw visual values inside migrated components.
- No untracked !important.
- No automatic promotion or generator self-approval.
- Every intentional change needs source lineage, before/after evidence, QA and rollback pointer.
- Reduced motion, reduced transparency, high contrast and low-power behavior are first-class outputs.

Return:
- Audit report and migration-candidates file.
- Migration map and exact files changed.
- Before/after screenshot evidence.
- Theme and state-matrix results.
- Validation and compatibility results.
- Rollback pointer.
- Known gaps and honest next action.
