# Changelog

## 0.5.0 — 2026-07-28

First-adoption proof pass focused on making full-game skin coverage visible,
editable, and honestly testable.

- Added a searchable 33-surface Test Chamber grouped by all seven organs.
- Added isolated per-surface palette and material overrides with provenance
  and one-surface reset.
- Made pack-authored, contract-connected, and game-fallback states visible.
- Added an engine-neutral adapter conformance assessor with six structural
  contract checks and four declared runtime-observation checks.
- Added a Studio conformance lab that resets evidence whenever the active game
  mold changes.
- Added conformance and Studio contract tests while retaining zero automatic
  game writes and the portable v1 skin/game contracts.

## 0.4.0 — 2026-07-28

Game-skin expansion focused on making Style Fabric genuinely whole-game while
retaining Character Forge as its character-focused organ.

- Expanded the portable catalog from six to 33 semantic game surfaces.
- Grouped surfaces into seven isolated organs: world, objects, gear, items,
  characters, effects, and interface.
- Expanded the mold catalog from eight to 16, including environment, vehicle,
  loot/combat, RPG, strategy, party, platformer, and Full Game Skin molds.
- Expanded the deterministic compiler so every full recipe carries materials
  and bindings for all 33 surfaces.
- Added category-by-category coverage reports with zero automatic game writes.
- Expanded the Studio mixer from four layers to seven game-skin organs.
- Expanded generated examples to 20 starter kits and 16 game contracts.
- Preserved the v1 pack and game-contract schemas and legacy material IDs.

## 0.3.0 — 2026-07-28

Third steward pass focused on future-game adoption and self-growing materials.

- Added eight reusable semantic game molds from one character to full presentation.
- Added deterministic game-contract generation from molds.
- Added compatibility reports that inspect semantic aliases without silently remapping.
- Added explicit, provenance-recorded binding remaps.
- Added a deterministic mold maker with six moods and visible complexity.
- Added 12 portable generated starter kits plus eight example mold contracts.
- Added a four-organ layer mixer for world, character, interface, and effects.
- Namespaced materials, assets, and blueprints to prevent cross-scope leakage.
- Added legacy, balanced, showcase, and reduced-motion performance profiles.
- Added Studio controls for molds, growth, performance limits, and layered skins.
- Preserved the v1 pack and game-contract schemas for adapter compatibility.

## 0.2.0 — 2026-07-28

Second steward pass focused on useful creative range.

- Added 25 editable built-in preskins in six families.
- Added deterministic two-preskin fusion with recorded source IDs and blend.
- Added portable precompiled preskin packs and a machine-readable catalog.
- Expanded bounded style vocabulary from 18 to 32 words.
- Added 19 declarative pattern languages.
- Added complementary, analogous, triadic, split-complementary, and monochrome
  palette generation.
- Expanded material controls with glow radius, emissive, specular, clearcoat,
  sheen, weathering, pulse, and shimmer.
- Added pattern strength/scale and geometry controls.
- Expanded character choices to eight silhouettes, seven heads, eight outfits,
  and eight accessories.
- Made character outfit, accessory, shape, and pattern choices visible in the
  specimen.
- Split player, enemy, and world/FX preview variables so character-only scope
  cannot leak material appearance into game-owned fallbacks.
- Added preskin/fusion tests, integrity checks, documentation, and rebuild
  tooling.

## 0.1.0 — 2026-07-28

Initial standalone WORKING / TEST release.

- Universal presentation-slot and skin-pack contracts.
- Deterministic human/machine recipe compiler.
- Whole-game, character, and reusable style creation.
- Material, palette, character, accessibility, and raster-asset controls.
- Resolver receipts and graceful fallbacks.
- Explicit approval/apply/rollback runtime.
- Local creator, library, and portable sharing.
- Security, provenance, integrity, and hosted-provider seams.
- Neutral specimen and example skin.
- No existing AXM game integration or automatic promotion.
