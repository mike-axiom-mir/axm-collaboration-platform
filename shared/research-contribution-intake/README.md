# Research Contribution Intake

Status: `TEST`

Representation boundary: v0.2 uses the shared strict deterministic JSON core.
Safe JSON keeps the existing canonical bytes; unsupported, cyclic, sparse, or
otherwise non-JSON state is refused instead of being dropped or rewritten.

This permissionless leaf turns a caller-supplied research contribution bundle
into one exact, rebuildable assessment and a planning projection compatible
with the Baseline Simulation Lab signal shape.

It exists for the seam that previously required audit-specific glue:

```text
inert artifacts + reported contributor seats + stewarded signals
  -> exact artifact and seat references
  -> evidence-stage and disagreement preservation
  -> common-mode cautions
  -> Baseline Simulation Lab planning projection
```

The projection is not a lab run. It does not build an Evidence Desk receipt,
execute an artifact, invoke a model, prove contributor independence, promote a
signal, choose a proposal, or establish AI learning or human benefit.

An `OBSERVED` signal without a separate declared evidence source is held for
repair. Multiple model seats or apparent agreement never add truth weight.
Unknown artifact-to-seat mapping, partial model identity, or prior-output
exposure remains visible as a warning.

Run:

```powershell
node shared/research-contribution-intake/selftest.js
```

Passing proves only deterministic contract behavior for the tested fixtures.
