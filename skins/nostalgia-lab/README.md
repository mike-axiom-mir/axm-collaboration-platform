# Nostalgia Lab skin experiment

This is an **optional, inactive** AXM skin seed. It does not replace the AXM
default and contains no copied movie artwork or remote asset URLs.

The visual direction is based on a privately shared interface reference whose
creator gave Mike permission to recreate the decorative approach. Before image
slots are added, record the creator's preferred public credit here and place
only independently produced or explicitly licensed assets in the local skin
vault.

Use the Skinner to import `skin.config.json`, review its exact changes and apply
it manually. Reset remains available at all times.
