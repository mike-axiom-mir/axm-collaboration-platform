# Known limits — v0.7

1. **School evidence is not native capability proof.**
   The Forge can teach, grade and preserve adaptive receipts. The current tiny token learner does not yet natively perform the full architecture without future integration.

2. **Audience models can be wrong.**
   Listener facts, assumptions and preferences must remain sourced, tentative, expiring and reviewable. No hidden psychological certainty is claimed.

3. **Semantic checks are bounded.**
   Field comparison, round-trip reconstruction and static graders reduce drift but cannot prove perfect meaning preservation in every language or culture.

4. **Successful reception is not agreement.**
   A listener may understand and still disagree. Agreement rate, approval, obedience and emotional attachment are intentionally not optimization targets.

5. **No autonomous live communication authority.**
   School grades do not grant permission to send messages, use tools, access private data, modify consent, or act on external systems.

6. **No covert personalization.**
   The package does not authorize private-trait inference, emotional exploitation, identity mimicry, profiling, or persuasion designed to bypass judgment.

7. **No fifth root.**
   Adaptivity is taught as a cross-root capability. Truth, Agency, Continuity and Wisdom remain the four fixed anchors.

8. **No arbitrary code execution.**
   Coding Foundations remains static-first. A future execution lab requires a separate disposable, network-off, fixture-only runtime and explicit consent.

9. **No Studio pixel authority.**
   Creative packets remain proposals. Actual creative proof requires the real Studio eyes loop and pre/post pixel evidence.

10. **No broad intelligence claim.**
    The schools do not prove consciousness, human equivalence, broad social intelligence, wisdom, empathy, or safe self-direction.

11. **Transfer remains the hard test.**
    Repeated success on familiar examples is insufficient. Promotion requires frozen held-out, adversarial and cross-domain evidence without regressions.

12. **Native integration remains a visible seam.**
    Meaning Anchor, Audience Model, Meta-Flex Controller, Listener Simulator, Semantic Verifier and Agency Gate are documented candidates, not silently installed organs.

13. **A deadline is not preemptive proof for arbitrary future code.**
    The supported bounded client aborts after 30 seconds and the server records overruns and cooldown. Current Forge operations are synchronous, bounded JavaScript. Any future heavy trainer or arbitrary executable must run in a separately killable worker/process before it can inherit the same safety claim.

14. **Body Pulse coordination is local and optional for manual study.**
    Manual dashboard work always faces the Forge memory guard and respects a visible red Body Pulse when available. Automatic work refuses without an exact active Body Pulse lease. If the Workshop is offline, automatic learning holds while explicit standalone study remains possible within local memory limits.

15. **Windows body sampling has a bounded wait.**
    The local read-only Body Pulse check may take up to three seconds while GPU and battery sensors respond. A timeout makes automatic learning hold; it never grants a bypass.
