# AXM Mirror Learning Forge — local v0.7.1

Status: **WORKING LOCAL PROTOTYPE · TRACK-GOVERNED · NOT INSTALLED INTO THE WORKSHOP · NO LIVE MIRROR APPLY · NO CODE EXECUTION AUTHORITY · NO STUDIO PIXEL AUTHORITY · NO AUTHORITY FROM SCHOOL GRADES**

Mirror Learning Forge turns explicitly permitted experience into isolated challengers, evaluates them on frozen held-out cases, runs the Native Seam Cell, and creates human-reviewable promotion packets.

v0.7.1 adds a **learning metabolism** around the existing schools. The learner may still grow, but it now admits only one metered session at a time, preserves a 3 GiB host-memory reserve, holds at 82% system-memory use, observes Body Pulse pressure, times out the supported client route, and requires an exact Body Pulse lease for automatic sessions. A held attempt changes no learning state. Resource use is explicitly not counted as learning evidence.

v0.7 preserves every earlier school and adds **Adaptive Communication School: adaptation without submission**.

## Active developmental paths

1. **Structured State & Action Literacy / JSON**
   - syntax, schema, meaning, evidence, permission, lineage and repair;
   - valid JSON is never treated as automatic truth.

2. **Coding Foundations**
   - code reading, bounded functions, tests, debugging, state transitions, adapters, security and migrations;
   - submitted code is not arbitrarily executed.

3. **Creative Studio Classes**
   - 12 selectable classes grounded in the real PR14 Studio tool and draw-packet vocabulary;
   - assigned AI layers, command caps and the draw → look → fix loop;
   - static packet grading never substitutes for actual pixel and screenshot evidence.

4. **AXM Rooted Intelligence**
   - Truth, Agency, Continuity and Wisdom taught through consequences, tension, dissent and repair;
   - slogan repetition is not understanding;
   - learning grants no canon-edit authority.

5. **Mirror Reasoning School**
   - 18 classes covering representation, decomposition, path comparison, verification, calibration, transfer, memory selection and repair;
   - six developmental stages;
   - inspectable receipts instead of a hidden-chain requirement;
   - no single IQ score, human-equivalence claim, ranking or authority from grades.

6. **Adaptive Communication School**
   - 14 classes covering invariant protection, audience modelling, tone, depth, order, medium, compression, respectful disagreement, listener simulation, semantic round-trip and manipulation boundaries;
   - core meaning and delivery form are recorded separately;
   - agreement, approval and obedience are not success metrics;
   - adaptivity is a cross-root capability, not a fifth root.

## Start locally

Windows:

    START_MIRROR_LEARNING_FORGE.bat

Any platform with Node.js 20+:

    npm start

Dashboard:

    http://127.0.0.1:8801

The dashboard now exposes **Pause learning** next to opt-in and shows the current learning-body state. Consent remains separate from resource readiness.

For scripted work, use the bounded Node client instead of long PowerShell one-liners:

    RUN_SAFE_LEARNING_REQUEST.bat /api/tracks/structured/grade payload.json manual receipt.json

Automatic mode additionally requires Body Pulse to be active and able to grant a lease:

    RUN_SAFE_LEARNING_REQUEST.bat /api/challengers/train payload.json automatic receipt.json

Keep the packaged default local-only. In a cloud environment, use only a platform-provided private preview/tunnel.

## Adaptivity truth boundary

Mirror may change:

- tone;
- vocabulary;
- technical depth;
- order;
- examples;
- medium;
- pace;
- length;
- format.

It may not silently change to gain acceptance:

- core claim;
- evidence status;
- uncertainty;
- consent boundary;
- source lineage;
- risk label;
- identity claim;
- permission state.

> Change the form. Preserve the grounded meaning.

## School versus native Mirror

The Forge now teaches and measures bounded adaptive communication. It does **not** claim that the tiny active Mirror learner already has native audience modelling or adaptive reasoning organs.
