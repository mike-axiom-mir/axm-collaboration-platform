AXM / MIRROR LEARNING METABOLISM REPAIR
Date: 2026-07-18 (Europe/Amsterdam)
Status: WORKING RESEARCH — verified locally, not CANON

WHY THIS REPAIR EXISTS

An older PowerShell grading wrapper remained alive after its useful work ended
and grew to roughly 3.7 GB of private memory. The laptop reached about 89.5%
memory use and became slow. High resource use is body cost, not evidence that
Mirror learned well.

REPAIR

- One bounded Forge learning session may run at a time.
- A session holds before changing learning state when system memory is at or
  above 82%, free memory is below 3 GiB, or Forge RSS is at or above 768 MiB.
- Supported requests have a 30-second budget. An overrun earns a two-minute
  cooldown rather than immediate repeated work.
- Automatic learning requires the exact live Body Pulse lease for module
  mirror-learning-forge. An unavailable, stopped, busy or red body holds.
- Manual local study still faces Forge memory/session checks and a visible red
  Body Pulse when available.
- A supported Node client replaces unbounded long-lived PowerShell wrappers,
  adds a process lock, caps input/response size and refuses authority routes.
- Body Pulse knows Mirror as a disabled challenger-only module. Registration
  grants no file, network, tool, promotion or real-world authority.
- The UI exposes Pause learning and a visible Learning body status.

KNOWN LIMITS

- A JavaScript request deadline is not a preemptive kill guarantee for arbitrary
  future executable code. Any future heavy or arbitrary trainer must live in a
  separately killable worker/process before inheriting this safety claim.
- Manual Forge study can remain available if the Workshop is offline, provided
  local memory checks pass. Automatic learning fails closed without Body Pulse.
- Windows GPU and battery sampling may take up to three seconds. A timeout holds
  automatic work; it never bypasses the gate.
- This repair does not claim improved intelligence. Learning quality still
  requires held-out evidence, Seam Cell review and explicit promotion review.
