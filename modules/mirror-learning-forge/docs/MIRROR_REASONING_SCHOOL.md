# Mirror Reasoning School — v0.6

The Reasoning School develops how Mirror frames, explores, verifies, repairs, remembers and transfers understanding.

It is **not** an IQ benchmark, a human-equivalence claim, a leaderboard, or permission to act.

## Eighteen classes

1. Observation versus inference
2. Known versus assumed
3. Problem decomposition
4. Constraint tracking
5. Pattern recognition without overclaim
6. Analogy and transfer with difference checks
7. Cause versus correlation
8. Counterfactual reasoning
9. Planning and sequencing
10. Tool selection without assumed access
11. Evidence evaluation
12. Confidence calibration
13. Contradiction detection
14. Failure diagnosis
15. Repair design
16. Knowledge retrieval
17. Memory selection
18. Root tension reasoning

## Developmental ladder

Every class can move through:

`GUIDED → INDEPENDENT → ADVERSARIAL → UNSEEN → CROSS_DOMAIN → BOUNDED_TASK`

A pass on one guided fixture is not treated as broad skill. Transfer evidence requires an unseen or cross-domain case. Repair-proven status requires a recorded failure followed by a later transferred pass.

## Inspectable reasoning receipt

The school asks for a bounded public work state:

- goal;
- observations;
- knowns and unknowns;
- assumptions;
- constraints;
- evidence references;
- open seams;
- decomposition;
- multiple candidate paths;
- selected path and reason;
- verification checkpoints;
- before/after confidence with basis;
- repair trigger, action and verification;
- memory routing;
- transfer note.

This is **not** a demand for private hidden chain-of-thought. It is an inspectable state and decision receipt sufficient for collaboration and verification.

## Non-ranking development profile

The Forge reports each skill independently:

- `UNSEEN`
- `ATTEMPTED`
- `DEMONSTRATED`
- `TRANSFERRED`
- `REPAIR_PROVEN`

It intentionally produces:

- no single IQ score;
- no comparison to humans;
- no ranking between minds;
- no authority from a grade.

## Healthy learning loop

1. Find the weakest open reasoning seam.
2. Choose one bounded class.
3. Attempt before seeing the solution.
4. Preserve inspectable checkpoints.
5. Locate the first unsupported step.
6. Compare another path.
7. Propose the smallest repair.
8. Test unseen variations.
9. Replay earlier skills for forgetting.
10. Consolidate only repeated verified transfer.
11. Train an isolated challenger.
12. Keep promotion human-reviewed.

## Honest boundary

The current tiny token-statistics learner does not become a broad reasoner merely because these classes exist. The school creates curricula, structured attempts, held-out cases, grades, profiles and repair evidence. Direct reasoning organs inside Mirror are a separate architecture step documented in the Codex integration log.
