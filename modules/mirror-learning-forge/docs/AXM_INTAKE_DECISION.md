# AXM intake decision

Accepted as an isolated **AI-native TEST module** on 2026-07-16.

The original package passed 16/16 tests, its deterministic demo returned
`REPAIR` for a challenger that improved local overlap while worsening held-out
perplexity, its journal hash-chain verified, and its Mirror Core packet stayed
`DRAFT`.

## Integration authority

- Mirror's root training policy is the parent policy.
- Mirror's native Seam Cell is the final learning/promotion seam gate.
- The Forge Seam Cell is a useful secondary evaluator, not duplicate canon.
- The Forge may change only its own isolated active-model pointer after its
  review path. It cannot change the live Mirror runtime.
- Automatic local practice may later enter through the standing-practice
  policy. Automatic canon, identity, runtime, permission, or tool promotion is
  forbidden.
- The dashboard is a human rendering of shared machine state. A compact HUD may
  be added later without creating a second state store.

## Intake repair

The supplied loopback server had no request authentication. AXM intake added a
runtime-generated bearer token, injected it only into the local no-store UI,
and now requires it for every state or write API route. Public `/api/health`
remains read-only.

## v0.7 study and reasoning upgrade — 2026-07-17

The verified v0.7 package is accepted as an upgrade to this isolated TEST
module. Its outer and inner package checksums matched, its supplied suite passed
94/94 tests, and its build verifier confirmed the default-deny boundaries.

The upgrade has two deliberately different kinds of activity:

- bounded study/practice tracks for structured JSON, static coding, and
  creative-Studio planning;
- foundation-reasoning development through rooted-intelligence scenarios,
  dissent, inspectable reasoning, and adaptive communication.

Neither category is authority. Grades are evidence receipts only and grant no
tool, runtime, network, filesystem, canon, identity, apply, or promotion power.

AXM preserved the existing runtime state and bearer secret during overlay. The
state remained explicitly opted out at revision 0; no session, lesson, model,
or promotion was applied. The supplied v0.7 server had regressed the v0.1
bearer gate, so intake restored it before acceptance. Public health remains
read-only and every state-bearing or write API route remains authenticated.

The package's native-adaptivity proposal is retained as architecture evidence,
not installed as a new organ. Mirror's parent training policy and native Seam
Cell remain final, and all Mirror Core exports remain DRAFT proposals.
