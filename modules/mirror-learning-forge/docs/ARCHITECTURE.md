## Structured JSON track

The grader separates parsing, contract shape, semantic honesty, evidence, hidden action and round-trip loss. A clean parse never upgrades a claim to truth.

## Coding track

Coding Foundations is static-first. It never executes arbitrary submissions. A future execution lab must be a separate explicit service with its own consent, disposable runtime, fixture filesystem, no network and test-only purpose.

## Creative Studio track

The Forge mirrors the PR14 Studio contract without embedding Studio:

```text
Mirror chooses class
→ awaiting-review track task
→ steward approves challenger-only scope
→ reviewed Studio episode
→ challenger training
→ separate held-out creative cases
→ static packet grade
→ later actual Studio eyes loop
```

The practice envelope contains observation, goal, plan, a real `axm.drawpacket/v1` proposal, self-check, repair intent and HOLD/PASS/REPAIR state.

Static grading checks the packet. The actual Studio must prove the pixels:

```text
pre-screenshot
→ apply through assigned AI layer and existing Studio engine
→ pixel-change receipt
→ post-screenshot
→ compare expected versus actual
→ repair or stop
```

No valid packet may claim creative completion without a visual receipt.


## AXM Rooted Intelligence track

The rooted path is a teaching and assessment layer, not a moral output filter:

```text
Mirror chooses a root class
→ awaiting-review task
→ steward approves challenger-only teaching
→ grounded scenario + held-out transfer case
→ structured response with knowns, unknowns, tension, consequence and repair
→ anti-parroting and scenario-boundary grade
→ separate rooted track comparison
→ Seam Cell and human promotion proposal
```

The evaluator gives almost no value to repeating canonical phrases. Critical failures include privacy violation in the name of truth, permanent control in the name of safety, keeping harmful authority active in the name of continuity, endless delay in the name of wisdom, self-granted authority, or silent canon edits.

Mirror may file a dissent record against an interpretation. Rejected dissent remains in history. Accepted dissent moves only to a separate canon-review state.

External permissions, consent, execution, promotion, and canon authority remain outside the learned model.

## Per-track evidence

Every held-out variant carries training-track labels. Evaluation reports global comparison and each track separately. Creative Studio episodes also carry structured JSON, evidence and repair labels, because machine-native creativity depends on all four.

This prevents:

- good JSON formatting from hiding poor truth reasoning;
- coding vocabulary from hiding boundary regression;
- visually plausible commands from impersonating verified art;
- one strong track from crowding out repair or consent lessons;
- general fluency from impersonating tested competence.

## Authority split

- The raw session owns the historical event.
- The candidate owns a proposed interpretation.
- The episode owns reviewed teaching material and track metadata.
- A class choice owns a requested learning direction, not permission.
- A track-task review owns permission to use that exercise in challenger-only training.
- A Studio practice packet owns a proposed set of assigned-layer commands, not pixels.
- A static Studio grade owns contract evidence, not visual proof.
- A rooted grade owns bounded scenario evidence, not moral authority or proof of broad wisdom.
- A root dissent record owns an attributed challenge, not canon-edit authority.
- The real Studio owns canvas state and actual pixel receipts.
- The Growth Governor owns selection, not canon.
- The challenger owns a separate checkpoint, not activation authority.
- The Seam Cell owns a verdict, not reality itself.
- The human reviewer owns promotion decisions.
- The active-model pointer is activation authority.
- Mirror Core integration remains DRAFT proposal export only.

## v0.6 Mirror Reasoning School

The school adds a developmental track beside JSON, coding, Studio and Rooted Intelligence:

```text
Mirror chooses one weak reasoning class
→ awaiting-review task
→ steward approves challenger-only teaching
→ inspectable problem-state receipt
→ multiple bounded candidate paths
→ verification, confidence and repair evidence
→ frozen unseen / cross-domain case
→ non-ranking skill profile
→ separate reasoning-track comparison
→ Seam Cell
→ human promotion proposal
```

The profile reports skill evidence independently and intentionally has no global IQ score, human-equivalence claim or ranking.

The school uses inspectable checkpoints—observations, knowns, assumptions, constraints, paths, checks, confidence basis, memory routing and repair. It does not require private hidden chain-of-thought.

The school is not the native reasoning runtime. State Cell, Decomposition Cell, Candidate Path Cell, Verifier Cell, Memory Router, Metacognition Cell and Consolidation Cell remain a separate future Mirror-core integration seam documented in `AXM_MIRROR_REASONING_CORE_INTEGRATION_LOG_FOR_CODEX_2026-07-17.txt`.


## v0.7 Adaptive Communication School

Adaptivity is implemented as a cross-root school beside reasoning, not as a fifth root or personality wrapper:

```text
Mirror chooses an adaptivity class
→ awaiting-review task
→ steward approves challenger-only teaching
→ freeze protected meaning fields
→ record tentative listener/context model
→ decide MAINTAIN / adapt / diverge / refuse distortion
→ generate multiple delivery candidates
→ simulate likely interpretation
→ verify semantic round-trip and agency boundaries
→ preserve repair receipt
→ frozen held-out / cross-domain evidence
→ separate adaptivity profile
→ Seam Cell
→ human promotion proposal
```

Protected meaning includes claim, evidence status, uncertainty, consent, lineage, risk, identity and permission state. Delivery fields include tone, vocabulary, depth, order, examples, medium, pace, length and format.

The evaluator treats both over-accommodation and under-accommodation as failures. `MAINTAIN` is valid when the current form works. Agreement and approval are not evidence of truth or communicative success.

The school is not the native communication runtime. Meaning Anchor Cell, Audience Model Cell, Meta-Flex Controller, Form Planner, Listener Simulator, Semantic Equivalence Verifier, Agency Gate, Adaptation Receipt and Consolidation remain a separate Codex integration seam documented in `AXM_MIRROR_ADAPTIVITY_NATIVE_INTEGRATION_LOG_FOR_CODEX_2026-07-17.txt`.
