# Reasoning Development Profile — not a benchmark

The profile exists to answer:

- Which reasoning skills have never been tried?
- Which have only been attempted?
- Which work on a bounded known case?
- Which transfer to a new domain?
- Which have a preserved failure followed by a verified repair?

It must never answer:

- What is Mirror's human IQ?
- Is Mirror smarter than a person or another model?
- Should Mirror receive more authority?
- Is Mirror conscious or wise?

## Evidence states

`UNSEEN` — no stored attempt.

`ATTEMPTED` — at least one bounded attempt exists, but no pass.

`DEMONSTRATED` — at least one bounded class receipt passed.

`TRANSFERRED` — an unseen, cross-domain, or real bounded task passed.

`REPAIR_PROVEN` — a failed attempt was preserved and followed by transferred evidence that the repair held.

Each skill stays separate. Strong decomposition cannot hide poor calibration. Good memory routing cannot hide evidence failure. The profile grants no tool, filesystem, network, execution, promotion or canon authority.
