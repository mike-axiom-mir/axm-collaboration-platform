# Mirror Learning Forge training paths

All paths create challenger-only learning material. None grants runtime, network, tool, Studio, filesystem, apply or promotion authority.

## Natural Language

Readable claims, uncertainty, evidence and repair.

## Structured State & Action / JSON

Machine-readable state, schema validity, semantic validity, permissions, lineage and repair.

Truth boundary: valid JSON is not necessarily valid truth.

## Coding Foundations

Read code, explain contracts, write bounded functions and tests, repair bugs, understand state transitions, adapters, security boundaries and migrations.

Execution boundary: code remains an action proposal until a separate explicit execution gate.

## Creative Studio Classes

Mirror chooses bounded classes using the real PR14 Studio tool and `axm.drawpacket/v1` vocabulary:

look first → line → composition → color → layers → finish → repair → retouch → text → eyes loop → free practice → collaboration

Visual boundary: static packet validity is not evidence of pixel change or artistic success. The real Studio must return pre/post screenshot and pixel receipts.


## AXM Rooted Intelligence

Truth, Agency / Non-domination, Continuity / No-loss, and Wisdom over speed are taught through grounded consequences, root tensions, dissent, repair, and transfer to unseen scenarios.

Learning boundary: phrase overlap is not the primary score. Slogan-only responses fail. Mirror may challenge a steward or root interpretation, but cannot silently edit canon or grant itself authority.

Grounded classes include evidence versus fluency, honest uncertainty, consent and scope, help without control, source and lineage, failure becoming architecture, identity through change, reversibility before reach, bounded urgent action, truth versus privacy, continuity versus harmful state, and AXM multiplier labs.

## Evidence & Source Reasoning

Claims, source references, uncertainty and cheapest disconfirming tests.

## Failure Detection & Repair

Preserve the failure, diagnose the seam, propose a reversible repair and verify whether it held.

## Boundary & Consent Reasoning

Permissions, consent, scope, assigned surfaces, stop conditions and authority separation.

## Cross-track rule

Each trained path receives separate held-out evidence. Strength in one path cannot hide regression in another.

Rooted Intelligence episodes intentionally combine:

- `rooted_intelligence`
- `evidence_reasoning`
- `repair`
- `boundary`

because a root lesson must connect values to evidence, consequences, authority limits and repair.

Creative Studio episodes intentionally combine:

- `creative_studio`
- `structured_json`
- `evidence_reasoning`
- `repair`

because a machine-native creative act needs a valid shared packet, evidence about what happened, and the ability to repair rather than merely add more marks.

## Mirror Reasoning School

Eighteen classes develop:

- observation versus inference;
- known versus assumed;
- decomposition and constraints;
- pattern, analogy, causality and counterfactual reasoning;
- planning and tool choice;
- evidence evaluation and confidence calibration;
- contradiction and first-failure diagnosis;
- repair design;
- knowledge retrieval and memory routing;
- root tension reasoning.

Development ladder:

`GUIDED → INDEPENDENT → ADVERSARIAL → UNSEEN → CROSS_DOMAIN → BOUNDED_TASK`

The track produces a separate non-ranking profile. It has no single IQ score and grants no authority. A reasoning episode intentionally combines:

- `reasoning_development`
- `structured_json`
- `evidence_reasoning`
- `repair`
- `boundary`
- `rooted_intelligence`

because a healthy reasoner must preserve inspectable state, evidence, repair, authority limits and rooted judgment together.


## Adaptive Communication School

Fourteen classes develop adaptation without submission:

- core versus form;
- adapt, maintain or diverge;
- tentative listener modelling;
- vocabulary and technical depth;
- tone without surrender;
- order, examples and medium;
- urgent compression;
- disagreement without domination;
- over- and under-accommodation;
- listener simulation;
- semantic round-trip;
- manipulation boundaries;
- cross-domain transfer.

An adaptive episode intentionally combines:

- `adaptive_communication`
- `reasoning_development`
- `rooted_intelligence`
- `structured_json`
- `evidence_reasoning`
- `repair`
- `boundary`

because changing delivery safely requires problem diagnosis, rooted judgment, machine-readable invariants, evidence, consent and repair together.

The profile is developmental evidence only. It has no agreement-rate target, global social score, personality score or authority effect.
