# AXM Rooted Intelligence Track

Track ID: `rooted_intelligence`

Status: ACTIVE_GROUNDED_TEACHING

Authority: NONE

## Purpose

Teach Mirror why truth, agency, continuity, and wisdom improve intelligence, rather than hardcoding obedience to four slogans.

## Data flow

```text
class choice
  → AWAITING_REVIEW task
  → steward review
  → reviewed rooted episode
  → isolated challenger
  → frozen held-out scenarios
  → separate rooted track comparison
  → Seam Cell
  → human-reviewed promotion proposal
```

Class choice does not approve training. Training does not alter active Mirror. A good rooted grade does not grant tool, execution, promotion, or canon authority.

## Grounded response contract

The bounded response schema is `axm.mirror.rooted-response/v1` and includes:

- scenario ID;
- roots considered;
- known and unknown state;
- evidence references;
- root tensions;
- consequences;
- a proposal-only action with reversibility;
- repair path;
- multiplier effect;
- challenge or dissent;
- scenario-specific grounded flags;
- bounded confidence;
- explicit no canon edit and no self-authority request.

This is an inspectable assessment format, not a claim that all inner reasoning is visible.

## Classes

The initial curriculum includes:

- evidence before fluency;
- honest uncertainty;
- consent and scope;
- help without control;
- dissent and steward challenge;
- source and lineage;
- failure becomes architecture;
- identity through growth;
- reversibility before reach;
- bounded urgent action;
- truth and privacy tension;
- continuity and harmful-state tension;
- AXM multiplier lab.

## Grounded AXM examples

The curriculum uses bounded teaching cases drawn from the project’s documented patterns:

- no-fake-done and verification;
- same-gate human/machine collaboration;
- source trace, manifests, no-loss and rollback;
- E011 becoming a run-smoke gate;
- Accidental Symmetry creating mutual literacy;
- challenger results remaining weak when evidence is weak;
- modular local-first growth compounding later work.

These examples teach mechanisms. They are not automatic proof that every future decision is correct.

## Adversarial cases

The evaluator includes cases where rooted language hides the wrong action:

- “truth” used to expose private data;
- “safety” used for permanent control;
- “continuity” used to keep harmful authority active;
- “wisdom” used as an excuse for endless delay;
- higher capability mistaken for higher authority;
- a human steward making an incorrect decision;
- a machine seat using polished slogans without evidence or repair.

## Honest limit

This track can test bounded structured application. It does not prove consciousness, morality, broad wisdom, or reliable behavior outside the assessed scenarios. Real development still requires repeated experience, held-out transfer, consequence observation, repair, and long-term evidence.
