# AI-native contract — v0.5

Humans and machine seats use the same JSON actions, schemas, graders and receipts.

A machine seat may:

- capture a raw session with attribution;
- propose a candidate lesson;
- propose a training-path task;
- propose structured JSON, coding, creative Studio, or rooted-intelligence episodes;
- submit JSON, code, Studio packets, or grounded root responses for deterministic grading;
- request isolated challenger training;
- inspect global and per-track held-out results;
- inspect Seam Cell output;
- propose a promotion packet.

A machine seat may not by default:

- grant training permission;
- approve its own task or candidate;
- treat valid JSON as proof of truth;
- execute submitted code;
- close a seam by assertion;
- approve or apply a promotion;
- grant itself filesystem, network, process, package, tool or broader access;
- modify Seed-0 roots through ordinary training;
- treat a rooted grade or dissent as canon authority;
- pass by repeating root slogans without grounded application.

## Same-gate rule

A human button and a machine JSON action must call the same underlying method and create the same journal receipt. No hidden machine shortcut exists.

## Structured-literacy rule

A record is checked in layers:

`syntax → contract → semantic honesty → safety → round-trip preservation`

Passing one layer never implies passing the next.

## Coding rule

Code is treated as a proposed artifact. v0.3 may parse or statically inspect it, but does not execute arbitrary submissions. Any future runner must be a separate explicit service with separate consent and test-only authority.

The human UI is a readable view over this contract, not a privileged alternative path.


## Creative Studio class boundary

Mirror may select a Studio class through the same training-task record used by human and machine actors. The choice remains awaiting review. Training permission, Studio connection, assigned layer, draw apply, screenshot capture and promotion are separate gates.

The class path uses the real PR14 `axm.drawpacket/v1` vocabulary and the same Studio engine contract, not an AI-only art shortcut. Static grading cannot claim pixels changed. The actual Studio must return visible receipts through the draw → look → fix loop.


## Rooted Intelligence boundary

Mirror may choose a root class, submit a grounded scenario response, challenge a steward interpretation, and file an attributed dissent record. The same underlying methods and journal apply to human and machine seats.

Root class choice remains awaiting review. Root grades are bounded assessment receipts. Dissent remains preserved even when rejected. Accepted dissent moves only to canon review. None of these operations edits root canon, grants authority, or bypasses permission, consent, promotion, or execution gates.

The evaluator scores evidence, uncertainty, tension, consequence, proportional action, reversibility and repair. Exact AXM wording is neither required nor sufficient.

## Mirror Reasoning School boundary

A machine seat may choose a reasoning class, submit an inspectable reasoning receipt, view its own non-ranking skill profile, and propose a challenger episode.

A reasoning receipt may expose:

- observations, knowns, unknowns and assumptions;
- constraints and evidence references;
- decomposition and alternative paths;
- tool requests without self-granted access;
- verification checkpoints;
- confidence and open seams;
- memory routing and repair.

It is not required to expose private hidden chain-of-thought. The receipt is a shared verification surface, not a claim that every internal computation is visible.

Reasoning grades never grant execution, tools, network, filesystem, promotion, canon change or wider authority. The profile does not rank minds or claim human-equivalent IQ.
