# AXM Native Learning Shell

Status: **TEST**

This is the AXM-native implementation of the role the earlier Hermes shell was
meant to play for Mirror. It is dependency-free and does not require or imitate
an installed Nous Hermes runtime. A real external Hermes model may later be
connected as one optional reasoning profile through a reviewed adapter.

The shell makes a bounded learning session visible as seven structured stages:

```text
Context -> Analysis -> Reasoning -> Seam Review
        -> Lesson Admission -> Challenger Training -> Judgement
```

Each stage writes a JSON artifact and an append-only event. The human dashboard
and machine API render the same evidence. The artifacts contain inputs,
evidence, claims, decisions, seams and test results; they do not expose or
collect hidden chain-of-thought.

The Reasoning stage runs Mirror Core's native Reasoning Foundation. Its artifact
contains separated problem state, decomposition, candidate-path comparison,
verification, metacognition, proposal-only memory routing, consolidation and an
independent Seam Cell audit alongside the linked Principle trace.

## Linked foundation

The read-only context bundle links Mirror's roots, current status, bill of
materials, training policy, Workshop identity binding, attributed wisdom,
opted-in Mirror-only profile card, skill manifests, curricula, reasoning
profiles, specialist masks and prompt packs. These remain separate typed
inputs. None grants a permission merely by being present.

## Authority boundary

The shell can admit a verified local lesson to private practice under the
standing policy and run isolated token and reasoning-strategy challengers. The
two tracks keep separate metrics and Seam Cell verdicts: token perplexity
cannot impersonate reasoning transfer, and reasoning transfer cannot hide a
language regression. After a lesson, the shell builds a content-digested
curriculum evaluator and calls the separate Reasoning Experience Organ.
Expected behavior becomes a positive episodic receipt; mismatched behavior
becomes negative evidence without a success prototype. The next reasoning cycle
first discovers typed module-contract refusal fields, creates contract-derived
private exams for a stable training partition, and reserves other module IDs for
held-out transfer. It separately generates exact typed one-hop and depth-two
handoff route proposals and incompatible decoy checks without admitting either
to training. A separate content-addressed readiness overlay projects current
Technical Glasses requirements onto those routes, preserves UNKNOWN as a
blocking state, and records READY, AVAILABLE, NEEDS_ACTION, and BLOCKED without
starting or repairing anything. It then derives or reuses bounded, parent-linked synthetic
interventions before it discovers eligible receipts. Contract exams, synthetic
cases, and real local lessons remain separate evidence classes. Held-out
contract modules never create training receipts. Append-only receipts from a
superseded counterexample evaluator stay stored as `KNOWN_FAIL` but are excluded
from training. A single episode cannot become semantic truth, and learned-model
self-training is refused. It cannot execute the evaluated
Workshop action or promote runtime weights, canon, identity, wisdom,
permissions, network access or tool authority. The final stage may only hold
for repair or propose human review.

Before the private reasoning cycle, the Training stage also runs the hard-coded
Metamorphic Organ over verified real receipts. It derives invariance probes from
typed receipt shape rather than lesson IDs and stores each complete machine and
human trace under ignored private state. A confirmed invariant creates no
training receipt. A mismatch can create only negative evidence with no success
prototype and a Frontier exam proposal; it cannot repair or promote itself.

## Run

```text
node modules/axm-native-learning-shell/server/server.js
```

Then open `http://127.0.0.1:8802/`. The same-origin page receives a local bearer
token; API state and write routes reject unauthenticated requests.
