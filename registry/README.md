# AXM public registry

These files are generated by `scripts/generate-public-discovery.js` from
`tools-index.json`.

- `modules.json` records module paths, contracts, tests, readiness, and blockers.
- `capabilities.jsonl` records declared capability providers and consumers, one
  JSON object per line.
- `public-status.json` records public release gates and limitations.
- `proofs.json` routes public claims to evidence and states what each proof
  cannot establish.

Regenerate with `npm run discovery:generate` and verify without writes with
`npm run discovery:verify`. Do not hand-edit generated registry data.
