# Mirror native-organ route

Seed-0 does not imitate a finished assistant. It establishes the typed state
and evidence language that later organs must consume and produce.

Proposed order, each behind its own evaluation and human merge gate:

1. **Evidence organ** — source quality, contradiction, missing-information and
   calibration tests.
2. **Outcome organ** — compare predicted effects with observed results and
   propose corrections without rewriting the failed record.
3. **Candidate organ** — generate several bounded action candidates while
   leaving selection to the deterministic principle cell.
4. **World organ** — compact predictive state transitions for explicitly
   scoped domains, beginning with Workshop tests and simulations.
5. **Language organ** — translate between human language and native state;
   language never becomes the source of truth.
6. **Tool organ** — propose tool calls through AXM gates. It receives no tool
   authority merely because an earlier organ becomes capable.

High-capability model outputs may become candidate teaching artifacts only
when they contain reviewable decisions, evidence, alternatives, verification,
corrections and outcomes, and when use permission is explicit. Hidden private
reasoning is neither required nor accepted.
