# Outcome organ requirements

This keeps the useful core of the proposed causal/physics hybrid while refusing
the first implementation's false certainty and duplicate state layers.

The organ must:

1. represent a predicted state delta with source evidence and a declared scope;
2. preserve uncertainty as uncertainty — never rename it mismatch or failure;
3. compare typed predicted fields with typed observed fields;
4. score probability calibration across many outcomes, not invent a confidence;
5. keep deterministic identifiers and replayable input/output hashes;
6. send principle and permission questions to Seed-0 rather than hardcoding an
   alignment result;
7. append corrections while preserving the failed prediction;
8. propose repairs without receiving direct tool authority;
9. include tests for missing observations, contradictory evidence, partial
   matches, uncertain-but-correct predictions and confident wrong predictions.

The Grok `CausalPhysicsLayer v0.1` proposal contributed the direction. Its code
was held because it equated uncertainty with mismatch, hardcoded alignment,
used nondeterministic identifiers, allowed normalized fields to be overwritten,
duplicated existing evidence/constraint structures and provided no tests.
