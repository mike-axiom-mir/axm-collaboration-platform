# Mirror Studio candidate organ — first bounded rung

Status: **EXPERIMENTAL**

The first candidate organ is intentionally smaller than a creative model. It
turns a structured AXM Studio observation into several reversible geometric
proposal packets. It then ranks those packets using declared, inspectable
features: canvas margin, geometric balance, command simplicity, blank-canvas
fit, and contrast against the declared background.

The ranking is order-invariant. Reversing the candidate array must not change
the recommendation. Equal scores use a stable candidate id rather than input
position.

The organ cannot:

- see pixels or infer visual meaning;
- execute a Studio command;
- change permissions, roots, identity, learned weights, or itself;
- promote its output to wisdom or canon;
- claim aesthetic understanding.

The live route remains split:

```text
structured Studio observation
-> isolated candidate organ originates and ranks proposals
-> deterministic Principle Cell checks evidence, permission, risk and recovery
-> explicit Studio button applies only the selected Mirror-owned packet
-> before/after pixel receipt records whether anything actually changed
```

This closes only the narrow "no candidate exists" seam for a blank Studio
exercise. Open-ended candidate generation, learned judgement, vision, outcome
learning, and general tool use remain later rungs.
