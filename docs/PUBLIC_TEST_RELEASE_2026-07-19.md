# AXM Workshop public-test candidate — 2026-07-19

This candidate is the next large public-safe Workshop checkpoint. It replaces
the old fixed module-count story with generated discovery: at the time of this
candidate, the verifier discovers 80 manifest-backed tools and nine modular
game packages. Future readers should use Technical Glasses or
`npm run glasses` for the live inventory rather than treating those dated
release numbers as permanent.

## What changed

- Added a beginner Windows front door: extract the repository ZIP and open
  `OPEN_AXM_WORKSHOP.cmd`; no account, API key, AI connection, or `npm install`
  is required for the core Hub.
- Reworked the repository front page, start guide, security guidance,
  contribution path, and GitHub issue templates for public testing.
- Added a GitHub Pages doorway with an honest boundary: Pages explains and
  downloads AXM, while the actual Workshop and its local services still run on
  the user's device.
- Added the newer modular rooms, games, asset hands, governance routes,
  evidence systems, learning and creative workspaces from the active Workshop.
- Preserved the public Mirror Core baseline byte-for-byte and kept the newer
  evolving Mirror AI body, learning state, corpus, weights, organs, and
  training runtime out of this candidate.
- Recorded narrow provenance and publication authorization for the included
  Mike/AXM-generated District Party art. No broad CC0 or standalone art-license
  claim was invented.
- Hardened public packaging so local saves, sessions, logs, state, backups,
  caches, tokens, temp evidence, and redundant source archives stay out.
- Repaired public-checkout portability in the native-host and Claude connector
  tests and removed machine-specific user paths from public metadata.

## Honest open seams

The verifier intentionally retains 30 game-night warnings. They describe
unproven controller, physical-phone, reconnect, blocking-overlay, or external
collaborator behavior in specific game packages. They are not release
failures, and this candidate does not relabel them as complete.

This is a public test, not a production certification. Network exposure,
remote machine authority, AI providers, Discord, and controller transports are
optional capabilities with separate setup and review boundaries.

## Review route

3. Report reproducible seams using the repository issue templates.
