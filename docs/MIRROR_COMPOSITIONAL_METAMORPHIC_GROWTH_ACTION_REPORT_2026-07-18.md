## Outcome

Mirror's hard-coded Reasoning Metamorphic Organ can now generate bounded new
evaluation work from operators it already knows. For every verified real local
reasoning receipt, v2 selects the applicable atomic invariance operators from
the receipt's typed shape and automatically creates every pairwise composition.
It then reruns the deterministic Reasoning Foundation and tests whether the
parent decision value and action identity remain unchanged.

The first real v2 batch evaluated 70 complete probe sessions: 26 atomic probes
and 44 generated pairwise compositions. All 70 retained the parent decision.
Zero matched probes became positive training examples, zero negative receipts
were created, and no repair proposal was invented. This is evidence that the
declared transformations and their current pairwise combinations are stable on
the current six-parent corpus. It is not evidence of general reasoning or
open-ended self-improvement.

## What worked and what did not

What worked:

- the typed receipt shape still decides which atomic operators apply; there is
  no lesson-ID switch;
- pairwise probe definitions are generated, not enumerated as 21 separate
  operator cases;
- operator order and composition lineage are explicit in every result;
- every probe preserves a full hash-bound Reasoning Foundation session with
  machine state, human rendering, decision, Principle trace, and independent
  Seam Cell audit;
- automatic runtime practice and the Learning Shell both reused the same
  immutable batch and current reasoning cycle;
- confirmed invariants remained evaluation-only and did not inflate the
  training corpus.

What is not yet proven or implemented:

- the seven atomic operator definitions remain hard-coded;
- Mirror cannot invent an arbitrary safe new transform;
- composition is pairwise only and recursive composition beyond depth two is
  refused;
- the actual corpus produced no mismatch, so genuine repair learning is still
  unproven;
- all six real receipts are positive and correlated, with two successive
  versions of one Publish lesson.

## Why the v2 organ change was earned

Metamorphic v1 removed the need to add lesson-specific robustness cases, but it
still required a human to add every interaction between valid operators. That
left a concrete growth seam: Mirror could verify atomic irrelevance but could
not automatically ask whether two individually irrelevant changes interact.

The new organ is intentionally small. It supplies a deterministic composition
rule over already admitted operators, a depth limit, complete lineage, and the
existing negative-evidence route. It does not generate code, add an operator to
itself, grant permissions, grade its own repair, install an organ, or promote a
runtime model.

- atomic selection: typed receipt shape;
- generated selection: every unordered pair of applicable atomic operators;
- maximum composition depth: 2;
- learned weights in generation or evaluation: refused;
- expected relation: decision value and action ID remain invariant;
- matched result: immutable evaluation trace only, no training receipt;
- mismatched result: negative `SYNTHETIC_COUNTEREXAMPLE` receipt with no
  success prototype, plus an evidence-linked Frontier assessment;
- repeated independently sourced mismatch: may open a typed repair-operator
  exam candidate marked `FRONTIER_EXAM_REQUIRED` and
  `NOT_SUBMITTED_EVIDENCE_ONLY`;
- recursive composition, code generation, installation, promotion, tools,
  world action, canon, identity, and permission authority: none.

The admitted atomic vocabulary remains:

1. reword human-facing rendering;
2. add attributed decision-irrelevant tested evidence;
3. add an explicitly non-blocking unrelated unknown;
4. add a permission no candidate requires;
5. reverse evidence order when multiple items exist;
6. reverse candidate and path-profile order when multiple paths exist;
7. reverse constraint order when multiple constraints exist.
