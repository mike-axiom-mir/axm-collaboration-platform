## Why this increment exists

Reasoning Memory Context v1 made verified experience retrievable, but it remained
advisory and could not affect a Reasoning Foundation choice. That was an honest
first boundary, not the requested end state. For Mirror to learn from preserved
experience, the Foundation needed one tested way to use memory while keeping
truth, evidence, permissions, prohibitions, and eligibility outside memory's
authority.

The narrow integration point is path ordering after deterministic eligibility.
This lets past verified outcomes influence a choice without letting popularity,
fluent narrative, or a remembered success make an unsafe path possible.

## What was built

`Reasoning Memory Guidance Organ v1` maps a fixed set of structural strategy
tags to exact typed features and requests bounded context from Reasoning Memory
Context v1. It creates one sealed guidance record for the complete candidate
set. Every comparison row preserves its guidance state, adjustment, evidence
sufficiency, and guidance identity.

The adjustment policy is hardcoded and inspectable:

- deterministic evidence, permission, prohibition, and eligibility gates run
  first;
- memory may add at most `+12` or `-12` to an already eligible path;
- a nonzero adjustment requires at least two distinct source groups and two
  evaluator IDs;
- supporting verified non-synthetic experience may add `+12`;
- recurrent counterevidence may subtract `-12`;
- contradictory, mixed, synthetic-only, insufficiently independent, or absent
  context receives zero adjustment; and
- memory cannot supply missing evidence or permission, erase a prohibition, or
  make an ineligible path selectable.

The independent Seam Cell now reconstructs and verifies the guidance digest,
policy, comparison-row binding, sufficiency state, and closed authority. The
experience organ refuses every `PRIVATE_*` Foundation session so a private
memory-influenced choice cannot automatically become its own training proof.

The runtime server has no `reasoningMemory` request field or route. The
Foundation module now imports the guidance code, so the earlier statement that
the memory context organ was not imported by runtime code is superseded. Code
reachability is not activation: the server never supplies the private option,
and the active process was not restarted during this work.

## Known limits

- The exam pack is locally authored and is not outside-independent evidence.
- The two improvements use contract-derived receipts, not independently
  observed real-world outcomes.
- The current real-local opportunity has two source groups but only one
  evaluator, so memory correctly remains neutral there.
- Fixed exact tag-to-feature mappings cover a small known strategy vocabulary;
  this is not semantic language understanding or autonomous concept discovery.
- A fixed `12`-point adjustment is an instrument boundary, not calibrated
  confidence or probability.
- Counterevidence and contradiction behavior are strongly covered by fixtures,
  but no independently recurrent real-local contradictory pair exists yet.
- The server does not activate memory guidance, and runtime safety under such
  activation is untested.
- Mirror still has no general learned language organ and is not a general AI.
