# AXM Hub naming map

As of 2026-07-23:

- `hub/` is the authoritative Workshop Hub shell and module browser.
- `tools/main-hub/` is a declared `SHELL` compatibility scaffold, not the authoritative Hub.
- `tools/prehub/` is the original local notes/save compatibility workspace, now classified as a product tool.
- `tools/hub-test-room/` is a test surface for Hub integration behavior.
- `tools/source-connector-hub/` is a bounded official-data connector product; “hub” describes its source-aggregation role, not Workshop navigation ownership.

These names should not be consolidated by path alone. Retirement or folding requires an explicit compatibility and saved-state decision.
