# AXM Public Project Map

AXM is a growing set of local-first games, creation tools, deterministic systems, and human–AI collaboration experiments.

This index is a navigation map, not a claim that every repository is finished or production-ready. Each project keeps its own evidence, limitations, branch state, and merge status. Private repositories and private continuity are intentionally excluded.

## Shared public boundary

- Experimental means experimental. A repository being public does not make an unmerged branch CANON.
- Measured evidence stays separate from proposals and long-term direction.
- Private state, personal experience, secrets, local saves, and private continuity do not belong in public exports.
- Apache-2.0 applies where the repository includes that license; repositories without an explicit license grant no automatic reuse rights.
- Human review remains the merge boundary.
