# AXM Public Project Map

**Human-readable checkpoint — audited 2026-09-13.**

This page is a fast orientation map for the public repositories owned by `mike-axiom-mir`. It is deliberately shorter than the individual READMEs so a person can see what exists, what stage it is in, and whether a packaged GitHub prerelease exists without having to inspect dozens of repositories at machine speed.

## How to read this map

- **Public** means the repository was public at this checkpoint. It does not mean finished, CANON, safe for every use, or production-ready.
- **Stage** is a compact summary of the repository's own current/default-branch truth boundary. The repository README remains the detailed source of truth.
- **GitHub prerelease** means an actual GitHub Release object marked prerelease, not merely an experimental `main` branch.
- AXM-owned source in the public repositories is licensed under **Apache License 2.0** at this checkpoint. Third-party code, assets, runtimes, models, data, fonts, media, and other imported material keep their own upstream terms and notices; Apache-2.0 does not silently relicense them.
- A repository being listed here grants no automatic install, execution, merge, CANON, scientific, professional, identity, or device authority.

## Release truth at this checkpoint

Only two public repositories currently expose an actual GitHub prerelease:

1. **AXM Workshop** — `v0.7.0-experimental`.
2. **AXM Local Game Hub** — `v0.1.0-proof-of-start`.

Both repositories have continued to evolve on `main` after those tagged package checkpoints. The release tags therefore mean **reviewed/packageable historical checkpoints**, not “identical to the current branch head.” Their individual READMEs preserve that distinction.

The other public repositories currently use their default-branch README, tests, evidence files, action reports, and source history as the public experimental/pre-release surface. A missing GitHub Release object is not silently described here as a packaged prerelease.

## License boundary

The public AXM repository set was checked for a top-level Apache-2.0 license at this checkpoint. Repositories that already carried Apache-2.0 were left intact; newer public repositories missing a top-level license received the canonical Apache License 2.0 text.

That project-level grant covers AXM-owned source only. Preserve every repository's `NOTICE`, `THIRD_PARTY`, provenance, donor, vendored-license, model/data license, asset attribution, and other more-specific upstream terms when they exist.

## Why this map exists

Machines can scan dozens of repositories quickly; humans should not need to. This map is a navigation layer, not a replacement for evidence. Open the repository you care about, read its first-stage/status section, then follow its own start, verification, limits, and provenance files before using it.
