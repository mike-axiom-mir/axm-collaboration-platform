# Mirror Foundation-development evidence-hand planner action report

Status: TEST machine-readable need to nonbuilt hand interface, not CANON.

## Purpose

The Foundation frontier router could preserve every measured hold or regression
as a request, but its human-readable statement was not a safe basis for deciding
what kind of hand might collect the missing evidence. Routing from a dimension
name or prose would turn language into hidden decision authority and require a
new hard-coded branch for each future dimension.

The observatory now attaches a bounded machine-readable `developmentNeed` to
every newly measured non-passing dimension. The generic hand planner consumes
only its typed `acquisitionMode` and maps it to one reusable interface family:

- `EXTERNAL_PERMISSIONED_SUBMISSION` →
  `PERMISSIONED_EXTERNAL_EVIDENCE_INTAKE_HAND`;
- `PASSIVE_LOCAL_OBSERVATION` →
  `NON_INDUCING_LOCAL_EVENT_OBSERVATION_HAND`; and
- `INDEPENDENT_BOUNDED_EXAM` →
  `INDEPENDENT_REGRESSION_EXAM_HAND`.

The planner source contains no current dimension IDs. A legacy or incomplete
frontier request without a typed need holds instead of inferring from prose.

## Operational result

The real content-addressed batch
`foundation-development-hands-79f691cb9f67d40ba828a193` binds frontier batch
`foundation-development-frontier-90182f776b69bdf7db316321` and contains two
reviewable, nonbuilt interface requests:

1. `foundation-evidence-hand-cd7deb916c3f332334776443` requests a
   permissioned external evidence-intake interface for the outside-authored,
   sealed language exam need.
2. `foundation-evidence-hand-6bcacd772d6bb4b8be363ba4` requests a
   non-inducing local event-observer interface for a naturally occurring,
   verified real-local negative reasoning episode.

The passive hand explicitly forbids inducing, scheduling, or manufacturing a
failure to fill the evidence gate. The external hand preserves authorship as a
declaration Mirror cannot certify. Both leave capability matching
`NOT_SEARCHED`, new-organ need `UNASSESSED`, and implementation
`NOT_BUILT_OR_SELECTED`.

## Falsification

Five focused planner tests passed:

1. renaming both dimensions and replacing their statements with hostile prose
   decoys preserved the same two hand families, while a valid evidence kind
   paired with the wrong valid acquisition mode was refused;
2. an all-observed frontier produced an explicit empty hand batch;
3. a same-source regression produced an independent regression-exam hand and
   preserved the `foundationCanaries` evidence delta;
4. a missing typed need held without prose inference, and committed tampering
   was refused without erasure; and
5. policy, contracts, commands, Workshop integration, and active-runtime
   exclusion are explicit.

The complete Foundation feedback chain passed 33/33 focused checks. The whole
integrated Mirror regression surface passed 186/186, including the live settled
Workshop check. A second real observation execution returned
`NO_NEW_OBSERVATION_REQUIRED` and wrote no duplicate request, snapshot,
execution receipt, frontier, or hand batch.

## Authority and limits

The planner may write only ignored private content-addressed proposal traces.
It has zero evidence-acquisition, event-induction, priority-selection,
capability-claim, organ-need-claim, implementation-build, repair-selection,
training, model-change, permission-grant, runtime-promotion, canon-change, or
world-action authority.

This advances Mirror from “a named gap exists” to “the missing evidence has a
typed reusable hand interface” without asserting that such a hand must be new.
The next honest seam is an independent compatibility survey over existing
capabilities. Until that occurs, neither hand proves a missing organ, and no
implementation is justified.
