VERDICT

Agent Tool Forge is a usable draft-only software foundry rather than a display
card. It creates a bounded draft, validates it, renders a complete file set,
calculates deterministic SHA-256 fingerprints, previews generated files,
saves/resumes locally, and exports an actual module ZIP or review JSON.

It cannot install, overwrite, execute, delete, promote, or canonize. Those remain
later governed steps.

FACTORY ARCHITECTURE

Human Hub screen -> index.html -> forge-core.js
Machine host adapter -> machine.js -> forge-core.js

Both doors use the same normalized draft, validation, render, and fingerprint
logic. The machine adapter requires a host-supplied authorization decision and
refuses unknown actions, including install.

PACKAGE TYPES

- Foundation tool
- Hub module
- Dual-door tool
- Proposal-only analyzer
- Machine-only capability

Every generated manifest starts EXPERIMENTAL. Risk is a separate LOW / MEDIUM /
HIGH field.
