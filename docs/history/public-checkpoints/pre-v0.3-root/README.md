# Pre-v0.3 public checkpoint records

These manifests, verification reports, sanitization notes, and patch cards
belong to public checkpoints that predate the v0.3.0 experimental release.

They remain available for provenance and historical review, but they are not
the current launch instructions or release truth. Begin with the repository
[`README.md`](../../../../README.md), [`STATUS.md`](../../../../STATUS.md),
and [v0.3.0 release notes](../../../releases/v0.3.0-experimental.md).
