OBSERVED SEAM
-------------
A person downloaded or browsed the GitHub repository, clicked the expected
"Run AXM All" route, and saw source code instead of a running Hub. GitHub
previews .bat/.cmd files as source and cannot start a local server from its web
page. Running a script from inside a ZIP is also an unreliable beginner route.

REPAIR
------
- Added OPEN_AXM_WORKSHOP.cmd as the obvious Windows beginner front door.
- Added RUN_AXM_ALL.bat as a compatibility name.
- Added a root README with Download ZIP -> Extract All -> Open instructions.
- Added explicit in-ZIP/missing-folder and missing-Node explanations.
- Made the launcher prefer a future bundled runtime at
  runtime\node\node.exe, then fall back to an installed Node.js runtime.
- Kept optional AI and specialist services in the advanced launcher rather
  than starting them silently for beginners.
- Replaced shell-built Windows browser opening with explorer.exe argument
  passing.
- Added a launcher contract self-test and wired it into Workshop tests and
  public-package restore maintenance.
