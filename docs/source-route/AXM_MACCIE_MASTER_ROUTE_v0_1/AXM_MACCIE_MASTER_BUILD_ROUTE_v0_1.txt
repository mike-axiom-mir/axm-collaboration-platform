==============================================================================
PURPOSE
==============================================================================
Build an AXM-native local machine intelligence from inspectable principles, state, search, world
learning, memory, verification, and eventually native trained weights—then connect it to the AXM
Workshop beside Nova/Gemini without requiring any outside model at runtime. The route deliberately
creates a useful local body early and lets learned organs replace or strengthen deterministic parts
only after they pass the same evidence gates.

THE CORE BET
------------------------------------------------------------------------------
Observed reality updates an explicit world model. Stable, versioned principles govern how knowledge
becomes action. Learned components propose, predict, rank, compress, and translate; they never
silently become authority.

ARCHITECTURE
------------------------------------------------------------------------------
AXM WORKSHOP :8788  (unchanged Foundation)
        |
        | selected context / presence / gated proposals
        v
WORKSHOP MACCIE ADAPTER
        |
        | local authenticated native contract
        v
MACCIE RUNTIME :${AXM_MACCIE_PORT:-8798}
  ├─ API + session boundary
  ├─ Root bundle + permission policy
  ├─ Typed state / evidence / claim graph
  ├─ Principle Cell and ternary gate
  ├─ Candidate generation + search
  ├─ Exact simulators where available
  ├─ Learned organs (advisory, replaceable)
  ├─ Verifier + Seam-Finder
  ├─ Explicit memory stack
  ├─ Language shell / vision adapters
  ├─ Tool proposal client
  └─ Append-only traces and Action Reports

Authority order:
  real observation / authorized tool result
      > deterministic invariant or verified rule
      > sourced human assertion within its scope
      > calibrated learned prediction
      > unsourced proposal

Hard roots and permissions are never gradient-mutable.
Learned components may propose, rank, predict, compress, and translate.
They do not silently authorize, canonize, rewrite roots, or declare completion.

MILESTONES
------------------------------------------------------------------------------
M0 — Research body exists
  Repository, roots, route, source trace, runtime skeleton.
M1 — Connectable kernel
  Maccie appears locally in the Workshop and returns deterministic structured traces with no write power.
M2 — Principle Cell
  Bounded worlds prove observe → candidates → consequences → +1/0/-1 → test → repair.
M3 — First native weights
  A from-random-initialization learned organ improves a held-out metric under the deterministic kernel.
M4 — Learned world model
  Maccie predicts consequences and improves bounded planning without bypassing verification.
M5 — Native structured planner
  A native sequence model produces verified plans and tool structures.
M6 — Native language shell
  A from-scratch language component translates between human text and structured Maccie state.
M7 — Local Collaborator v0.1
  Offline native-only package can be selected beside Nova/Gemini and complete bounded gated tasks.
M8+ — Living research forest
  Scale, multimodality, community compute, and broader transfer remain separate evidence-gated routes.

NON-NEGOTIABLE ARCHITECTURE DECISIONS
------------------------------------------------------------------------------
D01. Do not wait for a large language model before integrating. Connect the deterministic kernel early.
D02. Do not call the deterministic kernel a learned model. The first native weights arrive later and are labeled separately.
D03. Do not put Maccie inside Workshop `server.js`; run it as a bounded local sidecar.
D04. Do not reuse port 8792; the current Foundation already routes game 002 there.
D05. Do not make an OpenAI-compatible endpoint the native mind. It is only one optional compatibility skin.
D06. Do not require Ollama, LM Studio, llama.cpp, Nova, Gemini, Claude, or ChatGPT at runtime.
D07. Do not reject transformers as a component on principle. Test architectures; keep language prediction subordinate to the reasoning/governance body.
D08. Do not let one probability collapse erase evidence, alternatives, uncertainty, or principle vectors.
D09. Do not train roots into weights and hope they remain stable. Keep roots executable, versioned, and outside gradient updates.
D10. Do not train on scraped mystery data. Every sample needs lineage, rights/consent status, and a removal path.
D11. Do not optimize only for task reward. Advancement requires integrity and wisdom metrics not to regress.
D12. Do not pretend operational traces fully explain neural weights. Trace recorded inputs, modules, candidates, rules, and outcomes honestly.
D13. Do not scale by parameter count alone. Each rung must demonstrate a distinct useful capability.
D14. Do not make Maccie mandatory. AXM remains usable without AI and without the native model.

- SentencePiece and byte-level tokenization work: Candidates for a from-scratch language encoding experiment.
- nanoGPT / clean-room small-model training examples: Educational baseline proving that a language model pipeline can be trained from random initialization.
- OLMo fully open model programme: Reference standard for exposing data, code, weights, recipes, checkpoints, and reports.
- SPDX AI and dataset profiles: Reference for machine-readable provenance, license, integrity, model, and dataset metadata.

==============================================================================
KNOWN LIMITS OF THIS ROUTE
==============================================================================
- This route does not prove that broad machine wisdom or general intelligence is achievable.
- It does show a technically coherent path to a native local reasoning runtime and progressively learned model components.
- No training run, model checkpoint, API service, or Workshop adapter was built in this planning pass.
- Hardware feasibility for larger rungs must be measured on the actual machines; no fake duration or cost is asserted.
- A custom hybrid Maccie architecture may not be loadable directly by Ollama, LM Studio, or llama.cpp. The native local service is therefore the stable integration point.
- Formal rules can be wrong; roots and constraints still require explicit human governance and evidence-based amendment.
- Operational traces explain recorded computation and decisions, not every causal property hidden inside learned weights.
- Passing bounded worlds is not evidence of safe general deployment.
- The public Foundation remains read-only in this route; all early work belongs in the separate local project.
