Status: `TEST`

## Requested outcome

Wire the installed 1,000-entry Code Recipe Foundry catalog into the
provider-neutral Code Capability Fabric without confusing this work with Code
Mirror or RepairBuddy.

## Bounded rung

Add exact recipe-selection request and packet contracts. Bind one validated
packet into semantic request, candidate, and Review Card lineage. Preserve the
catalog's structural holds, parse-only evidence ceiling, and unresolved source
and license claims. Do not apply snippet text to generated source in v1.

## Lane

Twelve implementation paths under `shared/code-capability-fabric/` plus this
append-only steward-run directory. Code Recipe Foundry catalog bytes, Mirror,
RepairBuddy, Foundation, registries, executors, and the canonical checkout are
unchanged.

## Explicit non-goals

- automatic recipe ranking or selection;
- authenticated-human-selection claim;
- source or license verification;
- snippet composition, copying into output, loading, or execution;
- provider, Mirror, RepairBuddy, sandbox, or candidate execution;
- installation, integration, learning, promotion, or `CANON`.

Mike remains the final merge gate.
