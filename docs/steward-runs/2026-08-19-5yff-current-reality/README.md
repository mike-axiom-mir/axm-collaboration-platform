repair, the closure set reports `HELD` with one `MISSING`, two `CHANGED` and one
unchanged `CURRENT` source. The repair does not restore bytes or grant action;
it prevents later proof from silently relying on absent or changed output.

The research proposal's separate output-bundle adapter is unnecessary on this
baseline. Its useful negative fixture was retained in the current self-test.

### 2. Ancestry continuity — PARTIAL, no duplicate walker imported

Git proves repository ancestry. Module Evolution Ledger already proves immutable

Comparator proves exact two-bundle differences without choosing a winner.

What remains partial is one portable baseline identity across arbitrary
software, Mirror and specialist masks. The later simulation-lab branch should
provide adapters around the shared acceptance contract rather than importing
Steward 4's lineage walker as another authority.

The proposed 10-signal comparison with and without reversible links was not run
with a human. Review time, reference mistakes, dissent preservation,
