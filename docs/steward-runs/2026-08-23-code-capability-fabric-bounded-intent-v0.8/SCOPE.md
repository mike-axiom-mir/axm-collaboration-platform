## Requested outcome

Advance the Fabric toward creating arbitrary software, games, entertainment,
systems, and future hardware while keeping every step bounded, inspectable, and
unable to grant itself authority.

## Bounded rung

Implement one deterministic, provider-neutral compiler from a human-authored
typed artifact graph to an inert cross-domain creation program. Reuse Fabric v2
route plans, deterministic JSON, the Hand Specification Foundry, Review Inbox
handoffs, and existing consent tiers. Unsupported capabilities must become
typed hand contracts instead of fake universal support.

## Lane

Lane-owned paths are additive files under `shared/code-capability-fabric/` plus
the existing Fabric README and this steward-run receipt. No registry, Foundation,
canonical checkout, provider, executor, runtime, candidate, or target artifact
is modified or run.

## Explicit non-goals

- natural-language semantic understanding;
- automatic capability inference;
- provider invocation or candidate generation;
- workspace or source inspection;
- sandbox, verifier, game, media, or hardware execution;
- authenticated human decision;
- automatic hand implementation;
- permission, network, learning, install, integration, publication, model
  training, physical actuation, promotion, or `CANON` authority.
