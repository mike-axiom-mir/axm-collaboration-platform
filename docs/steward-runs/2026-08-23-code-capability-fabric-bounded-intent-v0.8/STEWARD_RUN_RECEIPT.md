## Outcome

Code Capability Fabric can now compile one human-authored typed graph of
artifacts, dependencies, capability contracts, existing Fabric route plans,
acceptance claims, settings, rights, resources, privacy, and root evidence into
one deterministic cross-domain creation program.

The example proof spans a game module, animated guide, and vendor-neutral
hardware simulation packet. Domains are portable identifiers rather than a
closed catalog. Unsupported or imagined domains emit Foundry-compatible typed
gaps; they never fall back to a universal executor or pretend the hand exists.

The best result is `READY_FOR_DETACHED_CANDIDATE_REQUEST`, which is only the next
request gate. Evidence stays `UNKNOWN` and `NOT_RUN`. Consequence and lifecycle
scope expose new consent tiers. Taste remains a human seat.
