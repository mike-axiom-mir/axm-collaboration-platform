# Capability decision

The required bounded discovery capability is `READY` at the focused-test
surface. The generic gap comparator reports the whole inventory as `DEGRADED`
because optional automatic semantic selection is unavailable and proposes a
future hand-contract shape.

That optional proposal is deliberately not implemented or accepted here.
Automatic choice would collapse mechanical discovery, human meaning, and
exact selection into one authority-bearing step. The v1.1 adapter therefore
ends at evidence with `selection: null`; any use requires a separate exact
selection request and later consent gates.
