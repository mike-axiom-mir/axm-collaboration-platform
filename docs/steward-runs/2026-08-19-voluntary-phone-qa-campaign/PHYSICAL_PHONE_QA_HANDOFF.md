A ChatGPT mobile remote-control connection is useful for managing the PC, but it does not by itself count as a game controller, shared-screen action, disconnect/recovery observation, or physical-phone QA proof. Use the actual game phone/controller route for each selected game.

1. Start the selected game through its normal trusted Workshop route.
2. Open the QA Lab and choose the same verifier-listed game.
3. Join from a separate physical phone through the game's intended controller route.
4. Observe the six checklist items; leave any unobserved item unchecked.
5. Capture a candidate receipt and stop whenever desired.
6. Review the candidate separately. Acceptance does not clear the verifier warning.
