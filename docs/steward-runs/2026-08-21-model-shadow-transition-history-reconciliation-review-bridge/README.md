# Model Shadow transition-history reconciliation review bridge v4.0 evidence

Status: `TEST` · branch material only · merge and `CANON` gate: Mike Tobi / AXM

This folder binds the bounded v4.0 advance from a machine-oriented v3.9
complete-history divergence receipt to a minimized exact-digest reconciliation
review request and a fail-closed human-readable Review Inbox view.

The bridge exact-rebuilds the caller's v3.9 package against both explicit v3.7
roots. Only `COMPLETE_HISTORY_DIVERGES` is admitted. The artifact retains both
complete-history commitment references, both snapshot references and counts,
the common normalized prefix length, and the earliest divergent event. It omits
the complete v3.9 receipt, complete histories, configured paths, raw records,
model output, and private context.

The request declares the existing Review Inbox route and explicit-submit header
but does not invoke it. A task-owned synthetic ReviewService proves only shape
compatibility and exact reload, then removes its temporary state. It does not
prove a live host submission, durability, authenticated identity, review, human
participation, reconciliation, or resolution.

The browser view independently recomputes the v4.0 artifact's canonical SHA-256
with Web Crypto and binds it to the Review Inbox item digest before enabling the
vote control. Malformed, oversized, mismatched, or authority-inflated artifacts
stay on an integrity hold. Raw exact-item JSON remains visible. The existing
v2.9 typed held-audit view and generic review path remain separate and pass
regression checks.
