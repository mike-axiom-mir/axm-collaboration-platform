# Human handoff evidence routes

## Native source declaration

- Claim: a local-steward source declaration has a native, digest-bound builder
  and verifier.
- Kind: static structure plus deterministic behavior.
- Risk: medium.
- Pass condition: exact protocol, session, evaluation, judgment, scope, and
  pseudonymous judge references rebuild byte-for-byte; attestation, mode, or
  source changes fail verification.
- Primary surface: `grounded-growth-human-handoff.js` focused execution.
- Counterevidence: a changed declaration verifies, a synthetic declaration is
  usable as LIVE trust, or the declaration claims identity authentication.
- Observed: PASS in the 45-check focused suite.
- Verdict: `PASS` for the contract; LIVE use remains `NOT_RUN`.

## Staged judgment boundary

- Claim: evaluation does not silently become a human judgment.
- Kind: deterministic behavior and authorization boundary.
- Risk: high.
- Pass condition: evaluation is deterministic, judgment remains a separate
  explicit input, and the interactive driver requires a local TTY and a
  declaration before building a package.
- Primary surface: native Human Benefit verification plus child-process refusal
  check.
- Counterevidence: signal selects the judgment, piped input proceeds, or
  stopping creates a judgment.
- Observed: focused package truth binds `judgmentDerivedFromSignal: false`; the
  non-TTY child process exits 1 before touching the supplied path.
- Verdict: `PASS` for the technical boundary; human entry is `NOT_RUN`.

## Candidate and reuse-existing composition

- Claim: the same handoff composes both exact ancestry modes without inventing
  a candidate.
- Kind: deterministic behavior.
- Risk: high.
- Pass condition: candidate and reuse packages rebuild exactly, a cross-mode
  intervention link fails, and closure covers the exact ancestry surface.
- Primary surface: handoff focused suite.
- Secondary surface: all four exact current selectors and v2 links rebuild.
- Counterevidence: a reused surface is relabeled candidate or one route accepts
  another route's session, declaration, or link.
- Observed: PASS for two synthetic contract modes and 4/4 current selectors.
- Verdict: `PASS` for composition readiness.

## Human source and benefit

- Claim: a person participated, was authenticated, or benefited.
- Kind: human-native observation and judgment.
- Risk: high.
- Pass condition: external voluntary LIVE session evidence, explicit judgment,
  declared source trust, exact current closure, and an admitted bridge package.
- Primary surface: human-native receipts plus external source authentication as
  appropriate.
- Counterevidence: no opt-in, synthetic fixture, withdrawal, held closure, or
  unauthenticated source treated as authenticated.
- Observed: no human participation and no persisted LIVE receipt or package.
- Verdict: `NOT_RUN`; source authentication is external and unclaimed.
