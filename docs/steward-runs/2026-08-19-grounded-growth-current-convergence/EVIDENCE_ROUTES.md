# Evidence routes

## `current-state-compose`

- Claim: the newest technical portfolio and the earlier voluntary-human
  participation frontier can be represented together without rewriting either.
- Kind: deterministic behavior and static structure.
- Risk: medium.
- Pass condition: both sources verify natively, the participation portfolio is
  an exact ordered prefix of the latest portfolio, and the derived receipt
  rebuilds byte-for-byte.
- Primary surface: focused execution with adversarial fixtures.
- Counterevidence: missing, reordered, rewritten, or invalid source receipts.
- Secondary surface: exact source references plus required repository checks.

## `participation-preserve-or-hold`

- Claim: optional human readiness remains reviewable only when later outcomes
  leave its protected capability chain unchanged.
- Kind: authorization and workflow outcome.
- Risk: high because it touches consent semantics.
- Pass condition: an unrelated appended outcome preserves the review candidate;
  a protected capability advance is detected as requiring rebind; no action or
  participation is started.
- Primary surface: deterministic allow/hold assertions.
- Counterevidence: stale handoff presented as current, review counted as
  participation, or autonomous action count above zero.
- Secondary surface: contract inspection and exact receipt rebuild.

## `human-benefit-current-state`

- Claim: a person benefited from the current portfolio.
- Kind: workflow outcome and human meaning.
- Risk: high.
- Pass condition: separately admitted, voluntary, human-native evidence on the
  declared claim scope.
- Primary surface: human observation or judgment through the existing bridge.
- Observed evidence: none in this increment.
- Verdict: `UNKNOWN` / `NOT_RUN`.
- Named seam: `HUMAN_BENEFIT_NATIVE_EVIDENCE`.
