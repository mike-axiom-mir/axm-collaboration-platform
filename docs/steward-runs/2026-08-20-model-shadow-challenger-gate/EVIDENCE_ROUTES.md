# Evidence routes

| Claim | Native evidence | Verdict | Does not prove |
|---|---|---:|---|
| Model-shadow input is exact | Native observation rebuild from embedded snapshots and receipt fields | PASS | Model correctness or provider identity beyond caller disclosure |
| Only ordinary drift becomes a plan | Focused routes for match, invalid context, critical authority drift, same artifact, and ordinary drift | PASS | Semantic desirability of the drift |
| Existing direction is reused | Native Challenger Lab plan verification binds the exact Direction Handoff digest | PASS | Direction acceptance or execution |
| Held-out evidence remains mandatory | Native Challenger Lab manifest validation | PASS | That any case was executed |
| Plan reaches Review Inbox | Temporary sender projection plus Review Inbox item with the same plan digest | PASS | Real human participation or application |
| Declared human seat is required | Approved synthetic Review Inbox fixture plus machine-only refusal | PASS | Actor authentication |
| Review grants no execution | Proposal and reviewed handoff truth fields plus tamper checks | PASS | Safety of a future authorized execution |
| Raw/private/review narrative is not retained | Output inspection and absence checks for actor identity and vote note | PASS | Absence from caller-owned source systems |
| Proposal and handoff integrity | Exact rebuild and tamper tests | PASS | Persistence after an external consumer stores them |
| Actual human review | No native human observation gathered | `NOT_RUN` | Human judgment |
| Shadow execution and challenger evaluation | No provider or experiment execution performed | `NOT_RUN` | AI-workflow improvement, regression, or learning |
| Held-out human benefit | No voluntary human-native outcome gathered | `NOT_RUN` | Shared growth |

Authorization is high-risk evidence. The focused suite checks both the allowed
synthetic route and denied digest, state, machine-only, conflict, and tamper
routes. Consequential execution remains a separate absent authority surface.
