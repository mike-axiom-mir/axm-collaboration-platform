# AXM Mirror definitions

**Mirror Runtime** is the complete stoppable local body: API, kernel, state,
memory, adapters, learned organs, tests, and traces.

**Mirror Kernel** is deterministic reasoning/governance code that runs with no
learned weights.

**Mirror Model** is a parameterized component trained from random
initialization under AXM-controlled code and recorded data lineage.

**Native** means no outside model or third-party AI API is required at runtime.
Infrastructure libraries are not inherited model intelligence.

**Machine-native reasoning** means the authoritative reasoning record is typed
state and evidence rather than prose: observations, relations, claims,
unknowns, conflicts, constraints, candidates, predicted consequences,
permissions, decisions, tests, and repairs.

**Human collaboration surface** means humans can teach, question, disagree,
verify, and operate tools through clear language and visuals rendered from that
same authoritative state. Machine-native does not mean machine-only.

**Principle** is a versioned executable constraint or evaluator with an
explicit amendment path outside gradient learning.

**Wisdom** is operationally evaluated as truthfulness, uncertainty awareness,
consequence depth, restraint, consent, reversibility, repairability, and
long-horizon value. Seed-0 does not reduce these to one mystical score.

**Decision +1** means supported enough to proceed within explicit bounds.

**Decision 0** means hold, ask, observe, test, or preserve an unresolved
conflict.

**Decision -1** means contradicted, unauthorized, impossible, or beyond an
accepted risk boundary.
