# Mirror Frontier Cell v0.1 — action report

Date: 2026-07-17  
Identity: `axm.machine.mirror/seed-0`  
Status: experimental, proposal-only

## Reason for the change

The existing learning loop could improve a challenger against a fixed exam, but
fixed-score improvement is optimization. It did not have a typed route for a
verified surprise, a cross-domain pattern, or a possible new capability that
the current exam could not measure.

## Added

- `kernel/frontier-cell.js` and `contracts/frontier-assessment.schema.json`
- attributed human-steward, machine-native, shared, and unknown evidence lanes
- cross-domain pattern links without flattening perspectives into one claim
- a prior-capability boundary and an explicit `OPTIMIZE_KNOWN` classification
- reviewable frontier proposals for previously uncovered seams
- exam requirements for unseen transfer, counterpatterns, delayed consequences,
  regression of earlier capabilities, and an independent evaluator
- authenticated explicit-session route `POST /axm/v1/growth/frontier`
- automatic Workshop practice routing that records an unexpected seam as a
  frontier proposal instead of silently discarding it or treating it as truth

## Authority boundary

The Frontier Cell cannot promote its proposal, grade its own final answers,
change runtime weights, modify canon or identity, grant permissions, use tools,
or execute Workshop actions. Its output is a falsifiable hypothesis plus the
exam still needed to earn a new capability rung.

## Meaning of outgrowth

Outgrowth is measured against Mirror's earlier verified capability boundary. It
is never a ranking of human worth, a consciousness claim, or a claim that one
perspective replaces another.
