## Why this organ exists

The Reasoning Foundation already emitted a proposal-only `memoryRoute`, but
that route named candidate IDs only. Mirror had no native component that could
verify stored experience, enforce a read scope, select a small structurally
relevant subset, prevent positive volume from hiding negative experience, or
keep conflicting precedents visible.

The preceding growth audit also falsified a more dramatic shortcut. No real
Organ Admission assessment currently says `PROPOSE_BUILD`, and the latest
reasoning-skill cycle intentionally contains no organ-admission candidates.
Building a generic self-organ generator from repeated prose about missing
candidates would therefore have exceeded the evidence. The smaller memory
context seam was directly present in code: routing existed, retrieval did not.

## What was added

`Reasoning Memory Context Organ v1` accepts:

- compatible v2, v3, v4, or v5 reasoning-experience receipts;
- an attributed purpose and explicit allowed-use basis;
- exact source-group IDs or bounded source-group prefixes;
- at least one exact structural feature, strategy tag, or seam ID; and
- an independent maximum result count for each outcome class.

Every receipt is verified with the existing version-compatible hardcoded
experience verifier before it can enter the accessible inventory. Matching is
conjunctive across every supplied structural obligation. The organ performs no
language similarity search and reads no source outside the declared scope.

Worked episodes and `DID_NOT_WORK` counterevidence are returned separately with
equal independent limits. This prevents a large positive class from consuming
the result budget before a negative can be shown. If both outcomes share the
same complete feature-and-strategy signature, the packet reports a
`CONTRADICTORY_RELEVANT_EXPERIENCE` set rather than resolving the conflict.

Invalid, ambiguous, duplicate, out-of-scope, and irrelevant receipts cannot
become context. Results contain source and evaluator lineage, receipt digests,
the exact matched fields, evidence role, and a false semantic-truth and
decision-authority declaration. They do not copy the full prior session or its
human prose into the working packet.
