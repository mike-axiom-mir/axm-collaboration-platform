# Mirror Foundation capability-affordance exam planner action report

Status: TEST independent exam planning, not CANON.

## Purpose

The declared-capability survey found exact implementation declarations for both
current evidence hands, but declaration compatibility is not operational fit.
The affordance-exam planner converts every exact hand/witness pair into its own
machine-readable independent exam request before Mirror may reuse an existing
capability or justify a new hard-coded organ.

The planner does not use dimension names, fluent descriptions, declaration
order, or frequency as exam authority. Case families come only from the hand's
machine capability tokens and typed input, output, permission, independence,
event-induction, recovery, source-hash, and closed-authority boundaries.

## Falsification

Five focused tests passed:

1. every exact hand/witness pair produced one separate unexecuted request;
2. reversed declaration order and multiple witnesses produced multiple exams,
   never a first or most-frequent selection;
3. fluent prose changes produced no case change, while one unseen machine token
   automatically produced one new required case without planner code;
4. committed batch tampering was refused without erasing the evidence; and
5. no-witness, empty, policy-disabled, contract, command-hook, Workshop, and
   active-runtime boundaries stayed explicit.

The complete Foundation chain passed 33/33 focused checks. The full integrated
Mirror regression surface passed 186/186, including the live settled-Workshop
check.

## Authority and limits

The planner writes only ignored private content-addressed proposal traces. It
has zero fixture-authoring, expected-result-authoring, source-execution,
capability-selection, operational-fit, new-organ-need, implementation-build,
evidence-acquisition, event-induction, training, permission, runtime, canon, or
world authority.

The next honest seam is independent fixture and predicate admission plus a
sandboxed adapter for these requests. Until independently authored cases are
executed and measured, Mirror cannot conclude that either existing capability
fits, fails, or needs replacement.
