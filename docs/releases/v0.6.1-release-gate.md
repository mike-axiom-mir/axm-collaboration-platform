# AXM v0.6.1 Experimental Release Gate

Status: **candidate until all receiver checks pass**

The release may be published only from the exact merged commit after all of the following succeed:

1. focused adversarial tests for runner file confinement, hardware authority, compute-root replay, RepairBuddy freshness, and PR-publisher transport boundaries;
2. focused module self-tests;
3. fresh `node verify.js` output and strict complete-warning delta;
4. deterministic discovery verification;
5. the complete aggregate `npm test` suite;
6. public-surface static contracts;
7. Windows public package creation with zero configured secret findings;
8. package restore test;
9. launch of the exact extracted package with no Node.js initially exposed on `PATH`;
10. checksum, package receipt, launch receipt, asset inventory, and GitHub receiver verification.

The workflow must refuse an existing `v0.6.1-experimental` tag or release. It must append the v0.6.0 audit note without moving or retargeting the old tag.

Repository branch/tag protection and Template-repository state are a separate administration gate. A source file claiming those settings is not evidence that GitHub enforces them.
