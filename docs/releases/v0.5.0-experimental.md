# AXM Workshop v0.5.0 Experimental

Released: 2026-08-04

This release publishes the current reviewed local Workshop as a deterministic,
public-safe snapshot. It does not grant CANON status and it does not include
private projects, intake workspaces, machine state, logs, sessions, generated
distributions, working handoffs, or rollback archives.

## Capability measurements

The Workshop exposes several honest counts because they answer different
questions:

- Public discovery registry: **206 modules / 1,748 capability identifiers**.
- Tool index: **210 tools / 1,769 declared capabilities**.
- Growth contracts: **1,610 exact unique provided capabilities / 1,828 total
  declarations**.
- Promotion evidence: **123 self-tests PASS / 0 not passing** at the release
  planning checkpoint.

Declarations describe interfaces and intent; they are not automatically proof
that every capability works in every environment.

- Expanded Game Hub games, QR/controller infrastructure, assets, and AI-seat

## Publication boundary

AXM's existing deterministic Source Control & Merge Workbench generated and
verified the exact publication plan. The plan:

- only adds or updates public-safe paths;
- has no tracked-file deletion authority;
- refuses secrets and files over GitHub's per-file limit;
- binds copying, staging, commit, and push to one reviewed digest;
- pushes only an `automation/` branch for pull-request review.

Local intakes, projects, state, sessions, caches, generated distributions,
working packs, archive-review folders, rollback archives, and editor backups
remain on the local Workshop and are not deleted.

## Status

`EXPERIMENTAL` / `TEST`. Merge and release represent Mike's publication gate,
not automatic promotion to CANON or broad production certification.
