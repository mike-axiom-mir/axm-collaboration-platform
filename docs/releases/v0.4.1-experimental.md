# AXM Workshop v0.4.1 Experimental

This prerelease brings the reviewed visual-fabric integration onto the public
Workshop baseline while keeping the existing local-first and authority
boundaries intact.

## Download and open on Windows

1. Download `AXM-Workshop-v0.4.1-experimental-Windows-source.zip` from the
   GitHub release.
2. Optionally verify it against the attached `.sha256` file.
3. Select **Extract All**.
4. Open the extracted folder.
5. Double-click `OPEN_AXM_WORKSHOP.cmd`.

The launcher uses an existing compatible Node.js runtime or downloads the pinned
Node.js 24.17.0 archive, verifies SHA-256, and stores it only inside AXM. No
administrator permission, account, API key, or `npm install` is required.

## What changed

- Style Fabric 0.6.0 now provides governed game-skin tokens, molds, preskins,
  transitions, and verification contracts.
- CSS Skin Fabric 0.2.0 provides the shared interface foundation, including 149
  semantic tokens, responsive layouts, components, materials, and themes.
- Aetherglass 7.1.0 is integrated through a bounded compatibility bridge.
- The Hub and Skinner consume the new visual foundations while preserving
  existing module behavior and authority boundaries.
- The Hub's phone layout and navigation drawer were rebuilt for a usable
  single-column opening, with keyboard focus and reduced-motion treatment.
- Fake private-key headers used by security self-tests are assembled at runtime,
  so the public-package scanner can still refuse real key material without
  mistaking its own fixtures for credentials.

## Evidence

- Style Fabric release manifest: 151 files verified.
- Style Fabric unit suite: 109/109 checks passed.
- CSS Skin Fabric intake manifest: 98 files verified.
- Required CSS validators, Hub skin tests, and Sentient Atrium tests passed.
- Static discovery and launcher checks passed in GitHub Actions.
- The integration passed the clean-Windows launch gate from a path containing
  spaces with Node.js removed from `PATH`.
- The release tag is created only from a green merged `main` commit.

These checks establish the named surfaces; they are not blanket proof of every
declared capability or complete accessibility conformance.

## Known boundaries

- Experimental and not production-certified.
- First bootstrap needs internet when compatible Node.js is absent.
- The source archive does not bundle Node.js.
- Clean macOS/Linux first launch is not independently proven.
- Optional deep CSS parsing requires `tinycss2`; required validators do not.
- The broader Workshop suite retains a pre-existing Heartbeat observatory
  fixture mismatch (`HELD` versus `READY`).
- An independent first-time-human usability test has not yet been run.
- No broad open-source license has been granted yet.
