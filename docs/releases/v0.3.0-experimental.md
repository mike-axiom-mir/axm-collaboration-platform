# AXM Workshop v0.3.0 Experimental

This is the first prerelease cut from the newly synchronized public Workshop
rather than the older reconstruction snapshots.

## Download and open on Windows

1. Download `AXM-Workshop-v0.3.0-experimental-Windows-source.zip` from the
   GitHub release.
2. Optionally verify it against the attached `.sha256` file.
3. Select **Extract All**.
4. Open the extracted folder.
5. Double-click `OPEN_AXM_WORKSHOP.cmd`.

The launcher uses an existing compatible Node.js runtime or downloads the pinned
Node.js 24.17.0 archive, verifies SHA-256, and stores it only inside AXM. No
administrator permission, account, API key, or `npm install` is required.

## What is in this prerelease

- 177 indexed tool modules;
- 1,183 declared capability routes;
- the modular Hub, games, worlds, studios, evidence and governance systems;
- Heartbeat and Pulse foundations;
- public discovery and machine-readable status registries;
- deterministic publication and clean Windows launch gates.

Capability entries are declarations, not blanket runtime proof or authority.

## Evidence

- Static discovery and launcher checks run in GitHub Actions.
- A real clean Windows job removes Node.js from `PATH`, launches from a path
  containing spaces, downloads and verifies the private runtime, and polls the
  Hub health route.
- The release tag is created only from a green merged `main` commit.

## Known boundaries

- Experimental and not production-certified.
- First bootstrap needs internet when compatible Node.js is absent.
- The source archive does not bundle Node.js.
- Clean macOS/Linux first launch is not independently proven.
- An independent first-time-human usability test has not yet been run.
- No broad open-source license has been granted yet.
