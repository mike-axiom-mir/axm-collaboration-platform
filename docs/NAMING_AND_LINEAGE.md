# Naming and lineage

`Mirror` is the human-readable family name. The native identity is a versioned
machine identifier rather than a claim of self-chosen biography.

- Native identity: `axm.machine.mirror/seed-0`
- Provider: `mirror-kernel`
- Signature: `OBSERVE -> MODEL -> COMPARE -> VERIFY -> REPAIR`
- Prior working name: Maccie

The prior name and its route package remain in source history. They are not
silently rewritten. If a later learned Mirror can produce a grounded
self-description, it may propose another display name through the same human
merge gate. Seed-0 does not pretend to have chosen its own name before it
existed.

The Workshop's existing `shared/mirror-core` is a separate world/linking
service. It is not this reasoning identity and retains its own port and status.
