## Manual seam removed

Foundation public-source discovery made future source visible, but Mirror Doctor
still contained a manually maintained array of hundreds of exact organ,
contract, script, test, module, capability, and skill filenames. A future organ
could therefore enter the Foundation subject yet remain outside structural
health inspection until a human edited the Doctor list.

The Doctor now consumes the exact content-sealed public-source inventory and a
separate deterministic integrity report. The filename array has been removed.
The public `skills/` root is now part of the bounded inventory, raising the
reviewed root count from thirteen to fourteen.

## Structural ground added

Without executing public source or tests, the integrity cell checks:

- SHA-256 and byte identity against the current public-source inventory;
- CommonJS/JavaScript syntax through compilation without evaluation;
- JSON parsing for every admitted JSON source;
- `$schema`, `$id`, object-root, and root-closure declarations for contracts;
- duplicate contract schema IDs;
- explicit `KNOWN_FAIL` contract supersession paths;
- module manifest schema and directory identity;
- present in-module entry files and companion module contracts;
- module manifest/contract ID agreement;
- static exact relative-require reachability from a public test to every active
  top-level organ, including transitive dependencies.

The require scanner ignores comment, block-comment, quoted-string, template,
and identifier bait. Static reachability remains only a structural witness; it
is not test execution or behavioral correctness.

The Doctor separately derives learned-artifact paths and SHA-256 seals from the
Model BOM instead of hardcoding them. Constitutional human documents remain a
small explicit anchor set.
