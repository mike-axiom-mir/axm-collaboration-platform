## Outcome

Mirror now has a generic, deterministic provider-binding experiment planner.
It converts the preceding immutable implementation-evidence survey into a
complete balanced matrix of experiment inputs without choosing a provider.

For the real `shared-physics` gap, the planner retained all five eligible
exported `axm-physics-2d` source witnesses—including adversarial and canary
sources—and paired each with all three positive `UNTESTED` architecture
hypotheses. This produced 15 unselected experiment frames. The selftest source
was reserved as independent validation evidence. Ordering, registration
syntax, filename, mention frequency, and consumer permissions selected
nothing.

The evidence ceiling is:

`BALANCED_EXPERIMENT_INPUT_MATRIX_NOT_PROVIDER_BINDING`

The planner does not infer provider identity, bind the outer requirement,
select a declaration schema or path, infer or grant provider permissions,
execute source, select or evaluate architecture, build a provider, write a
declaration, touch Workshop, admit traces to training, or promote runtime.

## Why this is growth

The preceding survey could answer which bounded source files visibly contain
the demanded selector. It could not turn those observations into reusable,
independently testable experiment inputs without manual assembly.

The new planner supplies that missing deterministic step:

1. classify every exact-selector witness by experiment role;
2. keep exported sources as nonauthoritative implementation inputs;
3. reserve tests and non-exported witnesses for validation;
4. pair every eligible source with every positive untested architecture;
5. bind each frame to the research exam authored before any candidate;
6. keep all binding, permission, selection, execution, and build fields
   unresolved.

This reduces manual anatomy while preserving the Reasoning Foundation as the
authority boundary. It is useful machine ground for a later learned language
organ: language may interpret and render these typed traces, but cannot become
hidden decision authority.

## Portability seam found by independent review

Mike supplied a Route Guardian/Fable external review of a 2026-07-18 zip run
in a clean Linux sandbox on Node 22 with zero npm installs. The reported result
was 125/126 tests passing. The sole failure was the live Workshop growth test,
because the prior default `C:\axm workshop` was interpreted as a relative
POSIX path. This is preserved as a human-supplied external verification claim;
the external sandbox artifact itself is not part of this repository.

The finding generalized beyond the cited curriculum line: the Windows default
was repeated across multiple organs and entry points. The repair therefore
added `config/workshop-root.js` and routed default resolution through:

1. explicit `workshopRoot` option;
2. `AXM_WORKSHOP_ROOT`;
3. supplied or local/example configuration;
4. `C:\axm workshop` on Windows or `~/axm-workshop` on POSIX.

An absent live Workshop is now a typed `WORKSHOP_ABSENT` observation. The live
integration test skips with the resolved path and remediation, while
fixture-backed logic tests remain strict. A forced-absent local run produced
one explicit skip and zero failures. Resolver, absence, inventory, and safe
review-copy behavior have dedicated tests.

## Safe review copy and state pressure

The external review also observed that an unfiltered zip was mostly private
`state/`. State is already ignored from commits, but append-only evidence can
still dominate ad-hoc archives. `scripts/make-safe-review-copy.js` now creates
a manifest-bound source-review copy under ignored `state/review-copies` from
Git tracked plus untracked nonignored files. It explicitly refuses private
state, logs, private memory, datasets, checkpoints, local config, and
token/key/secret extensions. It does not compact or erase the evidence store,
and it is not a complete machine-state backup.

No cold-storage compaction has been implemented. A future archive policy must
preserve content digests, source lineage, append-only failure evidence, and
recoverability before any hot trace is removed.
