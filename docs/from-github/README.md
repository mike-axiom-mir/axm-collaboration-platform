# AXM Collaboration Platform

Public/template base for the AXM local-first collaboration platform.

Founder / public contact name: **Mike Tobi**.

AXM is a modular workshop foundation for safer human-AI collaboration: visible files, local tools, reviewable changes, bridge-based AI connection, rollback discipline, and no fake-done workflow.
