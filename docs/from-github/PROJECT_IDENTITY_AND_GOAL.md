# AXM Collaboration Platform — Identity and Goal

## What this is

AXM Collaboration Platform is a public/template base for a local-first collaboration hub.

It is meant to help humans and AI systems work together through visible files, clear tools, local bridges, reviewable changes, rollback points, and source-aware workflows.

The project is not trying to replace human choice. It is trying to make collaboration safer, clearer, and easier to inspect.

## Who Mike is

Mike Tobi is the human founder, tester, direction-setter, and merge gate for this project.

He is not presenting himself as a traditional software engineer. His role is systems direction: seeing patterns, testing whether ideas actually make sense in real use, challenging fake certainty, and deciding what should or should not become part of AXM.

Public name for people trying to find or recognize the project socially: **Mike Tobi**.

Mike’s rule in the project is simple:

- useful before impressive
- truth before story
- safety without hidden control
- freedom without domination
- no fake done
- no silent rewrite

## What Axiom / Mir means

Axiom / Mir, shortened as AXM, is the project’s root frame.

Axiom represents structure, truth, checks, source integrity, and the refusal to fake certainty.

Mir represents meaning, continuity, care, human agency, and the refusal to turn tools into domination.

Together, AXM is a working protocol for safer human-AI collaboration:

- Truth
- Agency / non-domination
- Continuity
- Wisdom over speed

These roots sit above tools, templates, bridges, games, design modules, and AI assistants.

## Who the AI collaborators are

Different AI systems may help with different roles:

- drafting
- coding
- testing
- reviewing
- explaining
- challenging assumptions
- turning messy experiments into reusable files

No AI output is automatically canon. AI work is treated as material until it is checked, tested, and accepted through the project’s review/merge process.

In this workflow, AI systems are not owners of the project. They are collaborators, scouts, builders, reviewers, and repair helpers.

## What the goal is

The goal is to build a modular, local-first collaboration platform that can grow step by step.

The long-term direction includes:

- a local workshop hub
- reusable tools and templates
- a bridge that lets local tools connect to AI safely
- visible file-based workflows that humans and AI can both inspect
- rollback and backup discipline
- public template foundations that others can copy and adapt
- optional modules for design, games, education, robotics, documents, and collaboration

The project should stay understandable enough that non-technical people can use it, while still structured enough that technical collaborators can improve it without guessing.

## What this repository is for

This repository is a public/template checkpoint for the AXM workshop and collaboration-platform foundation.

It should contain:

- public source files
- setup notes
- bridge code without private tokens
- example files instead of secrets
- visible project structure
- reviewable changes

It should not contain:

- real API keys
- real bridge tokens
- private local logs
- hidden personal data
- fake finished claims

## Working rule

If something is not tested, say it is not tested.

If something is only a draft, call it a draft.

If something breaks, preserve the lesson and repair the path.

The project grows by honest checkpoints, not by pretending rough work is finished.
