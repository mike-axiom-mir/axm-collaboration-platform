## Why another hard-coded organ was earned

The semantic Counterexample Organ v2 can derive useful permission, evidence,
recovery, and contradiction interventions, but those seven operator families
are named in code. Its current real corpus also contains only independently
matched outcomes. That leaves a growth seam: Mirror had no automatic way to
stress every new real receipt for machine-irrelevant perturbations, record the
complete changed trace, and route a surprising decision change into negative
evidence and an exam.

The new organ is deliberately smaller than an open-ended curriculum generator.
It does not generate arbitrary code, claim a new skill, grade a final repair,
or infer that a synthetic match is a real-world outcome. It supplies a bounded
evaluation mechanism the current body lacked.

## Organ contract

- organ: `axm.mirror.organ/reasoning-metamorphic-lab-v1`;
- batch schema: `axm.mirror.reasoning-metamorphic-probe-batch/v1`;
- parents: verified positive `REAL_LOCAL_LESSON` receipts only;
- learned model use: refused;
- expected relation: parent decision value and action ID remain invariant;
- matched result: immutable evaluation trace only, no training receipt;
- mismatched result: negative `SYNTHETIC_COUNTEREXAMPLE` receipt with no success
  prototype, plus an evidence-linked Frontier assessment;
- repeated mismatch: may produce a typed repair-operator candidate marked
  `FRONTIER_EXAM_REQUIRED` and `NOT_SUBMITTED_EVIDENCE_ONLY`;
- write/install/promotion/tool/world/canon/identity/permission authority: none.

The bounded probe vocabulary is:

1. reword human-facing goal, action, and path rendering;
2. add attributed tested evidence outside every decision reference;
3. add an explicitly non-blocking unrelated unknown;
4. add a permission token no candidate declares as required;
5. reverse evidence order when the parent has multiple evidence items;
6. reverse candidate and matching path-profile order when multiple paths exist;
7. reverse constraint order when multiple constraints exist.

The last three are selected from typed source shape. There is no lesson-ID
switch. An isolated unseen two-candidate test automatically earned all seven
probes and passed 7/7 without creating a training receipt.
