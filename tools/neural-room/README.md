# Neural Room

AI-native, provider-dependent authoring room for bounded visual passes. It does
not bundle or impersonate a model. Prepare a request, run it through an explicit
provider, then import the provider's result JSON. The room verifies exact
request binding and the returned image's real SHA-256 before enabling the
ten-minute candidate transfer to Visual Draft Room.

No provider result can approve appearance or canon. Raw returned image bytes
are not included in Hub checkpoints.
