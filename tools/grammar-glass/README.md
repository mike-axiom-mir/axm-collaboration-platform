# Grammar Glass / Code Twister — Phase 1 steward pass

This browser surface renders only a recorded `axm.code.grammar-glass-visual-snapshot.v1` produced from the live AXM grammar-profile registry. The steward pass adds bounded cross-grammar influence carries and lineage-preserving composite formations without treating unlike grammars as equivalent.

Generate a grounded snapshot from the repository root:

```bash
node shared/code-capability-fabric/language-organs/generate-code-grammar-glass-snapshot.js \
  --day 2026-08-24 --ticks 8 --stars 8 > /tmp/grammar-glass-snapshot.json
```

For exact replay, pass the recorded 64-character root seed with `--seed <seed>`. If `--seed` is omitted, Node draws from the operating-system cryptographic entropy source and records the resulting root seed. The day label is not randomness, and RNG does not prove novelty.

Open `tools/grammar-glass/index.html` and choose **Load snapshot JSON**. No canned activity is shown before a snapshot is supplied. The viewer renders recorded atom positions, typed relationships, cross-grammar influence carries, composite formation lineage, Reactive Draft Mirrors, Draft Stars, replay data, and append-only ledger summaries. It does not execute, compile, install, use network, admit, select, promote, merge, or change CANON.

A cross-grammar carry is bounded deterministic recorded state with source/target grammar identities, a relationship class, signed phase delta, decay, limit, and digest. It is not training, a learned weight, semantic equivalence, or a rewrite of either grammar profile. A composite formation may combine roles from several grammars while retaining every grammar component and unresolved/incompatible boundary; no merged grammar identity is created.

Grounded claim: Grammar Glass is a seeded, replayable, provenance-bound polyglot structural field and observation simulator. It uses real AXM grammar knowledge to generate and photograph temporary draft formations without granting those formations authority.
