# Capability Recipe Foundry pilots

Pilot packets in this directory are generated, detached `EXPERIMENTAL` review
material. They are not installed, registered, staged, promoted, active, merged,
or CANON. Builder source and tests inside a packet remain unexecuted by the
Foundry; any test run must be an explicit trusted-host action with separate
evidence.

The v1.1 pilot set contains exactly three inactive packet routes:

- `HAND`: a bounded executable closed-schema validator contribution.
- `SKILL`: a host-mediated portable `SKILL.md`, `skill.contract.json`, and
  `skill.selftest.js` contribution.
- `ADAPTER` (`HAND` runtime kind): a closed flat-object mapping contribution
  with explicit field loss and structural compatibility boundaries.

The validator and portable SKILL have separately reviewed active counterparts;
their packets remain inactive provenance. The object adapter is still the one
registry `REVIEW_CANDIDATE` and is absent from the active recipe catalog.
