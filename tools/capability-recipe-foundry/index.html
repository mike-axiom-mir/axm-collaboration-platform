ONE PACKET DEFAULT

    Explicit download materializes review files only. The builder selftest remains unrun until a trusted host deliberately executes it.

    REUSE

    No duplicate invention

    Gap Workbench finds the need. Hand Specification Foundry defines it. Hand Verification Lab binds the evidence plan. This module handles only the missing recipe-authoring seam.

    DETERMINISM

    No constant model compute

    Once source exists, the same sealed input produces the same proposal, file bytes, packet digest, and receipt without a provider, API key, or network.

    PILOTS

    HAND and SKILL, separately typed

    The HAND pilot builds a bounded validator. The SKILL pilot builds portable SKILL.md, contract, and selftest files. Both remain outside the active Capability Fabric catalog.

    STOP LINE

    Foundry cannot approve Foundry

    Passing packet checks proves deterministic assembly and integrity only. Source quality, behavior, safety, usefulness, activation, merge, and CANON remain separate claims.
