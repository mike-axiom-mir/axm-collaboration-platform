# Sustainability Metrology Lab

Status: `TEST`

Technical child of Cognitive Resource Meter for hardware-bound direct, imported, or manually declared energy and carbon evidence. Power-meter and regional-factor digests preserve where quantities came from.

It refuses token-to-energy shortcuts, unbound carbon factors, current-grid certification, sustainability scores, and green claims. Capture requires `sustainability.evidence.write` and an explicit action header.

Verification: `node tools/sustainability-metrology-lab/selftest.js`
