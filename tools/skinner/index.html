Complete AXM design sheet · generated from the live safety contract

The full production surface includes visual controls, concrete image files, and the checks that keep warnings and controls honest. The image files map into 10 runtime vault slots.

Image slots a designer can supply · all optional

Sizes come from the shell's own CSS. Every slot is optional — a skin with no assets is a complete skin. Assets live in the Asset Vault and are referenced as vault:id. A skin may not point at a URL.

Get a skin from the web

Downloaded a skin someone shared? Import the file — or paste its JSON here. Pasting works even when file downloads don't.

Anything from outside is untrusted: it passes the same gate, and its author name is treated as a claim, not a fact.

Reset always works and cannot be skinned away. If a skin ever fails its gate, the previous one stays and you are told why.

There is no upload server — this hub is local-first. To share widely, open a pull request on the public repo's skins/ folder; every submission is checked by the same gate.
