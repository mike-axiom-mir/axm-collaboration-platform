# AXM Portable Visual FX

A governed Workshop surface for fifteen locally generated Opus effect blocks.

## What is real

- One deterministic runtime serves Node asset hands and the local browser.
- Equal parameters produce equal content-derived IDs.
- CSS is exposed for every admitted effect.
- SVG is exposed only where the primitive is truthful.
- Host-neutral tokens preserve the parameters for future adapters.
- A namespaced Shapeable Builder pack is available as an explicit download.

## Boundaries

Loading this tool never applies an effect to another page, application, game or operating system. It does not grant permissions, certify visual quality, compile shaders or promote a candidate. Conic gradients have no native SVG equivalent. Frosted glass needs a live backdrop. Film grain uses browser SVG `feTurbulence`, which some offline rasterizers cannot prove.

## Provenance

The source export was generated locally by Opus for Mike Tobi / AXM. The original files remain in `exports/fx-blocks`. This admitted copy fixes the runtime boundary and content-derived IDs without rewriting the effect vocabulary.
