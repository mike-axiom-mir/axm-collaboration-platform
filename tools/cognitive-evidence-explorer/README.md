# Cognitive Evidence Explorer

Status: `TEST`

Read-only technical child of Cognitive Resource Meter. It joins the Meter timeline with calibration, attention, sustainability, and Mirror-intake receipts for inspection while keeping every dimension and evidence kind separate.

It has no permissions and writes no state. It does not calculate cost, make composite scores, rank, select, allocate, train, write Mirror, promote CANON, or act on the world.

Open it from **Hub -> Build -> Cognitive Resource Meter -> Cognitive Evidence Explorer**. It is intentionally a machine-layer child rather than another everyday Hub card.

Verification: `node tools/cognitive-evidence-explorer/selftest.js`
