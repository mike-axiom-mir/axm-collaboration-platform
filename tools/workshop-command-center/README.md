# Workshop Command Center

The Workshop Command Center is the beginner-facing cockpit above Create,
Build, Publish & Library, Play, and AI Team. It is a presentation and explicit
request surface, not a new authority layer.

## Human path

1. Describe a direction in normal language.
2. Preview the deterministic capability plan. Preview writes nothing.
3. Read the six-dimension advisory assessment.
4. Save the plan and queue only already-declared bounded goal records.
5. Cast an attributed vote on the exact SHA-256 plan digest.
6. Request between one and ten independent review votes. One identity still
   contributes only one counted vote.
7. Discuss HOLD and DOWN decisions in the Decision Pool, then route the same
   direction to a changed repair digest or cancel it completely.

## Output panel

The Workshop Output panel reports files changed during the last 60 minutes by
code, asset, test, document, and other categories; 24 hourly modification
buckets; recent paths; explicitly finished directions; and net lines/hour
since the previous Workshop Growth snapshot. File modification is an activity
signal, not proof of completed work. Only an explicit direction lifecycle
event is labelled finished.

## Boundaries

- no automatic vote or identity impersonation
- no one identity filling multiple independent seats
- no Body Pulse start or mode change
- no generic POST execution from the advanced catalog
- no permission, tool, file, network, provider, budget, promotion, release,
  canon, Mirror-write, or world authority
- no required third-party runtime

Status is `TEST`. The room needs browser and human operator trials before any
production claim.
