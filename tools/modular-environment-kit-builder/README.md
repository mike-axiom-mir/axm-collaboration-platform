# Modular Environment & Prop Kit Builder

An offline street-kit foundation built from 20 exact existing source parts rather than thousands of generated files. Ten deterministic 12×8 layouts share a one-unit grid, 90° rotations, exact road connectors, source-origin ground pivots, modular facade recipes, floors, roofs, doors, interior and prop sockets, variants, and explicit damage pairs.

All layouts are references and receipts. Generated previews stay temporary; permanent-library promotion and visual-coherence approval remain separate human actions.

Run `node selftest.js` or open `index.html` through Workshop Hub.
