# Technical Art Validator

An offline, dependency-free technical gate for exact GLB bytes. It validates the four Forge target families against explicit PS2-rung budgets and production requirements, explains each repair in human language, emits a machine report, and runs an independent raw-byte verifier that does not import the report writer.

Missing LOD, collision, or semantic-pivot proof cannot become a pass. Numeric checks never approve visual quality, and no result automatically promotes an asset.

Run `node selftest.js` or open `index.html` through Workshop Hub.
