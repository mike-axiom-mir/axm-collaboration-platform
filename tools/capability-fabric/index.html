    NORMAL PATH

    No constant compute

    After a person or future intelligence authors a recipe, ordinary builds are closed local compilation. No provider, model, API key, or network is involved.

    FUTURE INPUT

    Proposals stay inactive

    Mirror or a mature Code Fabric may later propose recipes. Proposals cannot activate themselves; source review and Mike's merge gate remain outside this module.

    MODULAR KINDS

    Hands act; skills guide

    HAND binds an executable capability entry. SKILL binds portable SKILL.md plus an explicit instruction-only, host-mediated, or executable runtime. Neither kind carries authority.

    COMPOSITION

    Contracts connect; hosts still decide

    The machine and CLI doors can plan and materialize bounded acyclic graphs through exact consumes/provides identities. This proves wiring and lineage, not runtime payload semantics, host permission, or end-to-end behavior.

    EVIDENCE

    Tests are not claims

    The Fabric emits focused tests but does not execute generated code. A trusted host must run them; visual creation also needs separate live observation.

    AUTHORITY CEILING

    No self-growth shortcut

    Candidate generation grants no install, permission, promotion, Foundation, or CANON authority. Nursery readiness means structure only.
