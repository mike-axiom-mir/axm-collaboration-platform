Hermes Local Runtime Wrapper

An explicit-config bootstrap and consent-gated proposal control layer for an external Hermes Agent installation. AXM does not bundle or prove that runtime.

What exists now

  • Check local Node, Git, Python, config, and cloned-folder prerequisites
  • Clone or start only after an explicit local bootstrap command
  • Serve loopback-only health, consent, and module status
  • Write consent-gated tasks, review proposals, and prompt packs to declared local folders

Boundary

The landing card does not install, start, connect to, sandbox, or verify Hermes. Control-layer consent does not gate bootstrap install/start. Runtime readiness and integration remain UNKNOWN until checked locally.
The public source example points to NousResearch/hermes-agent; the bootstrap does not independently verify source or license.
