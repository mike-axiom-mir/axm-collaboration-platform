Hermes local start note

The bootstrap and control layer are separate.

External bootstrap path (explicit commands only):

cd AXM_WORKSHOP\tools\hermes
node hermes-bootstrap.js doctor
node hermes-bootstrap.js install
node hermes-bootstrap.js start

Install/start requires reviewed local configuration. The wrapper does not verify source, license, command safety, installation, or runtime readiness. These commands are not gated by the control-layer consent toggle.

Optional AXM control-layer test:

cd AXM_WORKSHOP\tools\hermes
node hermes-runner.js

Then check:

http://127.0.0.1:8791/health

Control-layer consent is OFF by default and gates its write routes. The control layer does not connect to or invoke the external runtime.
