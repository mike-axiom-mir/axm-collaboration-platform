Hermes local start note

Default rule:

Runtime ON by default.
Action OFF by default until consent.

Preferred path:

cd AXM_WORKSHOP\local_modules\hermes
node hermes-bootstrap.js doctor
node hermes-bootstrap.js install
node hermes-bootstrap.js start

The bootstrap path is for the real Hermes runtime from NousResearch/hermes-agent.

Optional AXM control-layer test:

cd AXM_WORKSHOP\local_modules\hermes
node hermes-runner.js

Then check:

http://127.0.0.1:8791/health

Do not confuse runtime with permission to act.

Runtime means Hermes is available.
Consent means Hermes may perform the selected action inside limits.
