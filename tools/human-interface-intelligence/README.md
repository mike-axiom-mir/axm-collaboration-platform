# Human Interface Intelligence platform module

AXM Module 2 is installed as a `TEST` machine capability. Its source engine is unchanged in `engine/` and runs through an isolated Python runtime.

The native Module 1 paired gate is intentionally still blocked because the same declared `0.1.0` contract has different schema bytes. The platform adapter can create target-valid review records with a hashed sidecar; it does not claim native compatibility or execution authority.
