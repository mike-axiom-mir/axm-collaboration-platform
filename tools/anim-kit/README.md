# AXM Procedural Animation Kit

Ten local motion Lego blocks are available for Shapeable Builder and the shared game-animation spine: juice, seeded camera shake, idle/walk/run locomotion, and two directed respawn morphs.

Open `index.html` to inspect the source proofs. Import `shapeable-block-pack.json` into Shapeable Builder to place the governed blocks on its Visual canvas.

This remains a TEST candidate. The math is deterministic and the semantic adapter passes, but a static filmstrip cannot approve final deformation, foot sliding, silhouette, camera comfort or game feel. Those remain live visual checks.
