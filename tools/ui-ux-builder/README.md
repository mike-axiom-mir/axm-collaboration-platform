# AXM UI/UX Builder

A single human-facing design workspace. It starts with a person and their job, not with CSS.

The five steps are:

1. **Human** — audience, primary job, frustration, and non-negotiable human needs.
2. **Journey** — a short ordered path through the experience.
3. **Look** — bounded visual tokens and presets; no raw CSS or scripts.
4. **Preview** — responsive Hub-shaped preview plus deterministic checks.
5. **Handoff** — a proposal packet for review, never an automatic rewrite.

The first built-in starter is the AXM Hub human-first pass requested by Mike. Local state is stored under `axm.uiux-builder.v1` and can be exported/imported as `axm.uiux-workspace/v1`.
