# AXM Local GameHub — Steam store copy draft

Status: **TEST draft** · human approval required

Working title: **AXM Local GameHub**

## Short description

Bring a local party together around one growing game shelf. AXM Local GameHub
hosts 19 distinct playable tests and experiments for 1–8 players, with shared
screens, optional same-Wi-Fi phone controls, gamepads where declared, and
visible human or AI seats.

## About this game

AXM Local GameHub is one local-first place for a varied game night. Choose from
nineteen installed experiences, keep the same visible party between rounds,
and let each game declare the players and controls it actually supports.

The current library ranges from neon co-op Pong and city adventures to racing,
strategy, stewardship, music, farming, story-driven action, emergency co-op,
and free-play casino simulation. Games support between one and eight players.
Some use one shared screen, some offer same-Wi-Fi phone controllers, and some
support local gamepads. Support is shown per game instead of being implied for
the whole shelf.

Human and AI participants occupy visible seats under the same declared game
rules. AI seats do not silently replace people, and a shared display never
pretends to be a player. External AI services are not required for ordinary
local play.

## Honest feature bullets

- One local GameHub with 19 installed game packages
- 1–8 players depending on the selected game
- Shared-screen play and optional same-Wi-Fi phone controllers where declared
- Local gamepad support where declared and tested
- Visible human, built-in AI, or adapter seats where a game supports them
- Local-first game servers with no required online multiplayer service
- Persistent results and per-game saves where implemented

## Claims not approved yet

matching evidence gate passes:

- Online PvP or online co-op
- Steam Remote Play Together
- Full controller support across the complete library
- Steam Deck compatibility
- Steam Cloud, achievements, leaderboards, Workshop, or trading cards
- Cross-platform support beyond the independently tested Windows build
- A final count of fully polished or complete games
