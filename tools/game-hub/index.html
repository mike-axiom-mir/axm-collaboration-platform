AXM Game Hub

A local lobby and launcher where humans and AI/adapter seats connect, swap seats and launch swappable games from a shared library — up to 8 visible seats.

What it does

  • Show the lobby: 4 visible seats, up to 8
  • Accept humans by link/QR and AI/adapters as visible seats
  • Load game-library manifests
  • Launch the selected game and return a result summary

Rule

Game Hub is the lobby and launcher, not one game. AI/adapters must occupy visible seats.
