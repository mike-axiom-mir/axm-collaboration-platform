# Bloomvale: Gatewatch — evidence route

This file maps each material beta claim to evidence capable of proving it. Source presence alone is not treated as proof of live appearance or feel.

| Claim | Primary evidence | Counterevidence / failure signal | Status gate |
|---|---|---|---|
| The package keeps one human Scout plus one selectable Human, Connected AI, or built-in Moxie second seat on a shared screen | `tests/toonfall-selftest.js`, `tests/partner-choice-http.test.js`, `game.manifest.json`, `/health`, `/api/launcher-state` | Seat choice ignored, hidden participant, split-screen claim, or client-owned Moxie state | Automated pass required |
| The managed local server owns combat, exploration, meetings, activities, unlocks, score, waves, and result | `tests/server-http.test.js`, `tests/toonfall-selftest.js`, `runtime/server.js`, `/api/state`, `/api/observe` | Client mutation survives a fresh server snapshot or an unlock appears without its condition | Automated pass required |
| The story has three distinct scenes and reaches a playable briefing | Core self-test plus observed live story journey | Missing scene, blocked Next button, or combat beginning behind the story overlay | Automated and live pass required |
| Pippa can move, aim, fire, dash, and use Heartburst | Core self-test plus observed keyboard/mouse interaction | Stale inputs accepted, controls ignored, or cooldown abilities repeat without gating | Automated and live pass required |
| Moxie visibly defends without consuming a player seat | AI projectile/target tests plus live combat frames and server observation | Moxie is decorative, frozen, hidden, or counted as a human | Automated and live pass required |
| Bloomvale exposes five named districts and five neighbors | Core expansion assertions plus live travel, district discovery, Maribel meeting, and Nori meeting | Counters advance without proximity, names are absent, or exploration cannot resume after combat | Automated and live pass required |
| Four optional activities and six unlocks have material effects | Wisp, district-loop, range, meeting, stat-effect, and result assertions plus live Chroma Reserve and Prism Paint unlocks | Checklist-only unlock, duplicated reward, reset corruption, or activity cannot complete | Automated and live pass required |
| The expanded world guides the next useful route and exposes exact upgrade progress | Wayfinder/map self-test plus live compass changes from Maribel to wisp to Patch range and six map progress cards | Direction remains stale, route points to completed work, progress disagrees with server state, or compact HUD clips | Automated and live pass required |
| Maribel's map positions current progress without violating CSP | CSP response plus final SVG map screenshot, route-marker observation, and distributed-marker DOM observation | Markers collapse, map blocks close/resume, or compact document overflows | Live visual and server pass required |
| Five player-triggered named watches can reach victory; clears return to exploration; Heartlight loss reaches defeat | Deterministic chronicle tests and the 83-slot semantic victory in `evidence/chronicle-3d-verification.json` | Missing receipt, repeated Crown, endless watch, forced auto-start, missing explore return, or missing result | Automated plus one full live outcome required |
| A local low-poly 3D layer materially presents Bloomvale with 16-step-per-channel color quantization | `runtime/bloomvale-three.js`, focused static assertions, live WebGL datasets, and desktop/portrait screenshots in `evidence/chronicle-3d-verification.json` | WebGL fails without Canvas fallback, flat non-depth rendering, external assets, unquantized claim, layout overflow, or motion ignoring reduced mode | Automated and live visual pass required |
| Pause, map, and help overlays are escapable, focus-safe, and never resume behind one another | Core pause and modal lifecycle tests plus live M/M, H/H, H/Escape, and map/Escape interaction | Elapsed simulation advances while paused, focus is lost, a panel traps input, or play resumes under an open overlay | Automated and live pass required |
| Reload recovers the authoritative session and accepts immediate new input | HTTP persistence and sequence-sync tests plus live ready-state reload followed by an accepted quick click | Reload resets the world, replays stale toasts, creates a second world, or rejects new input as stale | Automated and live pass required |
| Health feedback remains truthful when an upgrade raises maximum health | Health normalization self-test plus live Heart Pocket state showing 125/125, 100% fill, and progressbar values | Fill exceeds its rail, text disagrees with state, or assistive values remain at the old maximum | Automated and live pass required |
| Controller support has a coherent bounded mapping | Source/test inspection of edge-latched sticks, actions, View, and Menu, plus the in-game field manual | Held actions repeat each frame, pause cannot resume, or controls are omitted from help | Automated/source pass; physical-device pass remains optional |
| The presentation is coherent at desktop and narrow viewport sizes | Repeated observed screenshots recorded in `evidence/visual-verification.json` | Clipped controls, unreadable text, hidden canvas, severe overlap, or non-responsive layout | Live visual pass required |
| The runtime needs no internet or downloaded assets | `ASSET_PROVENANCE.md`, CSP, static-source scan in self-test | External HTTP(S) source, font, media, telemetry, or remote runtime dependency | Automated pass required |
| Performance is acceptable for this local beta run | `/api/telemetry` sampled during combat plus live interaction | Tick p95 exceeds the 50 ms server budget or obvious persistent input/frame stalls | Local bounded sample only; never generalized |

Taste, long-session balance, physical gamepad behavior, other machines, and Mike's release approval remain outside what this evidence can prove.
