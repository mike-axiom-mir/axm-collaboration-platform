# Casino Alpha asset and runtime licenses

The Casino Alpha interface, inline vector emblems, low-poly geometry, materials,
lighting setup, and presentation code in this package were authored locally for
AXM. No downloaded art, generated-provider art, proprietary art pack, or trial
asset is bundled by this visual pass.

The registered browser client uses the Workshop's shared Three.js r160 runtime
under the MIT License. The authoritative vendored source and license remain at
`shared/vendor/three-r160/three.module.js` and
`shared/vendor/three-r160/LICENSE`; this package serves that local dependency
without modifying or duplicating it.
