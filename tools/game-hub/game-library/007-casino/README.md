# Casino Workbench

> **Installed AXM route:** Game Hub slot 007 runs this package on managed port
> 8797 at `/games/007/`. The prototype's port 4175 is only its standalone
> development default. These are two launch modes for the same package, not two
> separate games.

This package began beside the live `game-library` as a private workbench. It is
now installed as Game Hub slot 007 with a `PUBLIC TEST` manifest. The original
math and runtime separation remains intact so promotion did not flatten the
evidence or turn laboratory defaults into production claims.

Current workbench:

- `slots/lux-5/` — the first 50,000-record LUX-5 RNG outcome book.
- `lux-5-prototype/` — a local playable presentation of that book with an
  authoritative ledger/server and a responsive 3D robot cabinet.

The LUX-5 prototype is launchable through Game Hub or on its own. Public TEST
means visible and testable; multiplayer, AI adapter control and final casino
economy integration are still explicitly future work.
