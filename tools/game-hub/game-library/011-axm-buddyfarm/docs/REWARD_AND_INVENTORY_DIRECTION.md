# Sparse reward and inventory direction

BuddyFarm does not use volume as a substitute for reward quality.

## Safe-start rule

- No random junk drops.
- No starter inventory full of weak duplicates.
- No individual hotbar that forces routine tool switching.
- Shared supplies contain only resources currently used by the farm loop.
- Every future drop must declare a purpose, source, rarity band, stacking rule,
  ownership rule and removal/use route before it enters the catalogue.

The initial state therefore contains only:

- one useful starter field kit per buddy;
- one shared seed pouch;
- harvested Buddy Carrots;
- shared growth tokens used to expand the farm.

## Later tuning

Mike will set the real items and drop rates through play. Default tuning should
remain quieter than common farming games: fewer drops, stronger identity, less
sorting. A deterministic drop table may be added later, but an absent reward is
preferable to noisy placeholder loot.
