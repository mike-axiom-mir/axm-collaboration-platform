# Milestone 11 - Neighborhood Debt Aftermath + hybrid low-poly 3D

Status: **WORKING**. Focused mechanics and the desktop browser journey pass; repository gates are recorded in `BUILD_RECEIPT.md`. This is not CANON.

## Purpose

Turn a final Starspite loss into longer-lived neighborhood play without allowing loss history to influence another random outcome. Raise the six existing places from a 2D-only presentation to an original low-poly 3D baseline while preserving the proven Canvas interaction layer and fallback.

## Authored content

One unhandled replay-valid losing `small-odds.casino-play/v1` receipt can open three visible responses on Lopsided Lane:

- **Lane solidarity rota:** one Lane visit; 2 hours, 5 energy, Day +2 return, up to 20 recovery credits, Crooked Kettle/home/Tavi/Oola consequences, solidarity-ribbon memory.
- **Long Table repayment job:** one completed paid order; 3 hours, 8 energy, Day +1 return, up to 48 recovery credits, Crooked Kettle/work pressure/standing/storefront consequences, repayment-stamp memory.
- **Hushglass breathing room:** trust 3 plus one agreement; 1 hour, 3 energy, Day +2 return, up to 28 recovery credits, warmth/trust/home/Sumi consequences, accommodation-lamp memory.

The payment is `min(saved loss, authored route cap)`. Start freezes the source receipt, route, due day, time/energy commitment, payment, and return effect. Return resolves once. Casino net remains unchanged and same-day storefront income is recorded as a separate path.

Malformed receipts, wins, authored lots, cash balance, and remembered bad luck do not qualify. Eligibility replays the saved 256-bit seed through the published table and checks the outcome, stake, winning set, insurance arithmetic, and final negative net.

## Visual baseline

`runtime/world-three.js` supplies a dependency-free WebGL 1 renderer for shore, room, kitchen, district, market, and Starspite:

- fixed 480x270 internal resolution with pixelated CSS scaling;
- depth-tested low-poly cube/pyramid geometry;
- 16-step shader lighting quantization;
- location-specific architecture and palette;
- block-built Pip and persistent route-specific district markers;
- Canvas 2D remains simulation/interaction authority and becomes the fallback if WebGL is unavailable.
