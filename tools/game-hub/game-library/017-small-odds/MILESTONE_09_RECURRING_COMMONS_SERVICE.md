# Milestone 09 - Recurring Commons Service

Status: **VERIFIED local pre-alpha slice**.

This milestone turns the first Hushglass accord into recurring public infrastructure. `night-valve reliability` persists as an integrity band, an authored service calendar, active work, exact-once returns, one-time overdue consequences, and inspectable history. Three public routes reuse real prior state: the saved accord, a retained owned installation/store asset, or the currently assigned pet named by the original Hushglass receipt. A due service date also publishes one declared Hushglass/Long Table work-board conflict. Nothing in this layer changes portal or casino odds.

## Persistent maintenance cycle

- Save version 9 stores integrity, next due day, active service, completed and overdue counts, participant pet ids derived from real household receipts, history, sequence, and the last exact receipt.
- Four public integrity bands are authored: `OFFLINE`, `PATCHED`, `STEADY`, and `RESILIENT`.
- Due, active, and overdue states select explicit resident schedule overrides before Hushglass warmth, Crooked Kettle standing, and base calendar layers.
- A completed service schedules the next date exactly four days later. Missing the one-day grace window applies one authored overdue consequence once for that due date; the service remains repairable.

## Routes that reuse lived state

- Public rota: requires the saved returned accord, shared-enough warmth, and one agreement.
- Retained relay: additionally requires an actually installed home object or storefront equipment with a public maintenance tag. Ownership never transfers; the return appends service history to that same object.
- Returning pet: additionally requires the currently assigned pet id to occur in a real earlier Hushglass receipt. The pet's current species and named traits are scored literally again; unrelated traits remain zero.

Locked routes remain visible with the exact missing condition. Starts freeze the real gate, energy, object or pet evidence, portal charges, and promised return in `small-odds.commons-maintenance-start/v1`.

## Hushglass / Long Table conflict

While maintenance is due or overdue, the normal three-order Long Table calendar is replaced by one declared `Rebuild the Hushglass night-valve jig` order. Its cooperative and exclusive bids keep the existing disclosed wage, owned-tool wear, literal pet labor, pressure, and exact-return contracts. Resolving it also writes the appropriate Hushglass integrity, warmth, trust, next service day, visible mark, and nested receipt exactly once. Starting a public maintenance route suspends the paid override; completing the cycle restores the normal base order calendar.

## Exact return and RNG boundary

- Direct maintenance resolves on its frozen due day through `small-odds.commons-maintenance-return/v1`.
- The receipt records Hushglass warmth/trust, Crooked Kettle standing, Long Table standing/pressure, storefront rating, home score, Oola rapport, retained asset or returning-pet state, the visible house mark, next due day, portal charges, and `random:false`.
- Overdue consequences use `small-odds.commons-maintenance-overdue/v1` and cannot repeat for the same due date.
- Routes read no entropy, wealth, previous luck, casino history, session length, or portal draw history. Portal charges and odds remain unchanged.
