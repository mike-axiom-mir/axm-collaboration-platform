# Asset provenance

No external visual, audio, font, trademarked character, or copied game asset is included.

- Battlefield, low-poly meshes, shader, aura rings, sprites, buildings, effects, interface decoration, and animation are original dependency-free WebGL / Canvas 2D / CSS code authored for spot 021.
- The WebGL geometry is generated from embedded cube and ring vertex data at runtime; there are no imported models, textures, or shader packages.
- The palette and low-resolution presentation are an original “warm dusk pixel theatre” direction.
- Audio cues are generated at runtime with simple Web Audio oscillators; no sound files are bundled.
- Controller semantics reuse the repository-owned AXM universal Xbox/Brawl control contract. “Brawl-style” describes the common twin-stick interaction pattern, not copied branding, art, or game data.
