# Third-party software

Runtime third-party packages: **none** are installed, fetched, or loaded from the network.

The visual depth layer imports the Workshop's retained source snapshot of **Three.js r160**, Copyright © 2010–2024 Three.js authors, under the MIT License. The retained module and full license are at `shared/vendor/three-r160/three.module.js` and `shared/vendor/three-r160/LICENSE`; Circuitseed serves that local file through `/vendor/three.module.js`. It is presentation-only and is not authoritative game logic.

Circuitseed uses only standard Node.js, browser APIs, and that retained MIT-licensed Three.js source. It does not load a CDN, remote module, analytics service, cloud account, external AI, web font, or remote asset. Read-only AXM contracts and District Party architecture informed compatibility; copied or adapted code is identified in `SOURCE_REFERENCE.json` and remains within Mike's AXM project boundary.
