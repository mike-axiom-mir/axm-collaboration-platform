# Third-party software

Runtime third-party packages: **none**.

Circuitseed uses only standard Node.js and browser APIs. It does not load a CDN, remote module, analytics service, cloud account, external AI, web font, or remote asset. Read-only AXM contracts and District Party architecture informed compatibility; copied or adapted code is identified in `SOURCE_REFERENCE.json` and remains within Mike's AXM project boundary.
