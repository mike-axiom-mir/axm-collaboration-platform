# Future adapter seams — documentation only

## Living Globe

Circuitseed is its own authoritative world in this alpha candidate. The Living Globe is not contacted or modified. A future adapter may propose a read-only selected representation with explicit provenance, limitations, consent, and native revision. It may later attach Circuitseed as a game ruleset only after the Living Globe owns and accepts that adapter. `game_ruleset_adapter` is currently `FUTURE` and multiplayer is currently false in the referenced Globe manifest.

## Mirror Core

Live movement and controller inputs stay in Circuitseed's game server. Mirror Core receives nothing automatically. A separately reviewed future packet may propose a verified business pattern, evidence summary, selected asset mapping, declared capability, or fictional-agent training pattern. Approval and application remain separate; no fictional Circuitkin becomes a real software agent.

## Router profile and community market

`axm.circuitseed-router-profile/v1` is game-local and participant-owned. The future Router seam may exchange explicit export/import copies with conflict reports. This build has no account, public identity, central economy, hosted world, or community market. Local stalls are visible only to the current local session.
