# Known limits

- The package's game world and saves remain browser-local; the managed server owns only the Game Hub launch session and static delivery.
- The declared AI player API exists inside the same browser runtime, but Game Hub has not attached an external adapter transport; this package therefore advertises one human Game Hub seat only.
- Phone and QR controller delivery are not advertised by this integration.
- Visual layout, touch feel, fun, balance and long-session performance still require human playtesting.
- The package's own v0.10 report states that its new infographic browser/render gate was not run before intake.
- The twelve-errand catalog and four-mission tour are deterministically tested, but their 12–18 minute pacing and Laurel values still need a human balance session.
- This install is not canon, production, scientific modeling, real governance, or a connection to Foundation Planet.
