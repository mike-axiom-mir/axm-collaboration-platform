# Living Globe Tycoon · Game Hub intake

Status: **TEST · STEWARDSHIP TOUR EXPANSION**. This is a new, separate island-scale game world. It does not modify, replace, or run on AXM Foundation Planet.

Game Hub slot `010` launches Tycoon Steward by default. A second launch mode opens the walkable Living Island Globe. The supplied v0.10 package is preserved under `runtime/game`; the only AXM additions are the managed local server, Game Hub manifest, source receipt and integration tests.

The world is intentionally smaller than a planet-scale substrate. Its bounded island is the correct playable scale for a casual tycoon; ideas may later travel through explicit proposals, but state does not silently cross worlds.

The walkable local Three.js globe now carries a repeatable four-errand stewardship tour. Two early wins open six harder variants, bringing the deterministic catalog to twelve missions. Starts occur every four active-play minutes, each errand remains open for six, and a complete tour normally asks for roughly 12–18 minutes of island travel, planting, gathering, fishing, fire-building and cooking. Tour rewards remain ceremonial and cannot change treasury, ecology, governance or Foundation state.
