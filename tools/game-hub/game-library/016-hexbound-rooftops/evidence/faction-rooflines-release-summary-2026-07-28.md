Every eight seconds it automatically repairs damaged nearby allied ordinary districts. It excludes itself, Grand Clocks, Wonderworks, enemies, unfinished buildings, full-health buildings, and distant targets. Mixed nearby charters strengthen the pulse through the existing bounded wonderweb, up to x1.45. Rival Thorn expansion keeps the Wonderwork-first contract, then uses Gatehouses for later forward districts.
