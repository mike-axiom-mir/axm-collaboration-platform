# Asset provenance

## Key art

`runtime/assets/hexbound-key-art-v1.png` was generated for this game in this Codex session with the built-in image generation tool. It is original concept art prompted as a future-Halloween fairytale rooftop war with cosmic swashbuckling, eccentric time fantasy, airborne storybook adventure, massed formations, ghost pirates, copper roofs, and no existing franchise characters, logos, vehicles, or locations.

The saved project asset is a copy of the generated output. The source output remains under the local Codex generated-images store.

## Runtime art

All battlefield geometry, roofs, bridges, fog, formations, buildings, particles, HUD components, icons, selection feedback, and minimap marks are drawn with original HTML, CSS, and Canvas code in this package. Text glyphs use system fonts and Unicode symbols. No third-party runtime images, scripts, fonts, or network resources are required.

## Audio

Short interface and combat cues are synthesized at runtime with Web Audio oscillators. No recorded third-party audio is bundled.
