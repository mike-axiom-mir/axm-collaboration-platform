# Tilburg Streetscape Foundation art pass

Current pass: **v0.3.0 — agent visual pass, human visual approval required**

The current art profile is `data/city-art.json` with id `axm-tilburg-streetscape-foundation-v0-3-0`. It is a deterministic presentation layer clipped to the existing Tilburg-derived material masks. It does not claim bespoke address-level buildings or navigation accuracy.

The renderer now supplies readable roads and curbs, paved sidewalks, connected and varied roof components, selective source-aligned markings, water and rail detail, park canopies, sparse street lamps, landmarks, district wayfinding and the existing curated prop overlays.

No collision, spawn, mission, route, territory, controller, save or multiplayer-authority data is changed. No new bitmap art was introduced. Canvas primitives are original project presentation; existing local images retain the provenance recorded in `ASSET_PROVENANCE.md` and the asset manifests.
