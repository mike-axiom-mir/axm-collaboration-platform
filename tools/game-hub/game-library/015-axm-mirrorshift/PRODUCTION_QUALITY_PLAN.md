# MIRRORSHIFT production quality plan

Objective: steward AXM: MIRRORSHIFT beyond the experience quality of current big-budget kart games without pretending that an attractive alpha already meets that bar.

"Better than AAA" is treated as a whole-product gate: precise and expressive driving, readable combat, memorable art and sound, resilient game-night operation, substantial authored content, inclusive controls, representative-device performance, and repeated human steward approval. No single score, screenshot, test suite, or asset can close that gate.

## Promotion rule

The manifest remains an alpha/beta label until every required production capability is `READY`, every release gate has native evidence, representative humans have approved it, and no gate is closed using evidence from the wrong surface. The active thread goal remains open while any required gate is missing, degraded, or unknown.
