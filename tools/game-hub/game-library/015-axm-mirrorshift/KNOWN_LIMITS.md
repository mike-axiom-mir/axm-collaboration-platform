# Known limits

- v0.23 adds four presentation-only Living Circuits identities. A 72,000-pose deterministic sweep proves finite bounds, time-invariant reduced motion, authority immutability, and frozen mechanics. Forge, Gardens, Foundry, and Mirror Core each rendered their named choreography at 1280x720 with no horizontal overflow; active local render work ranged from 1.37-2.87 ms average and 1.8-4.7 ms p95. The preview remained scheduler-limited, no rolling buffer existed, and the requested 390x844 override did not change the live viewport, so V23 responsive composition, high-cadence motion, representative hardware, human response, and art-direction approval remain unknown.
- Living Circuits enriches the three existing tracks and Mirror Core; it is not four new environments, a mechanics expansion, or completion of the broader authored-content gate.
- v0.22 adds the four-character Start Grid countdown reveal and repairs a public lobby hit-test seam where the invisible race HUD intercepted Mirror Core. A 112-pose deterministic sweep plus public Mirror Core, Signal Tour, and reflection Circuit Crown start journeys pass at 1280x720 and 390x844. This proves bounded presentation, pointer ownership, responsive composition, and server-owned transition—not high-cadence target motion, human attachment, physical phones, representative hardware, or art-direction approval.
- v0.21 adds the four-character Mirror Podium result tableau to Circuit Crown, Signal Tour, and Mirror Core. A 112-pose deterministic sweep plus natural race/battle result and rematch journeys pass at 1280x720, and the race debrief fits an explicit 390x844 responsive browser viewport without overlap or inner overflow. This proves bounded presentation and composition, not human attachment, high-cadence target motion, representative hardware, broader animation breadth, or art-direction approval.
- V21's live Mirror Core result measured 2.55 ms average / 3.9 ms p95 local render work, but the in-app browser classified cadence as scheduler-limited and reported 76.4 ms frame p95. This is useful counterevidence against a preview-based 60 fps claim; representative-device profiling and a 30-minute target run remain required.
- v0.20 adds server-authoritative Circuit Crown reflection routes across all three tracks and three signal conditions. Deterministic remapping, 36 reflection races, HTTP/state disclosure, and one complete select-to-result-to-rematch live journey pass. These are reversed traversals of the existing authored environments, not three additional tracks; Signal Tour stays forward-only, and human preference/balance judgment remains open.
- v0.20 upgrades the bounded browser-session Mirror Echo to isolate all 18 circuit/signal/direction identities. Focused direction-isolation/capture/interpolation/bounds tests and a reflection empty-to-seal-to-rematch live journey pass, but this is not a dedicated solo time-trial mode, persistent/shareable ghost system, human replay-preference verdict, or target-cadence proof.

- v0.19 adds the bounded browser-session Mirror Echo: the fastest completed lap for each circuit/signal-condition pairing can replay as a labelled non-colliding hologram on later laps and rematches. Focused capture/interpolation/bounds tests and an empty-to-seal-to-rematch live journey pass, but this is not a dedicated solo time-trial mode, persistent/shareable ghost system, human replay-preference verdict, or target-cadence proof.
- v0.18 adds four presentation-only kinetic vehicle rigs with bounded idle, drive, brake, drift, boost, impact, suspension, wheel, and identity-phase animation. A 108,000-pose deterministic sweep and one live 1280×720 idle/countdown/drive/reset journey pass with local render headroom and no browser warnings/errors. Repeated stills and diagnostics are not a rolling motion capture; target-display cadence, representative hardware, broader character animation/voice breadth, and human attachment remain open.
- This is a top-down playable alpha under active production stewardship; “beyond AAA” is a release gate, not a current claim.
- Circuit Crown includes Mirror Forge, Splitglass Gardens, and Null Foundry plus three signal conditions: three-lap Clear Signal, two-lap Shardline Sprint, and four-lap Redline Gauntlet. Every Circuit Crown pairing supports forward and reflection traversal. Signal Tour composes only the canonical forward routes into one fixed three-round 9/6/4/2 cup. Mirror Echo adds session-local fastest-lap replay, but larger tournament structures, dedicated solo time trials, persistent/shareable ghosts, and additional environment/variant breadth are not implemented.
- Every seat can choose any of the four characters in the lobby from the shared screen or its phone controller. Because character identities remain unique, selecting an occupied driver atomically swaps the two identities; duplicate-character and cosmetic-loadout variants are not implemented.
- The four identities now have unique bounded flourishes, oscillator motifs, signature callouts, phone labels, and winner quotes. Full character animation sets, spoken performances, narrative arcs, alternate costumes, and human attachment/preference evidence remain future production gates.
- Keyboard control is mapped to player one on the shared screen. Additional human seats use the Game Hub phone controller route.
- Physical-phone and mixed-router QA are still pending. Local browser reload, server replacement, dual screen/phone sessions, action acknowledgements, and client-reported round-trip telemetry pass, but they do not prove real Wi-Fi behavior.
- Keyboard layout remapping, light steering, and auto-accelerate are implemented. Arbitrary per-key capture, gamepad remapping/support, attack assists, and dedicated color-vision themes are not.
- There is no online matchmaking, account persistence, unlock economy, track editor, or long-term results history.
- AI races, drifts, hunts arena pickups, scores guard breaks, and uses combat items, but it does not yet learn from human driving style.
- The generated roster key art is concept/key art. In-race karts are deterministic canvas graphics designed for readability, not extracted sprites.
- Audio now has a responsive synthesized engine, event tones, and a deterministic four-profile adaptive procedural score. Human listening, speaker mix, fatigue, and final authored sound-effects review remain open.
- Replacing the authoritative Node process restores controller identity and input but intentionally resets the in-progress match to the lobby; durable mid-match process persistence is not implemented.
- A 30-virtual-minute, 12-rotation lifecycle soak passes locally. It is accelerated deterministic evidence, not a real-time target-hardware thermal, memory, battery, router, or frame-pacing soak.
- v0.11 separates Canvas render work, HUD update work, and request-animation-frame scheduling delay. Redline and Mirror Core render-work p95 stayed at or below 3.3 ms locally, but the in-app preview's frame p95 remained 34.9–55.6 ms and its visual tooling cannot capture high-cadence motion. Representative-device profiling, perceived interpolation smoothness, and a long-duration hardware soak remain pending.
- v0.12 provides an opt-in bounded target-session recorder and compact JSON receipt, but a recorder is not target-hardware evidence by itself. Browser thermal/compositor visibility is incomplete, unsupported Memory/Battery/Long Task APIs are labelled unavailable, an early stop remains `partial`, and the 30-minute hardware/60 fps gate stays open until joined with an external profiler and target-display observation.
- v0.13 provides an opt-in four-seat LAN qualification recorder with per-controller latency, action, heartbeat, reconnect, simultaneous-connection, and input-owner evidence. It never self-certifies physical hardware: host attestations are booleans, the receipt retains no session IDs/IP/user agent/raw actions, and the physical-phone/router gate remains open until a complete 30-minute intended-LAN run is externally observed and reviewed.
- v0.14 corrects the managed-launch transport route: Game Hub children bind all host interfaces while direct standalone launches remain loopback-only unless `HOST` is explicit. Deterministic resolution, a real all-interface socket, and a same-machine private-interface health probe pass locally; this proves the bind path, not firewall policy, router isolation, Wi-Fi stability, or four physical phones.
- v0.15 adds a privacy-bounded start preflight: the 30-minute clock cannot start until P1-P4 each expose exactly one live controller identity, duplicate/stale identities block visibly, and closed duplicates recover after a bounded 15-second telemetry hold. This prevents an already-ineligible run from starting, but local identities remain transport evidence—not proof of four phones, the intended router, or human seat confirmation.
- v0.16 requires each connected controller session to explicitly confirm its assigned seat before qualification can start. Same-session reload preserves that server-held acknowledgement; a fresh session or authority restart requires it again. This closes silent seat-assignment ambiguity in the software flow, but a tap does not prove who tapped, that the client is a phone, that four independent people are present, or that the intended router is in use. The in-app browser's advertised 390×844 viewport override did not change the live viewport during this slice, so current confirmation-layout evidence is limited to the default browser surface and prior phone-breakpoint coverage; a fresh native 390px/physical-touch check remains open.
- v0.17 adds the fixed three-round Signal Tour with server-owned itinerary, cumulative standings, deterministic tie-breaks, debrief/advance/champion/restart presentation, and a full natural local journey across all three circuits. A 390×844 browser override now renders the controller composition without clipping, but a responsive browser is still not a phone: physical touch feel, four independent devices, intended-router behavior, and 30-minute game-night qualification remain open.
