## Browser-primary evidence

Repeated visible browser frames and bounded clicks are required for state,
focus, stretch, zoom, background, safe-area, reduced-motion and A/B claims.
Script compilation and HTTP tests cannot substitute for that evidence. A live
browser journey may support EVIDENCE-UI-STATE-JOURNEY-001 only for the tested
browser wrapper and viewport.

The 2026-08-22 TEST run completed the bounded 12/12 browser journey, observed a
distinct regenerated A/B candidate, preserved the previous candidate after an
invalid edit, and checked the 390x844 responsive layout without horizontal
overflow. Browser console error/warning output was empty. This closes
EVIDENCE-UI-STATE-JOURNEY-001 only at TEST for this wrapper and these bounded
observations; it is not native-runtime or physical-device evidence.

The first responsive check covered a fresh viewer state and was contradicted by
an independent populated-state run that overflowed after create plus nine-slice
720x140 stretch. After min-width containment, the exact populated rerun held the
document to 375 CSS px of scroll width inside a 390 CSS px viewport. The
counterevidence and correction remain part of the TEST history.
