# Element Foundry

Element Foundry is the visible composition surface for `shared/elements/`.
It demonstrates that AXM can manipulate a smaller vocabulary than whole modules
without reducing every element to a UI widget.

The starter catalog covers interface, visual, interaction, spatial, media,
logic, content and fabrication families. Users can place exact-version elements,
inspect their facets and declared category-verifier route, cycle bounded surface
skins, check a composition and explicitly download its contract and receipt.

The eight route identifiers are future verification seams, not eight already
implemented executable verifiers.

The preview is intentionally lively, but remains a preview. A green contract
means exact records, categories, target compatibility, ports, dependencies and
UCP adaptation passed. It does not mean the result executed, rendered correctly,
was visually approved, was manufactured or was installed.

Run focused verification:

```powershell
node shared/elements/selftest.js
node shared/elements/discovery-seam-review.js
node tools/element-foundry/selftest.js
node tools/element-foundry/discovery-seam-review.js
```
