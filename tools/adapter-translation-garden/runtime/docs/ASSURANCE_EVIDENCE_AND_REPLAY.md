# Assurance, evidence chains, replay, and input bounds

Runs 36–40 strengthen the detached garden without activating more authority.

- The assurance index fingerprints identity, code, public API, boundaries, and lineage for every capsule.
- Proof chains are append-only value objects. They do not write logs or approve operations.
- Replay records compare exact fingerprints. They do not silently execute a module again.
- The input guard accepts command-looking and path-looking strings as inert data, but refuses oversized, too-deep, non-finite, or non-JSON structures.
- All claims remain local and bounded to included fixtures and tests.
