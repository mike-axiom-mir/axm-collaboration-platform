# Semantic Truth Rules

1. Never map by similar spelling alone.
2. Require an explicit meaning statement and confirmation for field mapping.
3. Keep unresolved and disputed mappings visible.
4. Never treat identifier equality as identity proof or authority transfer.
5. Never infer a timezone for a naive timestamp without an explicit assumption.
6. Keep axes, origins, units, and handedness explicit.
7. Report Unicode compatibility folding, case folding, trimming, and numeric-locale assumptions.
8. Keep null, missing, unknown, unsupported, redacted, empty, and defaulted states distinct.
9. Sidecars preserve meaning only when callers retain them.
10. Every conversion claim is local evidence, not universal compatibility.
