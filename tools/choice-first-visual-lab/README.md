# AXM Choice-First Visual & Simulation Lab

Status: `EXPERIMENTAL` · installed: false · promoted: false · canonical: false

This bounded lab proves that one game asset identity and causal state can be rendered through independently selected 2D and pixel-styled 3D profiles. The base 3D proof emits eight actual animated GLBs: Ferris wheel, carousel horse, ticket gate, and starter sofa in both `pixel-8bit-3d` and `pixel-16bit-3d`. A second live composer applies exact Style Fabric directions, AetherFX modules, PBR families, and supplied-copy Storycraft boards to the same identities. It emits four treated GLB pilots and six independently verified PBR map sets. It also proves that a complete game can gain a new art-direction pack while its save, simulation, gameplay proxies, and old-machine baseline remain stable. An interior object can still be repaired, refurbished and upgraded without deleting its identity.

The pilot art is original deterministic AXM material. Classic tycoon games inform the readability target only; no commercial sprite, name, map, sound or layout is copied.

## Run

```powershell
node tools/choice-first-visual-lab/selftest.js
node tools/choice-first-visual-lab/build-pilots.js
node tools/choice-first-visual-lab/build-game-visual-proof.js
node tools/choice-first-visual-lab/build-pixel-3d-pilots.js
node tools/choice-first-visual-lab/build-visual-treatment-pilots.js
```

Serve the Workshop and open `/tools/choice-first-visual-lab/` for the interactive game-pack, 2D asset-profile, native WebGL2 3D asset-profile, exact visual-treatment, simulation, sofa and video proof.

## Honest boundaries

- 8-bit and 16-bit are art-direction presets, not literal GPU colour-depth tiers. The 2D outputs use RGBA8/sRGB; the 3D outputs use palette-bounded glTF materials.
- Hardware entries are declared compatibility fixtures, not automatic device detection.
- Recommendations are advisory. A player action is required before activation.
- The baseline 8-bit pack is digest-bound, bundled, installed, and verified against the minimum declared machine fixture.
- Saves and simulation truth do not contain the active visual pack.
- The four pilot identities have executable 8-bit/16-bit 3D representations with real mesh hierarchy and node animation.
- Four pilot GLBs are not a complete walkable whole-game 3D pack; collision, physics, game import, and remaining semantic slots are still missing.
- Style/material/effect identifiers resolve exactly. Unknown requests return `MISSING_VISUAL_CAPABILITY`; no nearest effect is substituted.
- The current GLB route executes base colour, metallic, roughness, emissive light and bounded companion geometry/motion. Clearcoat, sheen, iridescence, translucency, pattern, web-only, token-only and scenario-only semantics remain declared metadata or companion outputs until an exact renderer adapter exists.
- The six PBR previews are local reference renders, not target-engine parity claims. The albedo, normal, packed ORM, emissive and height PNGs are the independently inspectable material deliverables.
- Storycraft uses supplied captions only; it does not infer story or mutate gameplay.
- High-detail realtime 3D and cinematic choices are visible typed gaps, not fallbacks.
- Time alone never changes condition or cleanliness.
- Different sofa branches retain different value vectors. There is no universal best score.
- Mike Tobi remains the human quality and canon gate.
