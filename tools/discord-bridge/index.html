Discord Bridge

LOCAL WORKSHOP · DELIBERATE NETWORK EXIT

Bring the collaboration room to Discord—without putting the Workshop inside Discord.

The app can accept attributed slash-command proposals and post deliberately sanitized action receipts. It cannot read ordinary chat, train Mirror, execute requests, or reveal local credentials.

1

Create the Discord app

Do this once in Discord's official Developer Portal.

  1. Open the Developer Portal and choose New Application.
  2. Name it AXM Workshop Bridge. Discord creates its bot automatically.
  3. Copy the Application ID from General Information.
  4. On the Bot page, reset/copy the bot token. Paste it only into this local screen.
Open Discord Developer Portal ↗
2

Tell the local bridge where it belongs

Numeric IDs are routing addresses, not passwords.

Can't see “Copy ID”?

Discord Settings → Advanced → turn on Developer Mode. Then right-click the server or channel.

3

Store the bot token locally

The browser can write it once but can never read it back.

Never paste this token into chat, GitHub, a screenshot, or an issue. The public packager excludes it.

4

Install it in AXM Workshop

The generated link asks only to view a channel, send messages, and expose slash commands.

Enter Application ID first

Choose your AXM Workshop Discord server on Discord's authorization screen.

5

Choose each permission lane

None of these switches grants broad Discord chat visibility.
