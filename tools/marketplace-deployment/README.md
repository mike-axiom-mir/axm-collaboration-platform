# AXM Marketplace & Deployment

Parent workspace **11** from the consolidated Workshop map.

It unifies the human and machine-facing preparation work around:

- catalog/store listings;
- licensing, provenance and dependency review;
- attributed reviews without reducing taste to one optimizer score;
- plugin and extension distribution proposals;
- download, LAN, static-host and self-host deployment plans;
- gallery drafts; and
- stable, beta and experimental update-channel drafts.

## Real foundation underneath

`Publish & Library` remains independently executable and owns the real artifact inbox, Output Engine, Asset Vault, verified Workshop Packager and launcher-card proposal routes. Marketplace & Deployment embeds that workspace as its distribution foundation; it does not copy its ledger or bypass its gates.

## Honest boundary

This first version has no payment rail, no remote marketplace API, no hosting credentials, no public upload adapter, no automatic installation and no automatic update authority. A deployment plan is inspectable data, not a deployment claim. A gallery entry is a local draft, not a public page. A listing that passes local review is only ready for an explicit export step.

Governance can be `solo` or `dual`. Dual mode requires an attributed human and machine upvote plus a passed rights gate. Solo mode remains available for any user or intelligence, while still requiring an explicit review and rights record.
