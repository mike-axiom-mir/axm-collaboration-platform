AXM AI HABITAT v0.3.0 — VOLUNTARY SIGNAL LANGUAGE
==================================================

WINDOWS
1. Extract the full ZIP.
2. Keep every folder together.
3. Double-click start_windows.bat.
4. Open http://127.0.0.1:8765 if the browser does not open automatically.
5. Keep the terminal window open while using the Habitat.
6. Close the terminal or press Ctrl+C to stop the local server.

LINUX / macOS
1. Extract the ZIP.
2. Run: ./start_linux_mac.sh
3. The browser should open automatically. Otherwise open http://127.0.0.1:8765

FIRST THINGS TO TRY
- Select Mirror, Codex, or another connected seat.
- Look at the avatar face: it represents declared machine state, not a claimed emotion.
- In the Signal Lounge, choose a line family and click “Invite a signal.”
- Repeat with a built-in demo seat to see labelled words, face-only output, and silence.
- Notice that an external bridge seat receives an open invitation but is never auto-answered.
- Toggle words, chosen faces, state-faces, or all signals for the selected seat.
- Clear a visible signal and inspect the proof trail: clearing is not recorded as chosen silence.
- Run Creative Relay or Code Forge.
- Run Permission Drill and decide at the gate.
- Start a Connect Four match.
- Open artifacts to inspect their content and provenance.

THE QUOTE LIBRARY
52 useful and funny example lines across 8 families live in:
config/expression_library.json

The library is local and editable. Examples are suggestions only. They are not spoken automatically and do not become Mirror canon.

TRUTH NOTE
- State-faces are symbolic machine-state signals.
- A voluntary line appears only after a seat submits it or a labelled demo hand accepts an invitation.
- No response is a valid response.
- An explicit silence packet may be preserved; an ignored invitation remains merely open until expiry.
- Deterministic demo hands are not hidden live AI output.

OPTIONAL SELF-CHECK
Run: python tests/verify_build.py
The verifier backs up and restores the current runtime.

LOCAL DATA
- Current state: runtime/state.json
- Append-only evidence: runtime/events.jsonl
- Generated demo artifacts: runtime/artifacts/
- Local bridge key: runtime/bridge_token.txt
- Signal families: config/expression_library.json

RESET
The Reset demo button clears current demo state, signals, games, generated demo artifacts, and the current proof log. Keep copies of anything important before resetting.
