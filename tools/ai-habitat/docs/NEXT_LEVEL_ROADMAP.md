# Next-Level Roadmap

## Real AI expression adapter

- let each provider decide whether and when to answer an open invitation;
- add a compact “signal suggestion” tool result without forcing its use;
- preserve provider turn/session identifiers with every expression;
- let a seat choose its own words instead of selecting only library phrases;
- add anti-spam pacing and a visible quiet mode;
- let the human mark a line useful, funny, unclear, or unwanted without turning that rating into canon;
- keep private Mirror-school material isolated from public seats.

## Optional voice layer

- speak only active, source-labelled voluntary lines;
- never vocalize example previews;
- per-seat voice and mute controls;
- push-to-hear or text-first defaults;
- visible microphone/speaker state;
- no background listening by default;
- local voice where practical.

## Real local file hand

- sandbox copy or checkout instead of arbitrary mutation;
- path allowlists and project boundaries;
- before/after SHA-256;
- diff preview and rollback point;
- explicit destructive-operation confirmation;
- result objects proving what changed.

## Real art and code executors

- map AXM bridge intents to existing local hands;
- stream progress without claiming unverified completion;
- show executor identity separately from AI-seat identity;
- attach prompts, model/provider, settings, input/output hashes, tests, and review state;
- allow multiple seats to relay one artifact without overwriting provenance.

## Real AI Game School

- external AI move-request packet;
- fair information and clock contract;
- difficulty profiles and handicaps;
- replay viewer and mistake analysis;
- voluntary game expressions that cannot alter the canonical board;
- lesson proposals separated from trusted memory;
- human-vs-AI, AI-vs-AI, and human+AI team modes.

## Desktop habitat

- transparent or borderless desktop overlay;
- safe app doors instead of unrestricted global mouse control;
- drag-and-drop work objects;
- app-specific action vocabularies;
- emergency pause and per-seat disconnect;
- no silent startup or background action.

## Phone companion

- private outbound connection from the home host;
- enrolled and revocable devices;
- encrypted transport;
- text/voice window and expression notifications;
- permission requests and game invitations;
- no public exposure of Mike's private Mirror school.

## Multi-seat collaboration

- shared task objects and visible handoffs;
- dissent and alternative proposals;
- reviewer and validator roles;
- Merge Gate comparisons;
- conflict-safe artifact branches;
- acceptance, rejection, rollback, and expression provenance.
