# Design Lineage Lab

The Lab is the intake surface for compact lessons extracted from visual pressure
tests. It is deliberately not an image archive, chat importer, visual judge, or
Asset Fabric promotion gate.

## Intended future intake flow

1. Preserve an original chat/archive outside the active Workshop.
2. Extract small design observation receipts with source references and, when
   available, the exact source SHA-256.
3. Compile one bundle in this Lab.
4. Review exact duplicates, repeated lessons, contradictions, and partial
   provenance.
5. Explicitly export the compact ledger.
6. Route selected vocabulary candidates through independent review before any
   Fabric or Studio adoption.

This allows years of platform design work to teach the Workshop without importing
the full generation flood or pretending deterministic text matching understands
visual semantics.
