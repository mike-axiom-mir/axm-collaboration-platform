# AXM Technical Glasses

Technical Glasses is the AI Team view over the shared live compiler in `shared/technical-glasses`.

It exists so a fresh Codex task, another cloud chat, Mirror or a future connected model does not have to reconstruct the Workshop from memory. The view shows the current source fingerprint, body state, focus routes, module evidence and important open seams.

The interface refreshes every 30 seconds while visible. The server recompiles the underlying result on every request. Its Human review card uses the same shared structural-readiness observer as the Workshop Needs Observatory, so both surfaces agree about whether the deterministic tools index is current.

A displayed review candidate is only current evidence for Mike to inspect. It is not approval, promotion, CANON status, runtime proof or a satisfied need. If the evidence is stale, invalid or unavailable, the card says so and displays no candidate count. Nothing is repaired, opened, approved or promoted automatically.
