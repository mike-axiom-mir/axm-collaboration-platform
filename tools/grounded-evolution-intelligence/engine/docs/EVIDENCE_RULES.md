# Evidence and Source Integrity Rules

Every evidence record must retain:
- stable evidence ID;
- source type and exact source location;
- SHA-256 source hash;
- capture timestamp;
- extraction method;
- relevant entity scope;
- claims supported;
- truth state and confidence;
- limitations;
- metadata needed to interpret the source.

Evidence records are references, not permission to rewrite the original source.
A missing or inaccessible source must be marked, not silently replaced with a summary.
Human statements and AI declarations are valid evidence types for what was said, but not automatic
proof that the underlying claim is true.
