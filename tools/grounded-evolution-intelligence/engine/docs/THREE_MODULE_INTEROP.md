# Three-Module Interoperability

## Module 1 — Human Capability Atlas
Exports capability identities and Capability Card references. Module 3 may evaluate evidence,
dependencies, gaps, and ecosystem reach but must not silently rewrite the human explanation.

## Module 2 — Human Interface Intelligence
Exports interface assessments tied to capability IDs, target humans, environments, resources,
reasons, unsuitable conditions, and evidence. Module 3 may identify missing interfaces or weak proof.

## Module 3 — Grounded Evolution Intelligence
Consumes records from Modules 1 and 2, maps relationships, emits improvement needs, research needs,
and evolution directions, then tracks intervention outcomes.

## Shared loop

Capability record -> interface reference -> grounded diagnosis -> proposed direction -> verified
intervention -> updated evidence and records.

Exchange packets always carry sender, receivers, contract version, payload identity, evidence,
truth state, and source snapshot hash.
