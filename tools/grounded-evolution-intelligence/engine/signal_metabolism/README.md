# Precanonical Signal Metabolism

This subsystem sits **before** the canonical factual kernel.

It allows Module 3 to preserve messy take-ins, mistakes, contradictions, failed preflights, research
leads, and feedback without confusing any of them with established facts.

Run:

```bash
python signal_metabolism/signal_engine.py
python signal_metabolism/signal_yield.py
```

The subsystem deliberately uses its own schemas and hash chain so the stable three-module shared
contract `0.1.0` does not need to change immediately before Module 1 + Module 2 + Module 3 intake.
