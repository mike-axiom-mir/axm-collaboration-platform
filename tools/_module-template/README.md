# New AXM module template

As of 2026-07-23, this is the source template for a new Hub module.

Before discovery, replace every `CHANGE-ME`, keep `id` equal to the folder name, declare `kind`, `uses`, and `permissions`, fill the module contract, and add a real selftest plus a discovery seam review. `verifiedAt` remains `null` until the current source has passed its declared verification route. A passing selftest does not promote a tool automatically.

The HTML establishes the current static accessibility floor: a 16 px base, 44 px interactive controls, explicit label association, and visible keyboard focus. Rendered contrast and complete keyboard behavior still require runtime checks.
