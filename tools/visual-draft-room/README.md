# Visual Draft Room

Human/machine visual draft workbench above the bounded Raster Compositor Hand.
It works without AI, supports up to 32 deterministic layers, and accepts a
verified Neural Room proposal only after an explicit import.

The canvas is a responsive browser preview, not an exact verification claim.
Export `axm.raster-composition/v1` and run the registered compositor hand for
exact pixels, PNG round-trip validation and a receipt. Hub checkpoints retain
recipe metadata but deliberately omit raw image bytes; self-contained draft
exports are explicit user actions.
