# Mirror Holo Shoebox

The Mirror Holo Shoebox is the first observer-first surface for `axm.experiment-world/v1`.

It provides:

- a disposable in-memory artifact graph;
- open known and unknown artifact kinds;
- a transparent spatial projection of artifacts and links;
- world, anatomy, evidence and timeline projections;
- the same structured sensor frame for human or machine observers;
- deterministic Mirror-compatible rehearsal pulses;
- a typed machine-intent port for a future live Mirror capability broker;
- declared intent time, storage, compute and artifact ceilings;
- explicit checkpoint save, restore and download;
- freeze-for-review without automatic promotion.

## Honest v0.1 boundary

The live Mirror broker and isolated code execution host do not exist here yet. Rehearsal pulses are deterministic local fixtures. The module refuses network use, process execution, credentials, installation, publishing, outside-filesystem writes and canonical changes.

Resource values are request declarations enforced inside the deterministic
rehearsal. They are not measured CPU, memory, storage or billing telemetry.
Only the allowlisted `candidate-memory` effect is admitted; every outside or
unknown effect is held.

The holographic globe is an observer projection. It does not grant authority.
