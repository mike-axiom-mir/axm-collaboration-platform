# Godot adapter

Store roles as Theme resources or `AXMTextRole` resources. Avoid fixed-height text containers, enable smart wrapping, define font fallbacks, and place outlines/shadows outside the readable core.

## Shader / material pack

Included starter hands:
- `AXMTextRole.gd`
- `AXMTextFxResource.gd`
- `axm_text_fx.gdshader`

Use the shader for premium hero text, menu banners, reward labels, or futuristic HUD emphasis.
Keep dense body text cleaner and simpler.
