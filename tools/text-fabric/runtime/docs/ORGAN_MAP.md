# Organ Map — AXM Text Fabric v1.0.0 RC

1. **Typography Role Organ** — decides what the text is.
2. **Responsive Scale Organ** — decides how large it must be here.
3. **Contrast Guardian** — decides whether the foreground is safe.
4. **Background Separation Organ** — creates a stable surface under text.
5. **Effect Stack Organ** — adds style in a safe layer order.
6. **Rendering Strategy Organ** — chooses native raster, SDF, or MSDF guidance.
7. **Localization Fallback Organ** — protects scripts, direction, and glyph coverage.
8. **Motion Safety Organ** — adds restrained motion with reduced-motion fallback.
9. **Data Typography Organ** — stabilizes numerals and counters.
10. **QA Regression Organ** — defines stress and release checks.
11. **Copy Readability Organ** — checks text density and casing.
12. **Platform Adapter Router** — translates one plan into platform hints.
13. **Material Finish Organ** — maps gold, silver, chrome, neon, and holographic surfaces.
14. **Sheen / Highlight Organ** — adds controlled reflection and highlight motion.
15. **Glitch Safety Organ** — keeps futuristic distortion readable.
16. **Shader Routing Organ** — maps premium effects to engine-native material strategies.
17. **Preset Gallery Organ** — packages transparent, searchable starting combinations.
18. **Render Cost Budget Organ** — scales effects to hardware quality tiers.
19. **Preset Workshop Organ** — saves, imports, replaces, and removes local custom presets.
20. **Bundle Integrity & Rollback Organ** — adds snapshots, locks, hashes, verification, and regeneration paths.
21. **Batch Library Compiler Organ** — compiles selected or full preset libraries across platforms.
22. **Glyph, Script & Fallback Audit Organ** — inspects Unicode direction, controls, scripts, and fallback requirements.
23. **Static Asset Fallback Organ** — produces portable SVG and optional PNG proof assets.
24. **Visual QA Matrix Organ** — renders quality-tier comparison matrices with hashes.
25. **Actual Font Coverage Organ** — verifies local TTF, OTF, and TTC glyph coverage.
26. **Font Capability Registry Organ** — records metadata-only local font capabilities.
27. **Font Fallback Planner Organ** — chooses a minimal registered stack for required characters.
28. **Layout Resilience Organ** — estimates wrapping, line budgets, and overflow risk.
29. **Pseudo-localization Stress Organ** — generates accented, expanded, and pseudo-RTL variants while preserving placeholders.
30. **Safe Area & Viewing Distance Organ** — applies platform edge and minimum-size guidance.

The resolver orchestrates these organs but does not own their data. Tokens, recipes, presets, audits, and generated bundles remain independently inspectable and replaceable.
