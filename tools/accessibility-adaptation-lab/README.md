# AXM Accessibility Adaptation Lab

The lab turns the curated Accessibility & Adaptive Interfaces intake into a
usable AXM surface without pretending its synthetic evidence is field proof.

- Search and inspect all 100 disabled source packets across ten families.
- Enter explicit goals and receive a bounded, explainable module shortlist.
- Preview text scale, contrast, spacing, density, focus, and plain-language
  presentation inside this tool only.
- Save or reset the preview profile in browser-local storage.

The lab never diagnoses a person, silently alters the wider Workshop, activates
source packets, or asserts WCAG, device, assistive-technology, production, or
real-world accessibility conformance.

## Verify

node tools/accessibility-adaptation-lab/selftest.js
