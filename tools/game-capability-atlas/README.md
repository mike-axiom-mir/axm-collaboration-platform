# AXM Game Production Atlas

The Atlas makes the 500 unique Run-111 game-production modules searchable and
turns selected modules into an `axm.game-capability-plan/v1`. Its default plan
is the source-authored first balanced wave: one module from each of 20 domains.

Open it directly from the Workshop or use the **Production Atlas** view inside
Game Forge. Attaching a plan is an explicit action. The Atlas does not generate
or install game code and does not claim that static knowledge passed a real
playtest.

Run:

```powershell
node tools/game-capability-atlas/selftest.js
```
