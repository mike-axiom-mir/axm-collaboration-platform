# AXM Memory & Continuity Garden

This working local tool makes the Run 100 memory and continuity reference garden searchable, inspectable, and independently verifiable.

The 100 internal records are unique sealed reference candidates. They are not represented as finished semantic implementations. Their original risk, posture, provenance, non-claims, and review gates remain intact.

## Commands

```powershell
python memory-cli.py --list
python memory-cli.py --search continuity
python memory-cli.py --describe axm.memory.session-handoff-packet
python memory-cli.py --validate
node selftest.js
```

The tool grants no permissions and performs no memory writes, installation, networking, orchestration, promotion, or CANON change.
