# Human Usability, Search, and Learning

## Coverage audit

A capability is not counted as usable because a manifest exists. The audit checks:

- source integrity;
- human explanation;
- interface readiness;
- learning readiness;
- safety readiness;
- evidence readiness;
- relationship integrity.

Unresolved conflicts, missing provenance, absent plain explanations, and unsafe high-risk exposure remain explicit blockers.

## Search

The local search engine uses an inverted index and published field weights. It requires no language model. Results list the tokens, fields, and score contributions that produced the ranking.

## Learning paths

An ecosystem path follows both capability dependencies and learning prerequisites. Dependencies appear before the target. Missing records and cycles are reported; they are not silently discarded.
