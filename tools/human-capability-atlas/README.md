# Human Capability Atlas platform module

AXM Module 1 is installed as a `TEST` machine capability. The supplier engine is byte-preserved in `engine/`; the original intake ZIP and handoff lineage are under `intakes/tri-20260809`.

Use `run.ps1` to call the Atlas CLI through the isolated workshop Python runtime. The platform does not automatically run a real-registry materialization, write to source declarations, or promote generated evidence to runtime proof.
