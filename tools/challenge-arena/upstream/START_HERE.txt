AXM CHALLENGE ARENA v0.6.0 — START HERE
========================================

PURPOSE
-------
Reusable challenge module for code, Hands, organs, assets, games, video,
research, documents, and future artifact types.

Same locked challenge -> independent attempts -> deterministic evidence ->
assigned blind review -> synthesis/merge proposals -> explicit human decision.

WHAT v0.6 ADDS
--------------
1. Evidence ZIP verification is independent of ZIP member ordering.
2. Observer progress exposes counts/readiness, not per-seat identity lists.
3. Observer integrity exposes aggregate validity, not forensic identity detail.
4. Observer lineage exposes topology/counts, not copied participant ids or
   selected blind labels.
5. Observer HTTP errors hide raw exception text.
6. Additional same-origin browser isolation headers.
7. Reusable randomized bundle portability audit tool.
8. v0.5 scoring, opaque aliases, revision preconditions, task binding,
   independence evidence, and replay behavior remain preserved.

TRUSTED VS OBSERVER READS
-------------------------
Trusted local adapters may use the detailed Python methods such as progress(),
verify_integrity(), and lineage_view().

The HTTP observer intentionally uses public_progress(), public_integrity_view(),
and public_lineage_view() so normal dashboards cannot become identity side
channels. Use the CLI/Python API for forensic detail.
