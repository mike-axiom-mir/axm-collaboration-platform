# UI-FX Composer

Governed TEST integration of the reusable effect batch from `exports/ui-fx/`.

- The reusable classes and optional helpers live in `shared/elements/axm-ui-fx.css` and `.js`.
- Every effect remains a removable class rather than a hard-wired skin.
- `--fx-accent` defaults to Visual Kernel's `--axm-brand`; `--fx-accent2` defaults to `--axm-action`.
- The composer previews and copies recipes. It never edits a host, approves appearance, installs a theme or promotes canon.
- Reduced-motion disables nonessential movement.

The source export remains untouched as provenance. See `WORKSHOP_INTAKE_RECEIPT.md`.
