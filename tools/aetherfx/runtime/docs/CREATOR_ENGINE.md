# Creator Engine

## Simple surface, inspectable depth

The human-facing surface offers Guide, scene, preset, mood, quality, intensity, depth, motion, and protection controls. The generated recipe, stack, dependencies, fallbacks, renderer intent, and provenance stay inspectable underneath.

## Guided Creation

Guide translates outcome, mood, energy, device target, and accessibility preferences into a normal recipe. It does not create a private or irreversible representation. Every chosen module can be inspected, tuned, removed, or exported.

## Derived creation

A derived module stores a unique ID, version, base relationship, tuned defaults, inherited safety metadata, and provenance. The composer resolves the base rather than copying adapter code.

## Composite creation

A composite captures enabled layers as an ordered graph. Children keep module IDs and values. Composites can nest; cycle detection blocks recursive loops.

## Promoted controls

A composite may expose 4, 6, 8, or 12 child controls at its top level. Each control stores an explicit parent parameter, child layer, and child parameter binding. Compilation routes the value into the child; expansion writes the current value back into the restored child layer.

## Review, repair, and compound growth

- Raw recipe review validates the submitted document before normalization and shows normalization changes before confirmation.
- Import Review validates the complete sealed package against a staged registry before transactional commit.
- Repair analyses the current recipe and proposes bounded corrections.
- Snapshots protect the recipe and custom module definitions together.
- The Dependency Graph preserves source relationships.

“Self-improving creator” means human-approved outputs can become inputs for stronger later compositions. It does not mean autonomous source rewriting.

## Discipline

1. Start from the smallest sufficient module or Guide result.
2. Inspect the graph and performance contributors.
3. Test fixed low quality and Auto mode.
4. Check reduced motion, photosensitive-safe mode, contrast, and readability.
5. Save a derived module only when tuning is reusable.
6. Capture a composite only when the relationship is reusable.
7. Promote only controls people genuinely need.
8. Snapshot before replacement or repair.
9. Review provenance and licence before public release.
10. Version shared modules rather than silently rewriting them.
