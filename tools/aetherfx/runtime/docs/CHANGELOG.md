# Changelog

## 1.3.0 — 2026-07-28 — Contract & Runtime Truth

- Added raw-recipe validation before normalization. Valid normalization changes are now displayed for explicit confirmation; invalid raw documents are not silently repaired into defaults.
- Made sealed-package integrity required and package import transactional. Full package graphs are staged, cycle-checked, bounded, and committed only after complete validation.
- Hardened module and recipe contracts around renderer types, scopes, interactions, class tokens, CSS-variable bindings, color values, generated counts, package size, recipe layers, and recursive depth.
- Added complete recipe-plus-custom-module snapshots with validated atomic restore and honest legacy snapshot behavior.
- Corrected photosensitive-safe CSS coverage for the sweep and shimmer layers actually emitted by the adapter and added explicit catalog metadata for photosensitive safety.
- Added the canonical `axm.resolved-visual-intent/1` contract, target profiles, per-operation support status, and exportable adapter-support reports.
- Added a dependency-free portable runtime in browser-global and ES-module forms plus a local validate/compile/inspect CLI.
- Upgraded static SVG generation to resolve derived and composite graphs, quality fallbacks, bounds, exclusivity, and unsupported interactions.
- Hardened the local server against malformed paths, traversal, sibling-prefix escapes, symlink escapes, unsupported methods, and outside network connections.
- Added `targetRole` routing intent and fallback provenance to resolved operations.
- Declared the primary material collision group explicitly for liquid-glass and crystal-prism modules.
- Kept the canonical catalog at 64 modules; this release strengthens the roots instead of adding effect volume.
- Preserved v1.2 browser screenshots as historical comparison material only. Current v1.3 claims depend on evidence regenerated from the current source state.

## 1.2.0 — 2026-07-28

- Added Guided Creation that converts human outcome, mood, energy, device, and protection choices into a normal inspectable recipe.
- Added Performance Inspector with estimated load, largest contributors, measured frame history, low-percentile frame rate, and adaptive transition history.
- Added adaptive quality biases for battery, balanced, and quality preferences without rewriting saved recipes.
- Added photosensitive-safe mode alongside reduced motion, high contrast, and large text.
- Added Dependency Graph and bounded Repair Center with protection snapshots.
- Added non-mutating Import Review with integrity, collision, dependency, and licence checks before commit.
- Added self-contained Web Component export.
- Added practical web Custom Element, Godot 4, Unity UI Toolkit, and static-SVG integration helpers.
- Added deterministic 320-layer stress coverage, package-preview tests, repair tests, integration tests, and v1.2 browser/phone/visual-regression evidence.
- Kept the canonical catalog at 64 modules; this release hardens usability, safety, recovery, and integration rather than adding decorative volume.
