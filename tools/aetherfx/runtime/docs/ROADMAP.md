# Roadmap

## v1.0 — foundation complete

Declarative catalog, web renderer, scenes, typed controls, creator engine, validation, local recovery, package import/export, standalone HTML, SVG approximation, and generic adapter contract.

## v1.1 — visual and recursive capability complete

64-module catalog, optical-illusion organs, promoted controls for composites, sealed cinematic molds, concrete handoff formats, and initial browser regression evidence.

## v1.2 — final isolated hardening complete

- Guided Creation with inspectable output
- Dependency Graph and Repair Center
- Import Review before mutation
- adaptive performance governor and load inspector
- reduced-motion and photosensitive-safe paths
- Web Component export and practical integration kit
- deterministic 320-layer stress test
- desktop, phone, network-isolation, and visual-regression evidence

## v1.3 — contract and runtime truth

- raw validation before explicit normalization review
- required sealed-package integrity and transactional import
- bounded renderer inputs, graph depth, package size, and generated layers
- recipe-plus-custom-module snapshots
- corrected photosensitive-safe runtime coverage
- canonical resolved-intent and target-support contracts
- dependency-free portable runtime and local CLI
- composite-aware static SVG adapter
- contained local server

The catalog remains at 64 modules. v1.3 strengthens trust, reuse, and adapter honesty rather than adding decorative volume.

## Next phase — real product integration

The next useful work is not another isolated effects run. Integrate AetherFX into one real AXM surface, such as:

- Workshop launcher or module shell
- game HUD or scene overlay
- public-safe marketing surface
- local tool/dashboard

Record implemented, approximated, contract-only, and unsupported visual intents and implement only the adapters demanded by real use.

## Later native adapter branches

- Godot CanvasItem/material runtime
- Unity UI Toolkit/URP runtime
- Unreal UMG/material-intent runtime
- Canvas/WebGL heavy-scene runtime
- static compositing pipeline

## Expansion gate

No catalog growth should outrun readability, accessibility, performance evidence, rollback, provenance, and adapter truth. A smaller proven fabric is stronger than hundreds of presets with hidden dependencies.
