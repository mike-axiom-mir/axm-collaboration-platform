# Example Recipes

Each file is an editable `axm.visual-recipe/1` document and can be imported through the studio.

- `command-dashboard`: balanced glass command surface.
- `luminous-hero`: atmospheric website or presentation hero.
- `game-hud`: sharper holographic game-interface treatment.
- `launcher`: restrained dark local-tool launcher.

Examples use stable instance IDs for readable diffs. The studio may assign fresh IDs when creating new layers.
