# Static SVG bridge

Create a deterministic documentation or fallback approximation from a recipe:

```bash
python adapters/static/render_recipe_to_svg.py examples/recipes/command-dashboard.axmrecipe.json --output dist/command-dashboard.svg
```

SVG keeps layout, major surfaces, gradients, and selected glows. Motion, pointer interaction, true blur chains, particles, and engine post-processing are recorded as approximation limits rather than silently claimed.
