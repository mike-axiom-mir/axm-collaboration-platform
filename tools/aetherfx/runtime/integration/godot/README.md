# Godot 4 bridge

1. Export a `*.godot-theme.tres` starter from the AXM adapter examples.
2. Copy the `.tres` and `AXMAetherTheme.gd` into the Godot project.
3. Attach the script to a node, assign the root `Control`, and assign the Theme resource.
4. Rebuild dynamic effects such as caustics, particles, beams, and parallax with native Godot shaders or particles, using the matching `*.visual-intent.json` as the source contract and `*.support.json` as the explicit gap report.

The generated `.tres` files are intentionally conservative theme approximations, not fake full shader ports.
