# Compute Substrate Lab CLI

Compile and verify compute-substrate research packages, derive evidence ledgers,
and govern a provisional historical working root. Use
`node tools/compute-substrate-lab/cli.js help` for commands.

The selected formal root is 1837. Earlier candidates cannot replace it without
two independent digest-bound evidence surfaces and an exact named-human
`WORKING_ROOT_ONLY` decision. Output writes are explicit, external, real-path
checked, and non-overwriting. No command runs a benchmark, controls hardware,
deploys an architecture, or declares CANON.
