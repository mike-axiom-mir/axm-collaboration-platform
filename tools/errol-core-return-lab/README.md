# Errol Core Return Lab

Status: **EXPERIMENTAL**

Installed: **false**

Promoted: **false**

This is a bounded private-local derivative of the useful parts of Errol
Salazar's returned core architecture. It does not install the supplied Python
package or make that package a second AXM center.

## What was integrated

1. **Epistemic orientation seam**
   - content-bound observations without raw-payload retention;
   - typed claims with evidence/model/authority lineage checks;
   - expiring, reversible attention frames;
   - expression projections labelled as current model views, not landscape,
     target, or total identity.

2. **Evidence-gated triad hypotheses**
   - exactly three named members and distinct role contributions;
   - evidenced relationships and all three pair baselines;
   - measured joint synergy and description compression;
   - replicate stability, provenance, counterevidence, alternatives, and
     falsification requirements;
   - fixed no-canon/no-promotion/no-merge/no-execution authority.

The browser workbench is in `index.html`; the same pure contracts are available
to Node through `core.js`.

```powershell
node tools/errol-core-return-lab/selftest.js
```

## What stayed mapped or deferred

- Archive inventory, whole-archive hashing, and central-directory path/structure
  holds remain with Archive Intake Cartographer and existing Workshop intake
  probes. That organ intentionally does not claim decompressed-content integrity.
  This source archive was independently checked against its embedded 91-file
  SHA-256 ledger for this intake; a generalized deep-content verifier remains
  deferred.
- Evidence receipts remain with Evidence Desk.
- Local module grants remain with the permission service. Errol contributor
  notices are a different rights question and were not silently mapped to local
  module permissions.
- Package return and rollback remain with Workshop package-return/intake tools.
- Full model commits, target proxies, contributor-notice resolution, and live
  shadow loading remain deferred pending a demonstrated local gap and current
  authority evidence.
