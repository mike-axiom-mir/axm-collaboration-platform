## r/selfhosted New Project Megathread

**Project Name:** AXM Workshop

**Repo / Website:**
- https://github.com/mike-axiom-mir/axm-collaboration-platform
- https://mike-axiom-mir.github.io/axm-collaboration-platform/

**Description:** AXM Workshop is an experimental local-first modular workshop for creative work, games, projects, research and human + AI collaboration. The full Workshop is designed to run on the user's own device; the website is a small no-account browser doorway rather than a hosted replacement for the local system.

**What it is trying to solve:** I wanted collaboration with AI and software tools without making a cloud account, subscription, or opaque automation layer the owner of the work. AXM keeps local files, visible review boundaries, portable project records and explicit authority as first-class parts of the design.

**Current features / areas:** creative studios, project and knowledge tools, local game workflows, human/machine collaboration seats, evidence and review systems, diagnostics, packaging and bounded automation. The public README links to the capability map and machine-readable registry rather than claiming every declared capability is production-ready.

**How to try it:** The browser doorway works without an account. For Windows, the current reviewed source package can be extracted and opened with `OPEN_AXM_WORKSHOP.cmd`; macOS/Linux currently require a compatible Node.js installation. Exact current limitations are kept in `STATUS.md`.

**AI transparency:** AI tools and coding agents have contributed to design, implementation, testing and documentation under human direction and review. The project itself is explicitly about human + AI collaboration, so that involvement is not hidden.

**Current boundary:** AXM is experimental, not production-certified, and the public repository currently does not grant a broad open-source license. I would rather leave those limits visible than market past them.

Feedback from people who actually self-host or work local-first is welcome, especially around first-run friction, understandable permissions and portability.
