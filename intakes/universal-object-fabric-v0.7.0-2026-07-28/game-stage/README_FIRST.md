# AXM staged game integration kit — v0.7

Status: STAGED-NOT-INTEGRATED
Source release: 0.7.0
Assets: 10

Start with `STAGE_MANIFEST.json`, then `STAGE_RESOLUTION_MAP.json`. Each row resolves the runtime manifest, Universal Object manifest, Runtime Capsule and visual-skin binding without inferring an overlay version.

This stage contains no STL or 3MF files and does not modify an active game. The receiving game still owns physics, gameplay, renderer-specific effects and final acceptance.
