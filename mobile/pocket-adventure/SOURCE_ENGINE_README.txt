AXM POCKET ADVENTURE ENGINE 0.1.0

FILES
- AXM_Pocket_Adventure_Engine_v0.1.0.html: the permanent, content-free, single-page phone engine.
- AXM_Adventure_Engine_Compatibility_Cartridge_v1_0_0.zip: a tiny external compatibility cartridge. It is not embedded in the engine.

PHONE TEST
1. Put both files on the phone.
2. Open the HTML in a Chromium-based browser.
3. Tap TAKE IN.
4. Select the compatibility cartridge ZIP directly; do not extract it.
5. Play the two-scene check, select the Silver Thread under Items, and try it on different choices.
6. Tap NEXT PROMPT to verify the deterministic handoff.

ARCHITECTURE
- Imported binary assets live in IndexedDB, not in the HTML or localStorage.
- ZIP entries are read one at a time.
- Current scene/map assets are lazy-loaded as Blob URLs.
- New packs are append-only unless an explicit revision-checked patch operation is declared.
- Continuation packs must carry the exact builtFromStateHash and generation sequence generated by the phone.
- The preferred ZIP method is STORE / zipfile.ZIP_STORED.

IMPORTANT
Browser storage belongs to the browser/file origin. Keep the original cartridge ZIPs as the recoverable source of artwork. The engine can safely undo the most recent intake only before additional play changes the state.
