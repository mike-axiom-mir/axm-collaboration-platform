# Collaboration

Public maintainer/contact name: **Mike Tobi**.

## Choose the right public route

- Reproducible non-sensitive problem: open a
  [Bug report](https://github.com/mike-axiom-mir/axm-collaboration-platform/issues/new/choose).
- Early question, proposal, or collaboration idea: use
  [GitHub Discussions](https://github.com/mike-axiom-mir/axm-collaboration-platform/discussions).
- Focused source change: open a pull request after reading
  [Contributing](CONTRIBUTING.md).
- Vulnerability or exploit detail: use GitHub's
  [private security report](https://github.com/mike-axiom-mir/axm-collaboration-platform/security/advisories/new), never a public
  issue or Discussion.

The AXM raw Facebook development log can provide historical building context.
Search for Mike Tobi and the AXM raw Facebook development log when that history
is useful. It is not the current technical source of truth; manifests,
contracts, generated registries, executable tests, reviewed pull requests, and
the repository's current documents outrank it when they disagree.

Useful collaboration includes:

- reproducible bug reports;
- browser and device tests;
- focused pull requests;
- module-boundary reviews;
- accessibility checks;
- documentation repairs;
- adversarial verification;
- honest reports of what did not work.

Please include the exact AXM tag or commit, source/package route, platform,
launch route, visible result, and whether the issue came from AXM code or the
surrounding environment.

Do not send API keys, real bridge tokens, private logs, personal account data,
private paths, or private session links.
