AXM WORKSHOP — TOOL FACTORY v0.2 EXPERIMENTAL REPORT
Generated: 2026-07-11

VERDICT

Agent Tool Forge is now a usable draft-only software foundry rather than a display card.
It can create a bounded draft, validate it, render a complete file set, calculate deterministic SHA-256 fingerprints, preview every generated file, save/resume locally, and export an actual module ZIP or review JSON.

It still cannot install, overwrite, execute, promote, or canonize. Those remain later governed steps.

FACTORY ARCHITECTURE

Human Hub screen -> index.html -> forge-core.js
Machine host adapter -> machine.js -> forge-core.js

Both doors use the same normalized draft, validation, render, and fingerprint logic.
The machine adapter requires a host-supplied authorization decision and refuses unknown actions, including install.

PACKAGE TYPES

- Foundation tool
- Hub module
- Dual-door tool
- Proposal-only analyzer
- Machine-only capability

Every generated manifest starts EXPERIMENTAL. Risk is a separate LOW / MEDIUM / HIGH field.

KNOWN NON-GOALS / NEXT GATES

- No governed Module Installer yet.
- No Machine Host yet.
- No arbitrary-code Code Forge yet; this is the safer skeleton composer.
- No module may promote itself.
- Approval is not yet persisted as actor + action + exact package hash.
- Command Center remains a SHELL and still needs its own package-assembly UI.
- Main Hub module remains a SHELL; the operational one-inner-screen experience is /hub/.
