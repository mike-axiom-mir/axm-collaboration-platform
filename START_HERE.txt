START HERE - AXM WORKSHOP
=========================

If you clicked a launcher on the GitHub website and saw code, nothing broke.
GitHub previews source files; it cannot run a local app from the web page.

1. On GitHub choose Code > Download ZIP, then extract the complete ZIP into a normal
   fully local folder.

   Recommended:
     C:\AXM_WORKSHOP\

   Avoid an online-only OneDrive Desktop or other cloud-placeholder folder.

2. Open the extracted folder and double-click OPEN_AXM_WORKSHOP.cmd.

   The browser opens the correct AXM Hub address automatically. No manual URL,
   port, file merge, or patch step is required.

   Do not run the launcher from inside the ZIP.
   RUN_AXM_ALL.bat is a compatibility name for the same beginner route.
   START_AXM_FULL.bat is the advanced route for optional local services.

3. In the Hub, open Test Room and run the checks when you want to inspect
   readiness. You can explore the Workshop without connecting an AI.

   CLAIMED  discovered, not opened yet
   TEST     opened and ready for checks
   WORKING  checks passed
   SAVED    checkpoint/reload persistence confirmed

   The internal compatibility value behind TEST remains NEEDS VERIFY.

REQUIREMENT
-----------
The core server needs Node.js. A portable release can bundle it at
runtime\node\node.exe; a source download uses the free Node.js LTS installation
from https://nodejs.org/en/download. No npm install, account, API key, or AI
connection is required for the core Hub.

TOOL FACTORY BOUNDARY
---------------------
It can draft, validate, render, fingerprint, preview, save/resume, and export.
It cannot install, overwrite, execute, delete, promote, or canonize.

NEED HELP?
