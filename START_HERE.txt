START HERE - AXM WORKSHOP
=========================

If you clicked a launcher on the GitHub website and saw code, nothing broke.
GitHub previews source files; it cannot run a local app from the web page.

1. On GitHub choose Code > Download ZIP, then extract the complete ZIP into a
   normal fully local folder.

   Recommended:
     C:\AXM_WORKSHOP\

   Avoid an online-only OneDrive Desktop or other cloud-placeholder folder.

2. Open the extracted folder and double-click OPEN_AXM_WORKSHOP.cmd.

   The browser opens the AXM Hub automatically. Do not run the launcher from
   inside the ZIP. RUN_AXM_ALL.bat is a compatibility name for the same route.

3. On the first Windows start only, AXM may need its local Node.js runtime.

   - If compatible Node.js is already installed, AXM uses it.
   - Otherwise AXM announces a download from nodejs.org, verifies the pinned
     SHA-256, and keeps Node only in this Workshop's runtime folder.
   - This needs no administrator permission and changes no system installation.
   - The first bootstrap needs internet; later core Hub starts are local.

4. In the Hub, open Test Room when you want to inspect readiness.

   CLAIMED  discovered, not opened yet
   TEST     opened and ready for checks
   WORKING  checks passed
   SAVED    checkpoint/reload persistence confirmed

   The internal compatibility value behind TEST remains NEEDS VERIFY.

IF STARTUP FAILS

Read AXM_START_REPORT.txt beside this card, then read docs\BEGINNER_GUIDE.md.
Nothing is uploaded and no administrator permission is requested.
