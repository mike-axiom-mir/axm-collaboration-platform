AXM TRUST CHARTER   (v1 · 5 July 2026)
Seven commitments written BEFORE anyone depends on us — because
rules adopted before temptation are the ones that hold. The
seams charter governs what people SWAP; this governs what
people TRUST. Private AXM today, anyone later, same rules.
============================================================

1. THE SPINE'S PROMISE (compatibility)
   The foundation ONLY EVER ADDS. No existing call is removed
   or changed in behavior: AXM.init / ask / store.save / load,
   the gate request shape, the storage slots — code written on
   the spine keeps working, period. If something must ever be
   replaced: long deprecation ladder (old + new side by side,
   loud warnings, migration help), NEVER a cliff. Version
   numbers signal additions, not breakage.

2. THE SUITCASE + THE EXIT (anti-extraction as a shape)
   Every person can always take everything and leave cleanly.
   Canonical form, declared now:
     axm-suitcase.json = { format: 1, exported: ts, saves,
       registry, wisdom, identity, logs, settings }
   — one readable file, importable back, understandable by any
   human or AI without AXM installed.
   The mirror: THE GOODBYE PATH — a documented way to wipe AXM
   from a device completely. Trust is a working door marked
   exit, not a promise not to lock it.
   STATUS: shape canonical now; the one-button implementation
   needs spine storage enumeration -> built with the settings
   hub. NO FAKE DONE: today the suitcase is manual (copy the
   folder + export registry/reports); that is stated, not hidden.

3. NAME TERRITORY (id namespaces)
   Official tools:    plain ids (prehub, studio) and axm.*
   Everyone else:     prefix with your name: errol.paint,
                      ivan.monitor — first-come per prefix.
   Asset packs and prompt packs: same rule.
   One line today; unfixable id collisions in shared saves later.

4. HONEST CARTRIDGES (declared powers)
   Every tool manifest carries a "uses" list — what the tool
   touches, readable BEFORE installing, by human or AI:
     "uses": ["storage"]                       (prehub)
     "uses": ["storage","ai","bridge"]         (duo-test)
   Vocabulary: storage · ai · bridge · export · network · files
   Declaration now; gate-enforcement later (a rule can deny a
   tool acting outside its declaration). A tool with no "uses"
   field is treated as declaring nothing and trusted less, not
   more. This is the club's safety floor: "add only tools you
   trust" cannot scale to strangers without declared powers.

5. THE BUG SUITCASE (issue reports)
   Failure reports have one shape, so helping strangers doesn't
   drown the household:
     { when, what-I-did, what-I-expected, what-happened,
       status-snapshot, recent-log-slice }
   BUILT TODAY: "Export Issue Report" button in the launcher
   (next to Action Report) — asks what you expected, bundles
   the rest automatically, writes a real file to /exports.

6. THE ACCESSIBILITY FLOOR (who can be in the club)
   Every AXM tool, from birth:
   - readable contrast (light text on dark: no muted-on-muted
     for anything that matters)
   - touch targets big enough for thumbs (44px-ish minimum)
   - never sound-only: anything a sound signals, something
     visible signals too
   - readable at arm's length on a phone (no critical 9px text)
   Four lines now; retrofitting 150 tools later is the most
   expensive cleanup in software. This decides who can join
   the Tilburg club at all.

7. THE CORE AS AN ASSET (the constitution on a shelf)
   The four roots stop living only in prose and AI memories:
   /prompts/local/axm-core.txt is the fetchable core — the same
   file for every tool, person, and mind that ever joins,
   including ones that don't exist yet. "Nothing is canon but
   the core" now points at an actual file.
   STATUS: CANON BASE. The four roots are fixed root anchors:
   TRUTH; AGENCY / NON-DOMINATION; CONTINUITY; WISDOM OVER SPEED.
   Everything else can evolve underneath them; the root set itself
   does not get casually revised by momentum, tool needs, or AI drift.

THE PATTERN (why now)
   Each item is one page today or a rewrite-plus-apology later.
   All seven are the anti-extractive principle turned into
   structure BEFORE there is anyone to extract from — the right
   order, on purpose.
