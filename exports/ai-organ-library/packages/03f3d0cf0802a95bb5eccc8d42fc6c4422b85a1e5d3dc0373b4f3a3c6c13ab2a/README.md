# Shareable Mirror AI organ library

This package contains 115 current public Mirror organ source files and static metadata. It deliberately excludes private Mirror state, specialist memories, checkpoints, archive receipts, raw verification output, tokens, logs and historical organ versions.

Start with `INDEX.md` for a human-readable map, `library.json` for the complete machine index, `taxonomy.json` for category meanings, and `categories/*.json` for cross-field lookup. Exact source bytes live once under `objects/<archive-object-id>/source.js`.

Nothing in this package should be executed merely because it was exported. Categories are inferred browsing labels. A receiving system still needs dependency closure, contracts, tests, permissions and explicit review.
