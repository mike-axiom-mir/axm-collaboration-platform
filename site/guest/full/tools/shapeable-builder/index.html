          QUICK GUIDE
          
Three layers, two readable seats, understandable blocks

          
No coding knowledge is required to start. Each placed block can be shaped gently, one visible choice at a time.

        

        
      

      

        
01
Shape the logic
Add events, decisions, state and actions. Join ports to establish a readable route.

        
02
Attach capabilities
Add storage, AI, controls or multiplayer. Review every requested permission yourself.

        
03
Design the experience
Arrange screens, game scenes, content and controls. Bind them to the other layers.

        
04
Place and move clearly
Drag a library block onto the canvas and follow the landing preview. Drag a placed block by its header; it snaps gently to the grid and nearby blocks. Hold Shift for free placement.

        
05
Shape one placed block
Select a block, open Per-block influence, then choose a moment, a response and a visible detail. Preview the reaction safely before testing the whole experience.

        
AI
Give a young AI a safe seat
Export the same project source as a structured workspace, review its proposed actions, then choose whether anything is applied.

      

      
Drag and drop: the landing card shows exactly where a new block will appear. Alignment lines reveal when blocks line up. The canvas scrolls near its edges, touch and pen dragging are supported, and every completed move remains one Undo/Redo step.

      
Per-block influence: changes belong to the selected copy, not every block of that type. Guided reactions can be previewed. Visual slots can hold local references now and asset-generator results later. Advanced code remains a visible, disabled draft in this beta.

      
Connecting blocks: select the output dot on one block and then the input dot on another. Cross-layer relationships are created in the Inspector. The AI seat never bypasses these visible source contracts.
