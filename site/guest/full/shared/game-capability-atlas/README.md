# AXM Game Capability Atlas

The atlas is the compact live representation of the Run-111 500-game steward
checkpoint. It keeps all 500 unique source ideas searchable while removing the
repeated per-run and per-module governance wrapper from the live Workshop.

It provides search, the source-authored 25 balanced intake waves, and bounded
project plans. Wave 1 contains 20 modules—one from every game-development
domain—and is the default Game Forge starter plan.

The complete 500 source JSON files and all checkpoint ancestry remain in the
Run-111 intake staging area. The atlas is knowledge and planning capability; it
does not pretend that advice about animation, multiplayer, performance, or AI
is an executable engine implementation.

Run:

```powershell
node shared/game-capability-atlas/selftest.js
```
