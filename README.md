# AXM Mirror Local

Mirror can inspect the Workshop's declared Asset Hands service through
`adapters/workshop/asset-hands-service-reader.js`. The adapter is deliberately
read-only and bounded: it reads the service contract and declared JSON Schemas,
checks path containment and digests the observed files, but never loads or
executes a creation provider. Missing Workshop state remains a typed absence;
observation grants no hand, permission, trust, approval or action authority.

Mirror now also contains an experimental, dependency-free native language
baseline under `learned/language-seed-0/`. It owns its tokenizer and learned
next-token statistics, but these artifacts are not loaded by the runtime and
have no tool authority. See `curricula/INDEPENDENT_LANGUAGE_MODEL_ROUTE.md`.

The next machine-grounded rung is under `learned/language-trace-1/`. It is a
real learned categorical surface-plan classifier trained on permissioned
abstract typed situations about bounded support, open uncertainty,
contradiction, missing evidence, repairability, and hard refusal. The learned
part may propose the order of audited trace sections; it cannot write factual
slots. A deterministic verifier rejects incompatible or insufficiently
discriminated plans, and the organ remains shadow-only.

`npm run evaluate:typed-trace-language-shadow` discovers verified,
permissioned real-local Principle traces from the private reasoning-receipt
store without a receipt fixture list. It writes an append-only ignored-state
batch, reruns every trace with hostile fluent human prose, and records fallback
and drift. A mismatch may propose a curriculum gap, but cannot add training
data, retrain, lower the gate, change the model, or activate runtime rendering.

An outside author can prepare a permissioned draft against
`contracts/typed-trace-language-independent-pack.schema.json`. The steward can
seal it with `npm run seal:typed-trace-language-independent -- <draft> <sealed>`
and run `npm run evaluate:typed-trace-language-independent -- <sealed>`. Mirror
binds the declaration, traces, author, and results by digest, rejects overlap
with its corpus and known local evaluation groups, and requires all seven plan
families for a full exam pass. It still records source independence as declared,
not proven. No outside-authored pack has been counted yet.

`npm run record:cognitive-work -- <draft.json>` explicitly seals a machine-only
cognitive-work observation under ignored private content-addressed state. Its
typed contract binds objective and start/end state digests, source and meter
lineage, work shape, pre-existing implementation state, model, toolchain,
environment, hardware, token and time meters, verification, outcome, cost
basis, and permission. The compute meter can preserve CPU core-time,
accelerator time, peak memory, or provider-defined units only under an exact
meter definition; it never infers provider-independent FLOPs. Incomplete and imported observations remain visible
holds; conversation prose, hidden reasoning, secrets, and inferred values are
not receipt fields.

`npm run profile:cognitive-work -- <comparison-key>` describes only an exact
cohort. Five eligible observations across at least three starting states are
required before Mirror emits minimum, median, and maximum resource ranges.
Failures and holds remain counted, and profile-estimated cost is excluded from
directly measured or billed cost. Even then the result is explicitly not a
forecast or an 80% interval. V1 makes no calibrated accuracy claim and cannot
choose a model, hardware, budget, permission, training path, promotion, canon,
or world action.

`npm run seal:cognitive-resource-prediction -- <draft.json>` is the separate
pre-outcome gate. It accepts only an exact sufficiently supported descriptive
profile, binds the future objective and starting state, freezes token and
wall-time intervals plus any provider-defined compute or exactly cost-bound
intervals, and records the complete observation inventory that existed before
the seal. An exact outcome already present in that local inventory is refused.
Prediction sources form a digest-linked per-source sequence and every record is
append-only private state.

`npm run evaluate:cognitive-resource-calibration -- <calibration-key>` later
counts every prediction in the exact method, metric-shape, target-coverage, and
cost-binding cohort. Hits, misses, pending outcomes, ambiguous matches, missing
metrics, and cost mismatches remain visible. Twenty evaluated predictions over
five starting states permit only an empirical local-order coverage report.
Mirror does not pretend its local append order proves external time or
independent authorship, so calibration and accuracy claims remain null and the
report has no optimization, selection, budget, permission, training, runtime,
canon, or action authority.

`npm run seal:cognitive-resource-economics-profile -- <profile-draft.json>`
seals one private content-addressed linear rate profile. Provider token billing,

separate, and total-token rates cannot coexist with token-component rates.
Profiles bind source and rate-schedule digests, declared freshness, currency,
model/hardware scope, exact meter definitions, and permission. They do not
certify current prices, nonlinear billing, hardware power, or carbon intensity.

`npm run estimate:cognitive-resource-cost -- <observation|prediction>

inherited 80% resource target remains lineage rather than a cost-accuracy

Mirror is an experimental AXM-native machine reasoning body. Its internal
contract is structured state: observations, evidence, unknowns, constraints,
candidate actions, consequences, permissions, decisions, and repair notes.
Human language is an equal collaboration surface rendered from the same trace;
it is not a hidden replacement for the machine record.

## Start

Double-click `START_MIRROR_LOCAL.bat`.

Default runtime: `http://127.0.0.1:8818`

Workshop location is portable configuration. Resolution order is an explicit
`workshopRoot` option, `AXM_WORKSHOP_ROOT`, `workshopRoot` in
`config/mirror.config.local.json` (or the example config), then the
platform-aware default: `C:\axm workshop` on Windows or `~/axm-workshop` on
POSIX. Live-Workshop integration tests report an explicit `WORKSHOP_ABSENT`
skip when that directory is unavailable; fixture-backed logic tests do not
silently skip.

For external source review, `npm run review:copy` creates a new manifest-bound
copy under ignored `state/review-copies`. It includes Git-tracked and untracked
nonignored source while explicitly refusing state, logs, private memory,
datasets, checkpoints, local config, and token/key/secret files. Zip that copy,
not the live Mirror directory. The copy is not a machine-state backup.

Active content-addressed batch and learning-cycle writers share
`kernel/immutable-batch-store.js`. When two processes originate identical
bytes, a Windows losing rename (`EPERM`) is verified against the completed
winner and reused. Different bytes are never overwritten or deleted; the
losing stage is preserved as failure evidence. This repairs the observed
concurrent-commit seam without erasing its earlier record.
