# Changelog

Notable public AXM Workshop changes are recorded here. Historical workbench
reports remain available under [`docs/history/`](docs/history/).

## v0.5.0-experimental - 2026-08-04

### Public capability truth

- Regenerated public discovery from current contracts: 206 modules and 1,748
  registry capability identifiers.
- Verified the broader tool index: 210 tools and 1,769 declared capabilities,
  with 123 promotion self-tests passing and none failing.
- Preserved the Growth page's separate measurement: 1,610 exact unique provided
  capabilities across 1,828 declarations. These scopes are intentionally not
  presented as the same metric.

### Production expansion

- Added the current Game Hub games and assets, Memory Continuity Garden,
  Adapter Translation Garden, Repair Resilience Library, Text Fabric, AetherFX,
  AI Habitat, visual-mold systems, Foundation Planet fixes, and the complete
  guest workroom tools.
- Added the dependency-free branch-backfeed leaf modules and the AI-seat courier
  used for real browser game testing from sandboxed collaborators.

### Source and retention boundary

- Separated public production source from local intakes, projects, sessions,
  generated distributions, working handoffs, rollback archives, caches, and
  temporary captures without deleting those local artifacts.
- Hardened deterministic GitHub planning so oversized or private/generated
  material is refused before commit or push.

### Known boundaries

- This is an experimental snapshot, not production certification or CANON.
- Generated declarations are not runtime proof; capability tests and human
  interface checks remain separate evidence surfaces.
- Tomorrow's Human Capability Atlas, Human Interface Intelligence, and Grounded
  Evolution Intelligence modules are intentionally outside this cutoff.

## v0.3.0-experimental — 2026-07-27

### Public front door

- Added a concise visual README with a direct beginner route.
- Added human- and machine-readable discovery maps.
- Indexed 177 tool modules and 1,183 declared capabilities without treating
  declarations as runtime proof.
- Added current status, security, contributing, and license boundaries.

### Launch and verification

- Added `OPEN_AXM_WORKSHOP.cmd` as the recommended Windows route.
- Added a private pinned Node.js bootstrap with SHA-256 verification.
- Added Linux/static and fresh-Windows GitHub release gates.
- Proved launch from a clean Windows path with no Node.js on `PATH`.
- Preserved exact-byte generated registries and digest-bound contracts across
  Windows Git checkouts.

### Platform growth

- Integrated the current modular Workshop snapshot, including Heartbeat, Pulse,
  update seams, game-building systems, capability registries, evidence routes,
  and governed automation foundations.
- Integrated the V106 local/offline deployment intake across its five declared
  owners: Windows launcher, Workshop Packager, Diagnostics, Recovery Center and
  Public Release Adapter.
- Added a verified offline Windows candidate mode with a bundled Node runtime,
  license/provenance companion, strict no-download launcher, deterministic ZIP
  metadata, restored-bundle boot test, safe mode, clean-device matrix, launch
  guide, truth draft and one-click local lifecycle proof.
- Added a read-only Windows precondition collector, runtime-byte verification,
  digest-only reviewed receipts, and explicit proof/publication boundaries.
- Compacted all 100 source capability cards into one routed catalog: 26 active
  cards integrated or mapped to stronger owners and 74 future contracts retained
  without copying 106 repeated run histories, Python mirrors or synthetic builds.

### Known boundaries

- Experimental, not production-certified.
- The ordinary public snapshot still needs internet for first runtime bootstrap;
  the new Offline Windows candidate does not.
- Clean physical Windows x64 adapter-disabled request-trace proof remains held
  until that candidate is exercised on the target device.
- Clean macOS/Linux first launch and independent beginner comprehension remain
  unproven.
- No broad open-source license has been granted yet.
