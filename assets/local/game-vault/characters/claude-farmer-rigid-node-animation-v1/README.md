# Claude Farmer Rigid-Node Animation Study

Status: `RAW_RESEARCH`

This folder preserves the two files supplied by Mike after a Claude Design 3D Object experiment. The source bytes were copied from the root of `D:` and SHA-256 verified before the two loose copies were removed.

## What is genuinely present

`farmer.glb` is a valid embedded GLB 2.0 file generated by `THREE.GLTFExporter r184`. It contains 25 meshes, 14 flat-colour PBR materials and three named animation clips: `Idle`, `Walk` and `Work`.

The animation is not a conventional skinned character rig. There are no glTF skins, bone-weight attributes or inverse-bind matrices. Instead, separate rigid meshes are parented below named transform nodes such as `Hips`, `Head`, `ArmL`, `ArmR`, `LegL` and `LegR`; the clips animate those parent transforms. This technique is cheap and entirely legitimate for stylized low-poly characters whose pieces do not need to bend.

`farmer.obj` is a static geometry snapshot. OBJ cannot preserve the animation. It also references `farmer.mtl`, but that companion material file was not included, so the OBJ should be treated as an incomplete geometry comparison rather than the production asset.

## What AXM can learn

AXM currently models “rigged animation” mainly as skinned deformation. This example demonstrates a second useful class:

1. **Rigid-node hierarchy animation** — separate body parts rotate or translate as nodes; simple, cheap and readable for stylized assets.
2. **Skinned-deformation animation** — one mesh bends according to joint weights; necessary for organic deformation, advanced retargeting and smoother characters.

AXM should preserve the distinction rather than relabel this file as a skinned rig. See `inspection.json` for the exact structural evidence and the claims that remain unknown until live playback.
