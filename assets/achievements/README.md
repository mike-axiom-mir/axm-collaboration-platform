# AXM achievement emblem artwork

The first serious local intake is installed here: 24 progressive transparent
PNG emblems plus six reusable templates. `manifest.json` records the active
art pack and `packs/achievement-badges-v1/source-manifest.json` preserves the
original intake metadata.

- Master canvas: 512 x 512 px.
- Safe artwork area: 420 x 420 px, centered.
- Transparent background; no square plate, scenery, text, letters or watermark.
- Keep lighting direction, camera angle, rim thickness and silhouette language
  consistent across the set.
- CSS only controls locked darkness and unlocked glow. The PNG owns the actual
  collectible artwork.

The Hub falls back to a small placeholder glyph for starter slots that do not
have final artwork yet, so the profile remains usable while more packs arrive.

The profile core owns verified metrics, identity binding, deduplication and
unlock history. These image files never grant authority or alter statistics.
Replacing artwork does not replace achievement truth.
