# AXM achievement emblem artwork

Place the eight generated transparent PNG files in this folder using the exact
filenames in `manifest.json`.

- Master canvas: 512 x 512 px.
- Safe artwork area: 420 x 420 px, centered.
- Transparent background; no square plate, scenery, text, letters or watermark.
- Keep lighting direction, camera angle, rim thickness and silhouette language
  consistent across the set.
- CSS only controls locked darkness and unlocked glow. The PNG owns the actual
  collectible artwork.

The Hub falls back to a small placeholder glyph when a file is absent, so the
profile remains usable while artwork is still being generated.
