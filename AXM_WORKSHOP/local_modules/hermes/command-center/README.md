# Hermes Command Center

Status: TEST / package assembly home.

This is the home folder for the Hermes Command Center.

The Command Center is where finished or test-ready AI parts come together into selectable package profiles.

It is not the main place where parts are deeply created.

It is not the main place where logs are analyzed.

## What comes together here

```text
identity profile
+ connector binding
+ specialist masks
+ skill wrappers
+ prompt vault links
+ template links
+ wisdom profile links
+ run settings
+ consent rules
= package profile
```

## Folder role

This folder should hold or point to:

```text
package profiles
identity binding records
approved/test-ready wrapper indexes
package assembly notes
package selection defaults
```

## Default rule

Command Center assembles strength from finished parts.

Runtime can be ready by default.

Hub sandbox is ON by default.

Action still requires consent.
