AXM PUBLIC BRIDGE SETUP
=======================

The bridge is public. The private token is not.

Public files that belong in this template repo:

- axm-bridge.js
- BRIDGE_SETUP.txt
- PUBLIC_BRIDGE_SETUP.txt
- bridge-token.example.txt

Private local file that should NOT be committed:

- bridge-token.txt

Why:

The bridge is the local connector body. It lets AXM browser tools ask a local process for AI help while keeping API keys on the user's own machine.

The token is only a local door key between the browser tool and the local bridge. It is not part of the public template. Each user should create their own local bridge-token.txt from the example file.

Beginner steps:

1. Keep the public bridge folder from this repo.
2. Copy bridge-token.example.txt.
3. Rename the copy to bridge-token.txt on your own machine.
4. Replace the placeholder with your own local random token.
5. Do not upload bridge-token.txt to GitHub.

Public template rule:

Share the bridge. Never share the real local token.
